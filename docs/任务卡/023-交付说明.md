## 迁移规则

`memory_items` 新增可空 INTEGER：`doneAt`、`statusChangedAt`、`sortOrder`；新增 `index_memory_items_dueAt`。

旧状态为 Done 的条目将 `doneAt` 回填为 `createdAt`。这是历史数据的近似值，不是真实完成时间，因此旧完成项会出现在提取当天的“当天完成”。其他旧条目的 `doneAt` 为空；全部旧条目的 `statusChangedAt`、`sortOrder` 为空。迁移不改原内容、状态和截止时间。旧进行中条目先按提取时间倒序显示；接受、撤回或拖动后使用新排序值。

## 界面配合与真机注意

- Claude 可直接接入 `inProgress()`、`appointments()`、`reorder(ids)`、`dayItems(date)`、`activeDays(month)` 和 `AppGraph.diary`。拖动结束提交完整的进行中 id 顺序。
- 分享时使用 `exportFile` 返回的 Uri，MIME 为 `text/markdown`，携带 `FLAG_GRANT_READ_URI_PERMISSION`（可同时设置 ClipData），再打开系统分享面板。
- 云同步需同时配置好原备份账号、启用定时备份和日记开关；仍沿用原定时备份的充电、空闲、非计费网络条件。手动立即备份不附带日记上传。
- 本卡全程没有安装 APK、操作屏幕、读取/修改手机数据或操作其他 App。系统分享接收、真实坚果云授权/网络、澎湃 OS 夜间后台调度，由负责人在界面接好后实测。
