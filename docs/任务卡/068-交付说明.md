## 合成与删除行为

选中段去重后按开始时间、ID 排序。skipMedia 对与未删除“媒体”事件时间重叠的整段排除音频及文字。无文件的语音输入计入 textOnly，其他无文件段计入 expired；这两类在 txt 中位置均为 `[—]`，语音输入附应用名和“无录音”。说话人规则沿用原话页（包括“可能是我？”）。

音频逐段解码至临时 `segment.pcm`，成功后才接入同一个 AAC 编码器；成功段之间插入 8000 个静音样本（0.5 秒）。每段 PCM 用完立即删除，累计样本数用于合成时间轴，避免逐段取整造成累计漂移。坏文件不接入时间轴，其文字保留且位置为 `[—]`。有可读录音就成功；所有现存录音都无法解码则 Failed。没有音频时可仅导出文字/字幕。

输出位于 `cacheDir/exports/<唯一目录>/标题.m4a|txt|srt`，同一组文件同名，重复导出互不覆盖。标题过滤非法字符与控制字符、截到 60 字，空名兜底“涛声录音”。txt 含标题、日期、实际合成时长、事件标题、人名；srt 只含成功接入音频的句子。取消会关闭编码器并删除本次未交付目录；启动和每次导出前清理一天前的导出，正在生成的目录不会被 cleanup 删除。

批量删除在同一数据库事务中删除声纹样本/排除记录、原话向量、原话和段记录；原话 FTS 由现有触发器同步删除。事件、待办及其搜索索引/向量保持不动。与现有隐私删除一致，事务提交之后清录音和声纹缓存（文件系统不能参与 SQLite 事务）；清文件失败只记不含内容/路径的诊断。重复 ID 和不存在的 ID 不重复计数，返回实际删除的段数。

## 内存与速度实测边界

本机测试使用两段各 1 小时的合成 PCM，共 230,400,000 字节，逐段生成、读取并删除；生成块 32,000 字节，编码器替身读取块 8,192 字节。此测试完成导出用时 **182 ms**；采样 Java 已用堆相对起点的最大增量为 **0 字节**（受 JVM 已分配堆、GC 和采样时点影响，不代表没有分配）。最大单段临时 PCM 为 **115,200,000 字节，约 110 MiB**。测试不含真实解码、AAC 编码及 MediaMuxer，不能当作手机速度或真实峰值内存结论。

生产路径不会 `readBytes()` 整段 PCM；编码输入块 8 KiB，0.5 秒静音块 16 KiB，解码复用 MediaCodec 的缓冲区。峰值音频内存不随总时长线性增长，但原话和元数据仍会载入内存。临时磁盘上限约为最长一段 PCM（32,000 字节/秒）加已生成 M4A；若单段长两小时，临时 PCM 约 220 MiB。真机耗时和进程峰值内存未测。
