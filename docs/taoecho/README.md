# TaoEcho

录音设备与手机 App 之间的开放通信协议，由涛声（TaoSheng）项目维护。

> TaoEcho 目前是协议设计草案，不是已经验收的稳定标准。现有设备通过各自协议的说明卡或驱动插件接入，不代表设备原生实现了 TaoEcho。当前设备能力、D3200 试用状态与厂商参与方式见[硬件接入与协议适配](../硬件接入与协议适配.md)。

- 当前版本：**0.1 内部草案**（[TaoEcho-0.1-规范草案.md](TaoEcho-0.1-规范草案.md)）

## 设备怎样接入涛声

| 级别 | 设备 | 接法 |
|---|---|---|
| 1 级 | 普通蓝牙耳机、有线 / USB 麦克风 | 手机系统直接支持，无需任何适配 |
| 2 级 | **按 TaoEcho 草案协作的新设备** | 设计目标为自动识别；需完成设备端、App 端及端到端验收，目前不承诺即插即用 |
| 3 级 | 协议公开的老设备（如 Omi） | 一张说明卡（配置文件） |
| 4 级 | 私有或加密协议的设备 | 插件（翻译成 TaoEcho 模型），贡献者认领维护 |
| 兜底 | 能导出录音文件的设备 | 文件导入 |

厂商想接入时，建议按顺序考虑：能否当标准麦克风 → 能否实现 TaoEcho → 协议是否公开 → 最后才是写插件。
