## 1. 功能全景（一句话版）

**官方 AI = 服务端托管的大模型服务**：App 只下发状态/额度元数据，密钥/地址/模型永不出服务端；用户登录授权→同意→即选即用，按点数计费（Free 100 点/月、Pro 1000 点/周期）；BYOK 自填密钥方式永远并存保留。

涉及的完整生命周期：

```
游客试用 → 注册/登录（Free）→ 状态下发 → 同意 → 自动选中官方 → 整理/问问/回顾/技能按点扣费
        → Pro 授予 → 额度 1000 + auto_digest 放行
        → 登出/会话失效 → 官方条目标"未就绪"，重新登录（登回原账号即归属自动解除）
        → Pro 到期 → 回 Free 行为（auto_digest 本地拦截）
```

## 2. 服务端契约（`server/src/`，worker.js / ai.js）

### 2.1 公开端点（需登录会话）

| 端点 | 行为 | 错误码 |
|---|---|---|
| `GET /ai/official/status` | 下发 `{enabled, configured, consented, plan, remaining, period_end…}` | 401 会话失效 |
| `POST /ai/official/consent` | 记录同意 `{version}` → `ai_consents` | 401 |
| `GET /ai/official/quota` | 当前周期额度明细 | 401 |
| `GET /ai/official/usage` | 用量/扣点历史 | 401 |
| `POST /ai/official/estimate` | 按 task_type+文本估点（返回区间，不扣） | 401 |
| `POST /ai/official/generate` | 生成并扣点；`request_id` 幂等（重放返回 `duplicated` 不重复扣）；`task_type` ∈ digest/auto_digest/ask/analysis/manual_todo/generic | 401 / 402 `QUOTA_EXHAUSTED` / 403 `CONSENT_REQUIRED` / 429 `RATE_LIMITED` / `REQUEST_TOO_LARGE` `TASK_FAILED` `PROVIDER_UNAVAILABLE` `UNKNOWN_PROVIDER_OUTCOME` |

**要点**：`auto_digest` 仅 Pro 放行（Free 一律 402）；点数 = 原子"预留→结算"，服务端是唯一扣点裁决者；所有非 401 业务错误都不是会话问题。

### 2.2 管理端（ADMIN_TOKEN Bearer / 控制台 csrf）

- `POST /admin/release` — 发布 `{channel, manifest:{versionCode,versionName,notes,apk:{file,sha256,size},patches}, files:{文件名:下载URL}}` → `app_release` 表
- `GET /release/update.json|preview.json` — 公开，读 manifest
- `GET /release/<file>` — 按 files 映射 302 到真实包
- `GET/POST/PATCH/DELETE /console/api/ai/providers|rules|users|usage` — 官方 AI 六块管理：运营开关/暂停、服务商 CRUD（含加密密钥、连通测试、默认切换、真删除）、点数规则（含 SSRF `allowed_hosts` 白名单）、用量成本、用户点数调整、权益
- `POST /console/api/users/<id>/reset_password` — 服务端哈希重置
- 用户 CRUD、会员授予/撤销、兑换码批次、审计

### 2.3 错误语义红线

- **HTTP 401** = 会话问题（App 才做 refresh-token 轮换重试）；**其余状态码一律是业务错误**，不得当会话失效处理。
- 管理台 `api()`：**只有 401 跳"会话失效"**；403（如 SSRF 拒绝、CSRF）就地显示真实错误。

## 3. Android 侧行为全集

### 3.1 条目三态（`ProvidersCard.kt`，订阅 `auth.status` + `officialAi.status` 两个 StateFlow）

| 状态 | 副标题 | 点按行为 |
|---|---|---|
| 游客（`AuthStatus.Guest`） | `official · 登录授权后可用` | 弹登录面板（原因栏"官方 AI 需要登录授权后使用"） |
| 已登录未同意 | `official · 同意后即可用` | 弹同意说明页（官方服务说明 + 「同意并启用」） |
| 就绪（登录+enabled+configured+consented） | `official · 点数制·剩 N 点` | 正常切换/检测；剩点随扣费实时变 |

**重组机制**：文案**直接订阅两个 Flow**，不依赖 `_saved` 列表重发（列表内容不变时 StateFlow equals 去重不 emit → 曾致注册后永远显示"登录授权后可用"）。

### 3.2 登录/同意/自动选中链路

- `AuthGate.onAuthSuccess` → `officialAi.refreshStatus()`（登录即拉，不用等重启）。
- `OfficialAi.consent()`：服务端记账 + 本地 `official-ai.xml` `consentVersion=1`；**status==null 时补拉 refreshStatus 自愈**（登录时弱网失败不死锁）。
- `officialAi.onStatusChanged` → `providers.refreshOfficial()` → 重发 saved 行（官方行 `hasKey=officialReady()`）；**false→true 就绪沿**且当前服务商不可用（无密钥/非免密/无 headerAuth）→ 自动 `activate(official)`；已填密钥的当前服务商不被抢占；只沿触发一次，用户手动切回不覆盖。
- 官方条目**不可编辑**（无密钥框/编辑钮），服务端下发的唯一标识 `OFFICIAL_PROVIDER_ID="official"`。

### 3.3 免密钥语义（1.0.9 核心修复）

`LlmPreset.allowsEmptyKey()` 现含 `id == OFFICIAL_PROVIDER_ID` —— 语义 = "该预设免本地密钥"。
效果：**所有共享密钥门**（ReviewStoreRepository / LocalSkillRepository.model.ready / SkillDrafting / AskSuggestions.hasKey / GroundedQA / ManualTodos hasBackup / digestSettings.usable → settings.hasKey）一律放行官方；
之后**由官方桥报真因**：`NeedLogin`→"请登录后使用声声不息官方 AI"，`CONSENT_REQUIRED`→"请先在设置里同意使用声声不息官方 AI"，`QUOTA_EXHAUSTED`→"官方 AI 点数已用完，请等下周期或升级 Pro"——替代原先的"还没填写大模型密钥"误报。

### 3.4 各调用路径的门（已核）

| 路径 | 未就绪官方 | 就绪官方 |
|---|---|---|
| 整理 `DigestRunner` | `needsUser("声声不息官方 AI 未就绪，请先登录并完成同意，或检查官方点数")`（条目 hasKey 作就绪标记） | 走 `digest`/`auto_digest` 扣点 |
| Free 安静自动整理 | 同上+`officialPlan()!="pro"` → 提前 `needsUser("官方 AI 的安静自动整理需要 Pro 会员…")`——**不发服务端请求、不再每周期 402** | Pro 走 `auto_digest` |
| 问问 Ask | `gateOfficialOrKey` → `LlmException(Auth,"声声不息官方 AI 未就绪，请先登录并完成同意")` | prefetch 模式（网关 v1 无工具流→`LlmError.Format` terminal→兼容性降级预取） |
| 回顾/技能/待办 | 门放行→桥 `NeedLogin`/同意文案 | 正常扣点 |
| failover | 官方失败一律 `terminal`，**不静默切 BYOK**；官方也不作他人备用 | — |
| `llmOptions`（重转写选择器） | `ready` 已豁免 `EndpointKind` 判定 | 可选 |

### 3.5 归属与登录（1.0.9 修复死锁）

- `ownershipIssue()` 与 `AuthGateRules.decide:55` 同口径：**仅"已登录且数据归他号"硬阻断**；登出态（session==null）不再误判 → 登录面板可弹。登回原绑定账号 = `AlreadyBound` 自动解除；登异号 = `BoundToOther` 拒绝接管（数据隔离是设计）。
- `bindLocalData` 门槛：会话 + 先有一份真实可用备份（本机文件夹或云端），90s 等落盘，失败不绑定（归属无回头路）。
- 会话失效：`expireSession` 清会话 + 主动 `_loginRequested` + `onSessionExpired` 通知回调；`bindDeclinedAt` 冷却只对"已登录归属确认暂不"生效，登出取消不冷却。
- `authed()`：401→Mutex 串行 refresh 轮换重试一次；非 401 业务错误不刷新不登出；`saveLogin` 登入后 `bindDeclinedAt=0`，空设备登录即绑定。

## 4. 管理台（`/console`，已上线的修复）

- 登录：token → csrf + sad Cookie（12h）；**启动时 GET /session 用 Cookie 恢复 csrf**，刷新/新标签/重开浏览器不掉。
- 官方 AI 页签：服务商列表（测试/设默认/启停/**真删**——删=物理 DELETE 非软停用）、新增（API Base/模型/密钥加密存）、运营开关与暂停、点数规则（**含"允许域名"SSRFF 白名单输入**——保存即生效）、用量成本、用户点数调整。
- 403 业务错误就地显示，不再误踢登录。
- 会员权益页：授 Pro（用户名+天数）、撤销；用户页：建/停/启/删/重置密码（服务端哈希）。

## 5. 设计红线（复核时按此判对错，不是按"方便"）

1. 官方上游地址/模型/密钥**永不出服务端**；App 拿到的只有 status/quota 元数据。
2. 官方条目 App 内**不可编辑、不可当 BYOK 备用、失败不静默切 BYOK**——计费方式选择必须显式。
3. **免密钥 ≠ 免费**：`allowsEmptyKey` 只决定"要不要本地密钥"，可不可用永远以就绪态+服务端裁决为准。
4. 请求幂等凭据（request_id、进行中凭据、预留结算）**不可删改弱化**——同一请求只扣一次点。
5. `request_id` 稳定派生（账号/任务/内容）；用户主动重生成用 nonce 换号。
6. 401 才刷会话；402/403/429 等业务码进各自错误类型。
7. 归属：数据跟账号走；绑定前必须有一份真实可用备份。
8. 本地优先：原始音频不出手机；官方请求只送所需文本。

## 7. 已知遗留 / 未验证（如实，勿当已覆盖）

1. **安静自动整理 quiet-digest 完整触发链未真机实跑**——Free 本地拦截是代码级验证（服务端 402 兜底已证）；Pro auto_digest 生成在服务端 E2E 过，App 侧等待窗口触发属 72h soak 项。
2. **BoundToOther 时归属弹层文案**仅"绑定失败，数据未变更"，未写清"数据归其他账号"；绑定的服务端账号被删时登异号无法接管（设计如此）。
3. **1.0.7→1.0.9 覆盖升级未在真机实测**（签名链一致、lineage 未变，预期无损）。
4. **72h soak / 黑屏 / 严格断网 E2E** 未跑；**正式签名包内测**未跑（本次真机验证均为 debug 验证包）。
5. 环境噪音非缺陷：安全中心"自动薯"无障碍弹窗遮挡 App 吃点击；PC→Cloudflare 偶发分钟级断连（App 正确报网络失败）。
6. `ui/` 归 Claude：本次为链路必须已动 `ProvidersCard`（同意弹层/文案/流订阅），移交 Claude 审核合并；主页/技能页个别静态提示未做官方感知（就绪后自然消失，低优先）。
7. `preview` 通道 manifest 仍停在 1.0.4-preview.1，未随本轮更新（如需预览通道另发）。
