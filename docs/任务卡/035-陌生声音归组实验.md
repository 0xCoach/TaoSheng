# 卡 035 · 陌生声音归组：离线实验（不改 App）

第二批第一项“陌生声音自动归组 + 问这是谁”正式开发前，先用负责人手机上的**真实声纹特征**在电脑上离线验证归组效果、定阈值。本卡**只做离线实验和报告，不改 App 代码**。

**分支 / 工作树**：`codex/035-voice-groups`，`~/Developer/resound-codex-035`。

## 一、数据从哪来（只读，不改手机）

- Claude 会把手机上的 `capture.db`（含 WAL）和 `capture.db.voiceprint-features/` 目录只读拷到 `tools/voice-groups-probe/private/`（已忽略，不进仓库）。**不需要原始录音**：声纹特征文件就是每个（录音段, 说话人编号）一组的声纹向量（卡 008 的缓存格式，见 `voiceprint/VoiceprintFeatureCache.kt`）。
- 可用的“标准答案”：转写句里 `speakerName`（“我”、人名如“璐璐”）和用户手动纠正过的；其余是未知。
- 不连网，不发送任何数据到外部。

## 二、要回答的问题

1. **归组**：把“不是我、也没认出是谁”的声音片段（按 段×说话人编号）做增量归组：新片段和已有组的中心比余弦相似度，≥ 阈值并入（更新中心），否则新开一组；定期合并中心足够接近的组。对比 2～3 种做法（增量单遍 / 凝聚层次聚类 / 增量 + 定期合并），给出推荐。
2. **阈值**：在不同阈值（如 0.45～0.75，步长 0.05）下，报告：
   - “我”的片段被错归进陌生组的比例（应接近 0，“我”的片段用来做负样本检查）；
   - 已知人名（如璐璐）的片段能否聚成一组、会不会被拆开；
   - 组的数量、每组出现次数和累计时长分布。
3. **过滤规则**：多短的片段（秒）、多低的声音质量（如特征来自很短或很吵的片段）应当不参与归组；外放播放标记的片段（`playbackMillis > 0` 的段）排除。
4. **“该问这是谁”的门槛**：按已定规则“出现 ≥ 3 次且累计 ≥ 5 分钟”，在现有数据上会触发几组？举例列出每组的出现时间段和 2～3 句代表原话（**报告里的原话只写在 private/ 下的报告里**，提交到仓库的报告只写统计数字，不写原话）。
5. **试听片段怎么挑**：如果要从一组里挑“最清楚的 3 段 × 约 10 秒”，用什么指标（时长、与组中心相似度、音量）？给出建议。
