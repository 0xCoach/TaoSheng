- 工作目录 `~/Developer/TaoSheng-123`，分支 `codex/123-backup-downloads`（从 `plan/0220` 拉出）。**不改 `ui/`、`MainActivity.kt`、版本号**；`BackupContract.kt` 已由 Claude 加好 `useDownloadsFolder()`，签名不改。
- 版本：**0.2.20**（负责人要尽快发版，范围只做下面这些）。

## 问题

GitHub #20（请先 `gh issue view 20` 读全文）：鸿蒙 7 上用安卓兼容层（卓易通 anco）运行涛声，本机备份选文件夹后一直“本机文件夹无法访问”；而导入录音、“导出一份”（单文件 CreateDocument）、云端备份都正常。结论：该兼容层的文件夹树（OpenDocumentTree + DocumentFile 建文件/改名/删除/列目录）走不通。诊断里只有 `access IllegalStateException reason omitted`，看不出卡在哪一步。

## 要做

1. **新增“下载/涛声备份”存储位置**（实现 `useDownloadsFolder()`）：
   - 用 `MediaStore.Downloads`，`RELATIVE_PATH = "Download/涛声备份/…"`，安卓 10 起不需要存储权限。
   - 现有本机备份用到的全部操作都要有：写入（先写临时名、写完改正式名，用 `IS_PENDING` 或改 `DISPLAY_NAME`）、列出、读取、删除、按天分卷（`VolumeStore`）、保留份数清理。只操作本应用自己写入的文件。
   - 本机备份的现有逻辑（自动备份、保留份数、恢复全部、恢复某一份）不改，只是多一种存储位置；抽象层照现有 `BackupFiles` / `VolumeStore` 的写法，**不要复制一份备份逻辑**。
   - 选了它，`LocalBackupState.folder = "下载/涛声备份"`，`folderAccess = Ok`，`sessionOnly = false`；选回文件夹则恢复原行为。随备份一起备份这个选择。
   - 换手机恢复后：MediaStore 里旧手机的文件不属于新安装的应用，读不到很正常；此时列表为空，不报错。
2. **诊断说清卡在哪一步**：文件夹树那一套每一步（持久授权、解析目录、建探针文件、写、读回、改名、删除、列目录）出错时，诊断记录写**步骤名 + 异常类型 + 脱敏后的原始说明**（去掉地址里的长串、可能的密钥；最多 200 字）。现在的 `reason omitted` 太少。
3. **错误文案**：文件夹树失败时，`lastError` 写“这个文件夹在本机用不了，可以改存到“下载/涛声备份””（界面会据此显示按钮）。

## 必测（5～8 个即可，Robolectric）

- 下载目录：备份 → 列出 → 恢复某一份；保留份数清理只删自己的。
- 按天分卷写读一轮。
- 选择随备份恢复；换装后列表为空不报错。
- 诊断记录含步骤名、不含长地址。
