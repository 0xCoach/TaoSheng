## 诊断

- 检查时没有残留的 Codex exec 后台开发任务，012 已结束。
- 手机诊断快照：167 个片段均已转写结束（151 Done、16 Empty），声纹待处理 0；315 句等待整理。上一版动态超时已让一个 65,144ms 片段在 96,453ms 成功完成。
- 手机截图中原有整理环已显示，但只有不确定动画，没有完成数量。模型一次处理一批，等待期间容易被误认为卡死。本次没有证据表明网络请求无限挂起。
- 崩溃日志：`IllegalArgumentException: layouts are not part of the same hierarchy`，调用栈 SelectionRegistrarImpl.sort / SelectionManager.getContentRect。EventSheet 外层 SelectionContainer 包含 SpeakerLines 的声纹 DropdownMenu；长按同时触发选择和独立 Popup 窗口菜单，文字选择注册器跨布局树计算坐标失败。

## 修改

- 新增独立 DigestProgress StateFlow，不改 MemoryContract。先确定本轮可处理的原话和批次，分母固定；成功落库后才增加完成句数，失败不加，取消释放 running。不依据时间估计百分比。
- 按钮显示真实进度环和“整理 已完成/总句数”；下方显示“第 x/y 批 · 等待模型 N 秒”，每秒刷新。每批仍最多 300 句，保持既有整理分组规则；例如 315 句可能按 0/315 → 300/315 → 315/315 更新，不是逐句 streaming。
- 等待转写/声纹/对话结束的原话，轮次结束后明确给出等待数量，避免无解释地显示刚整理过。
- 声纹卡片用 DisableSelection 隔开外层选择注册器；长按保留声纹菜单，增加“复制这段”。详情其他文字继续可以选择复制，复制全部保留。
- 公共进度环去掉最低伪造 4% 的显示，0 就显示 0。
- 版本 versionCode 3 / 0.1.2-验证版。
