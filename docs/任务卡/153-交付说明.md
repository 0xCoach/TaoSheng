### 过程中出现的失败

全部列出，不把最终通过写成从未失败：

1. 首次 Gradle 被沙箱拒绝写 wrapper 缓存锁；单条提权后恢复，未清缓存。
2. 首次安卓编译引用了 datetime 内部 DateTimeFormatException，编译拒绝访问；改用明确的 AskDateException，在安卓门面映射旧类型。
3. 首轮 114 项 shared 测试中 3 项样本比较失败：录制工具定义/出处时误用桌面 org.json（键顺序与转义不同）；工具模式的首轮消息样本又被自动预取轮覆盖。冻结旧实现后改在 Robolectric API 29 录制，并限制每模式只允许一次调用，保持逐字断言，没有将新输出覆盖成期望。最终 114 项全通过。
4. 重录时 KSP 出现 FIR RAW_FIR → STATUS 增量解析失败；仅该次录制命令加 `-Pksp.incremental=false` 后通过。没有删除缓存或停止 daemon；后续正常增量构建通过。
5. diff 检查发现一处迁移产生的空行尾空格，已删除。

无尚未解决的构建或测试失败。Gradle 弃用提示、既有 datetime monthNumber/IOException 弃用警告未顺手处理。
