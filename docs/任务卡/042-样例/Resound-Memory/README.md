# 回响记忆 · Resound-Memory

| 文件 / 文件夹 | 内容 | 更新 |
            | --- | --- | --- |
            | daily/ | 每日回顾、时间线、条目、卡片 | 按订阅触发 |
            | weekly/ | 每周回顾 | 回顾生成后 |
            | transcripts/ | 原话（仅开启时） | 按订阅触发 |
            | recent-days-index.md | 最近30天导航 | 同步时 |
| starred-highlights.md | 重点与进展 | 同步时 |
| todos-and-appointments.md | 待办与约定 | 同步时 |
| ideas.md、decisions-and-facts.md | 最近一年提取项 | 同步时 |
| archive/ | 一年以前的提取项 | 同步时 |
| inbox/ | 预留；只建空目录，不读取 | 不处理 |
| my-notes/ | 归用户所有 | 回响永不读写、不删除 |

            ## 给智能体的用法
            先读 recent-days-index.md → 某天细节读 daily/ → 核对原话读 transcripts/；重点和待办直接读汇总文件。
            my-notes/ 归用户；其余自动生成的文件请勿手动修改，改了会被覆盖。inbox/ 预留，不读取。
            缺少某类文件表示未订阅或没有内容。条目 I 编号、事件 E 编号用于引用来源。
