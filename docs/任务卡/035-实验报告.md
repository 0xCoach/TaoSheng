# 卡 035 · 陌生声音归组离线实验

## 结论

当前数据不能定出满足“本人误归接近 0”的上线阈值。建议后续使用增量+定期合并做可撤销的候选归组，以 0.70、有效人声 ≥3 秒作为观察起点，先补本人门禁和人工确认样本，再决定是否自动提示。0.70 下人工本人命中 3/14 (21.4%)；0.75 下为 2/14 (14.3%)，已知姓名的拆分情况见下表。这些数字是相似命中风险，不是真实误归率。已知姓名仅 1 人、2 个合格单元，不能充分验证多人之间的区分能力。

## 数据与口径

本地数据库含 319 段、687 句、363 个段×说话人单元。363 个特征文件中，有效向量 330 个、空向量 33 个、格式错误 0 个。精确缓存键匹配 363 个单元；缺失 0 个；孤立文件 0 个。
有效匹配向量 330 个；标签分布：{"unknown": 171, "self_auto": 143, "self_manual": 14, "named_manual": 2}。含播放标记的录音段共 8 个。
按生产缓存格式读取 192 维大端浮点向量，按生产哈希规则关联转写；按录音起始时间、段 ID、句子顺序增量处理。只读临时副本加载 WAL，前后逐文件 SHA-256 验证输入未变。
阈值扫描主过滤为有效人声 ≥3 秒，排除 playbackMillis>0、uncertain 说话人、混合/部分身份标签、异常时长。有效向量的互斥排除计数：{"short_speech": 63, "playback": 2}。
实际陌生池只含无名单元。已标“我”按标签被挡住，观测误入为 0，但这不构成声纹算法准确率。下表把所有合格“我”单元查询陌生池最终中心，统计达到阈值的比例（冻结中心，不更新；回顾性评估，含未来片段）；这是离线误吸收风险代理，不能判定未知声音真的不是我。人工子集单独列出。自动标签依赖现有模型，不能当独立真值；未知池也可能混有漏识别的本人。没有原音、未做听辨，不报告真实误归率或纯度。
已知姓名检查将姓名单元加入未知池，隐藏标签再聚类；按姓名列出“样本数/占据组数/最大组覆盖数”，不把无名成员当作不同人。
每次出现按独立录音段去重；累计时长用缓存去静音人声时长，同一段以对应句子时间并集作上限。录音分段仍不等于独立社交场次。

## 过滤与试听建议

3 秒是待验证的保守起点，不是已定标的最优值；1.5 秒是现有特征提取下限。无有效向量、播放标记、说话人不确定、身份冲突直接排除；短片段暂存等待更多证据。仅凭向量不能测出噪声、音量、削波或 SNR；有效人声/句子时长比只能描述静音占比，不能冒充质量评分。
试听候选先按与组中心余弦相似度排序，再优先具有连续 8～12 秒单人转写区间的录音，选 3 个不同录音段并尽量覆盖不同场次。当前没有原音，无法断言最清楚，也不能把拼接的 10 秒有效人声等同于可播放的连续 10 秒。未来持有原音时，再在候选区间上测 RMS、削波率、SNR 和重叠说话；以近中心、足够人声、低噪声/低削波综合排序，并允许试听拒绝。

## 结论边界

这批样本只能支持候选参数比较，不能证明自动归组可以上线。合并会减少碎组，也可能不可逆地混入不同人；首次产品试验建议把合并结果作为可撤销候选。先用本人/已知人的识别结果作前置门禁；对本人相似但未达身份确认阈值的片段单独待确认，不能直接当陌生人。需要独立人工确认的多人正负样本与跨场次数据后，才能定最终阈值；本卡不联网、不操作手机、不修改 App。
