# 卡 035 · 陌生声音归组离线实验交付

## 做了什么

- 新增 `tools/voice-groups-probe/probe.py`、README、11 个合成单元测试及目录忽略规则。
- 按生产缓存格式和键规则关联数据库中的段×说话人；支持 WAL 副本，读取前后核对全部输入文件哈希。
- 比较增量单遍、中心凝聚、增量+每 20 个输入及末尾合并，共 21 组方法/阈值组合；另比较 4 个有效人声时长下限、倒序、固定随机顺序和非导入子集。
- 公开统计及结论见 `035-实验报告.md`。完整出现时间、代表原话和试听定位候选见 `tools/voice-groups-probe/private/report.md`；输入指纹与逐组数字见同目录 `results.json`，均不提交。

## 主要结果

- 363 个缓存文件全部关联成功，330 个有效向量、33 个空向量，无缺失/孤立文件。
- 观察起点为增量+定期合并、阈值 0.70、有效人声至少 3 秒：127 个陌生单元、63 组，达到“3 次且 5 分钟”的组为 0。
- 0.65 对照有 1 个触发组：43 个单元、32 个独立录音段、474.80 秒；私有报告含其时间段和代表原话。
- 0.70 下人工本人查询陌生组中心仍有 3/14 命中；0.75 下仍有 2/14，且已知姓名的两个样本被拆开。相似命中是风险代理，不等于真实误归率。当前不能确定可上线的阈值。

## 怎么验证

- 本机 Python 3.14.6、NumPy 2.5.2，全程本地运行，无依赖下载。
- `python3 -m unittest discover -s tools/voice-groups-probe -p 'test_probe.py' -v`：11/11 通过，约 0.04 秒。覆盖大端缓存/空向量/损坏输入、生产键规则、WAL、过滤、三种聚类、合并权重、去重门槛、负样本不改中心、标签计分和空样本。
- 离线实验约 0.6 秒完成；SQLite 快速校验通过，所有 DB/WAL/特征文件 SHA-256 前后一致。
- 公开报告由统计字段生成；原话、时间、路径和输入指纹只进入 `private/`。提交前检查忽略规则、公开文件隐私内容、实验计数一致性和 `app/src/main` 无差异。
- 未运行 Android 编译或全量回归；本卡没有 App 改动。

## 真机注意事项与遗留问题

本卡没有连接或操作手机，不需要安装版本。本次仅有 1 个已知姓名、2 个合格人工样本；“我”的自动标签不是独立真值，无名池可能含漏识别的本人。以后由负责人补跨场次多人确认样本、试听组内成员，才能评估纯度并定阈值。

没有原音，不能验证 RMS、SNR、削波、重叠说话或“最清楚的 10 秒”。报告提供候选选取建议，不声称完成听辨。段数也不等于独立见面次数；正式开发前需确定场次去重及可撤销合并规则。

未改 `app/src/main`、界面或约定签名。中文提交在 `codex/035-voice-groups`，不推送远端。
