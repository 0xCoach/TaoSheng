# 040 交付说明

分支：`codex/040-ideas-mood`。数据库升级至 13。未改 `ui/`、`MainActivity.kt`、任何 `*Contract.kt` 或 `AudioSource.kt`，未操作手机，未推送远端。

## 做了什么

- `memory_items` 新增可空 `mergedInto`、默认 0 的 `noMerge`，提供 12→13 迁移和 Room schema 13。
- 向量每批补算完成后合并灵感；已有向量也会在后续补算任务检查。仅比较当前模型、向量有效、未拆分过的独立灵感。按提取时间、id 从早到晚处理，并入最相似的更早主条；较早条目延迟补好向量时，连同已有子条目一起改指向，避免多层关联。模型未就绪时等待现有下载/15 分钟补算机制。
- 主条内容、各条原话出处和时间都保留。普通列表、事件条目、日期条目、重点列表及问问/技能/回顾的条目查询只返回独立项；MemoryRepository 返回实时计算的 `repeats`。
- `mergedItems()` 按提取时间、id 升序；`unmerge()` 拆出并永久标记 `noMerge`，拆出的条目也不会成为自动合并目标。
- 普通删除和隐私删除都在删除事务内修复关联：以剩余条目中最早一条为新主条，其他幸存条目直接指向它。
- `importantEvents()` 跨天取重点事件，开始时间倒序，同时间按 id 倒序，最多 500 条，组装条目和重复次数。
- `dayMoods()` 含起止日、空白日；随事件 Flow 更新。按事件开始日归属，排除已删除、媒体、旁人；空白情绪不计，时长向上取整且最少 1 分钟，强度默认 3，按卡中效价计算心力。未知情绪保留分钟统计，但不猜测效价；无已知效价时 energy 为 null。并列主要情绪按名称排序稳定选取。
- 新增“情绪日记”：每日 22:15、Day/MeOnly/带原话、一天最多一张、默认不推送；五个字段按卡配置。明确情绪原话才出卡，不诊断、不评判，推断须用“可能 / 像是”。无本人原话时也使用规定原因“今天没有明显的情绪表达”。

## 阈值实测与微调

本机加载项目相同版本的 `bge-small-zh-v1.5` INT8 权重，校验模型/vocab SHA-256；按生产输入添加 `灵感\n`，WordPiece 分词、取 CLS 并归一化。合成句对只在本机计算，不包含用户原话。

| 句对 | 余弦相似度 | 最终结果 |
| --- | ---: | --- |
| 给回响加一个每天自动总结情绪的功能 / 回响可以每天自动整理一份情绪总结 | 0.928851 | 合并 |
| 把相似的灵感自动合并，保留每次说话的出处 / 相近的想法合到一起，每次提到的原话来源都保留 | 0.821703 | 不合并，保守漏合 |
| 给回响加一个每天自动总结情绪的功能 / 给回响加一个每周总结工作进展的功能 | 0.860014 | 不合并 |
| 用语音记录每天的心情 / 用语音提醒每天的待办 | 0.765330 | 不合并 |

第三组是相关但不同的想法，原 0.86 阈值会误并。因此按任务卡允许的微调将 `IdeaMerger.THRESHOLD` 调为 **0.88**；0.78～0.88 均不自动并。宁可漏合，不据这四组样本宣称已解决所有误并。复现脚本：`scripts/validation/040-embedding-probe.py`，传入包含模型和 vocab 的目录。
