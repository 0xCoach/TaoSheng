# R6.2.1 登录与官方 AI 深度复核交付

本轮基线为 0a86cfd5，分支 fix/r62-official-auth-audit，修复包 1.0.10（88）。任务卡提供的 1.0.9 已修复登出后归属弹层死锁及官方免本地密钥门，本次继续审核同一调用链。连接的 OPPO PGU110 原先运行 1.0.8 验证包，不能据此断言截图所在用户手机的版本。

## 修复

- 点选未就绪的官方 AI 立即持久化 activeId，避免同意后仍使用旧服务商；已选中但未就绪的官方条目仍可重新发起登录或同意。
- AuthLoginHost 订阅授权状态，注销或会话失效后及时切回登录界面。
- 登录回放动作重新核验授权，本机数据确认归属完成后才执行原操作，且只执行一次。
- 机主验证仅为完成绑定前的备份步骤放行，备份失败时保持其他受保护操作阻断。重新登录、登出和失效均清除机主验证标记。
- 绑定等待备份期间核对账号，防止切换会话后绑定到错误账号；原备份要求和异账号隔离继续生效。
- 授权状态核对遇 access 401 先串行续期。续期网络失败保留会话并返回网络原因；续期后仍 401 才请求重新登录。官方 402/403/429 业务拒绝不触发登出。
- 官方状态标记所属账号，登出时清空；本地同意记录关联账号，服务端未同意不再被本地缓存覆盖。请求返回时核对账号，避免把旧账号回执用于新会话。
- 官方生成成功后按服务端余额回执更新剩余点数，401 映射为需要登录。
- 修正旧服务端冒烟测试的 D1 shim 与断言，使其覆盖现有 refresh 宽限恢复和过期拒绝行为。

界面改动限于提供方点选和登录面板状态观察，属于本次故障链路。Contract 签名、数据库结构、官方幂等请求凭据和服务端扣点算法均沿用现有实现。
