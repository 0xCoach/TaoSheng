# 涛声 0.4.2 · 2026-11-16

待办按日历看、一键加到手机日历

【待办日历】
“进行中”顶上新增一周日历：选中的日子是橙色胶囊，日期下的小点表示那天有几件事，红点表示有过期，空心圈表示有待确认；点月份可展开整月。
下面从今天起按天排列；一周以后合并成“下周”“本月晚些时候”“12 月”等折叠组；没定日子的放在最下面“随时做”，长按拖动排序照常可用。
过期的事收在最上面，可一键“全部改到今天”。待确认但定了日子的事用虚线标出，可直接确认或不要。没安排的日子点“＋ 加一条”，说一句就加到那天。点过去的日子可回看那天完成了什么。

【加到手机日历】
待办详情里新增“加到手机日历”，打开系统日历的新建日程，标题、时间、备注已填好，点保存即可；没定日子的先选日子。说一句生成的待办确认卡，也可勾选“同时加到手机日历”。不需要日历权限；加到日历后，待办再改动不会同步到日历。
