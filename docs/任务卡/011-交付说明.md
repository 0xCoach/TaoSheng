# 011 交付说明

分支：`codex/011-review`。代码已实现；真实数据 DeepSeek 离线验证因手机未连接而未完成。

## 做了什么

- 新增 `RoomReviewRepository`，实现既定 `ReviewRepository` 接口；AppGraph 仅新增 `review` / `isReviewReady`，在 ResoundApp 装配，复用整理模块的模型服务、密钥和 LlmClient。
- 输入仅读当天未删除、非“媒体/旁人”的事件和关联提取项（含状态及截止时间），不查原话。无有效事件时不调用模型、不推送；已有缓存但事件已删空也不推送。
- 新增共用提示词 `assets/prompts/review.md`：固定七个栏目及条数、客观语气、按状态筛选待办、依据情绪强度记录心力。解析时限制 brief 60 字、固定栏目顺序、丢弃越界出处整条、去空栏目；必需的“一句话”“发生了什么”缺失时记固定格式错误，不覆盖已有结果。
- Room 升级 v7，增加 reviews 表和类型/日期唯一索引、Migration 6→7 与 schema。同日覆盖，最近回顾返回最多 30 天；模型与生成时间持久化。成功模型调用的 token 计入 llm_usage，解析失败的调用也计费。
- WorkManager 默认每天 22:00 附近运行，要求联网；使用唯一周期任务，改时间时重建，暂时错误最多尝试 3 次。当日已有回顾时直接复用推送；手动生成覆盖且不推送。时间、推送开关、lastError 保存在不含密钥的 SharedPreferences。
- 新增统一 `Notifier` 与本机通知实现，独立“每日回顾”渠道，默认重要度。标题为“{App 名} · 今日回顾”、正文 brief；点击打开 MainActivity，分别携带 `open=review`、`date=YYYY-MM-DD` extras。关闭推送仍生成，通知无权限时保留回顾并显示固定错误。
- 新增 `tools/review-probe/`，复用已有只读双读快照逻辑，本地检查完整性；只向 DeepSeek 发送指定日期整理后的事件/条目，原始文件放已忽略的 private/。
- 未改 ui/、MainActivity.kt、任何 Contract.kt 或 AudioSource.kt。既有迁移测试仅同步注册 6→7 和目标版本，未运行其他卡测试。

## 怎么验证的

新增 9 个测试，仅本卡：

- JSON 正常解析/顺序/去空/存储往返、越界编号和 brief 长度限制、缺必需栏目。
- 无事件及媒体/旁人/已删事件不生成；关闭推送只生成；已有回顾复用及用量；手动覆盖不推送；缺密钥固定错误；删空当天后不推旧回顾。
- 一次覆盖 6→7 和 1→7 迁移链，Room 完整结构校验、旧数据保留、覆盖后重新打开数据库读取。
- 定时任务去重、联网约束、改时间替换；独立通知渠道、点击 Intent extras。

执行（JDK 21）：

```sh
JAVA_HOME=/opt/homebrew/opt/openjdk@21 ./gradlew assembleDebug testDebugUnitTest --tests 'app.resound.review.*'
# 后补的 2 个投递测试单独运行，未重跑之前通过的用例
JAVA_HOME=/opt/homebrew/opt/openjdk@21 ./gradlew testDebugUnitTest --tests 'app.resound.review.ReviewDeliveryTest'
# 补上删空当天保护后，仅重跑受影响的仓库测试并更新 APK
JAVA_HOME=/opt/homebrew/opt/openjdk@21 ./gradlew assembleDebug testDebugUnitTest --tests 'app.resound.review.ReviewRepositoryTest'
```

构建与本卡测试通过；总执行时间远低于 10 分钟，没有全量回归。产物为 `app/build/outputs/apk/debug/app-debug.apk`，已检查实际文件，未安装到手机。

真实数据离线验证：ADB 返回 `no devices/emulators found`，未拉到库、未调用 DeepSeek。详见 `tools/review-probe/results.md`；不能据此声称语义验收通过。

## 真机与界面配合

- 负责人连接手机后继续只读离线验证，逐条检查真实回顾的栏目、出处、事实和语气。
- 由负责人在小米 14 Pro 实测通知权限、独立渠道、22:00 附近后台执行、无网恢复、推送开关与改时间。WorkManager 受系统省电与网络影响，不保证精确到分钟；采用 24 小时周期，时区变更或长期延迟后可重新设置时间校准。
- Claude 接 `AppGraph.review` 及详细回顾页面；MainActivity 处理上述两个 extras（含已有 Activity 的新 Intent）。本卡只保证通知打开 App，不实现详细页跳转。

## 遗留问题

- 手机未连接导致真实数据离线验证未完成，是本卡剩余验收项；无伪造结果。
- 模型对事实、跟进状态、情绪走势的语义遵从需要真实样本人工复核；本地解析只保证结构、数量及事件编号有效。
- 暂只实现本机通道；weekly 为表内预留类型，未实现周回顾。界面和真机验收按分工交负责人处理。
