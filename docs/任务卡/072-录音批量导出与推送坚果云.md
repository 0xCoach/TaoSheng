“录音”= 手机里保存的原始录音段（`files/segments/<日期>/*.ogg`），**OGG 原样，不转码**。只处理原声还在的段（受原声保留天数影响）。

## 一、录音批量导出（`RecordingPacker`）

- 选日期范围 → 打成一个 zip，保存到 `下载/Resound/录音包/`（MediaStore，同卡 068 的保存方式，不要存储权限）。
- 文件名：`涛声录音 2026-10-28 至 2026-10-29.zip`（单天写一天）；重名加“（2）”。
- zip 里按天分文件夹：`2026-10-29/14-05-33 3分12秒.ogg`；同一秒冲突加序号。zip 用**仅存储不压缩**（OGG 本身已压缩），流式写出，不在内存里攒整个包。
- `withText`：每段一个同名 `.txt`（该段原话，带说话人）；根目录一份 `原话.txt` 总表（每行：日期 时间、时长、文件名、原话首句或全文）。没转写的段写“（未转写）”。
- `skipMedia`：跳过事件场景为“媒体”的段，以及卡 070 判为已跳过（`SkippedEnv`）/ 疑似影视的段。
- 后台任务，仿卡 069（WorkManager + 前台通知“正在打包录音 35%”+ 取消）；完成通知点开 App。取消或失败删半成品。
- `estimate` 返回天数、段数、总字节、总时长（直接按文件大小加总，快）。
- `availableDays`：原声还在的日子，新的在前。
- `shareUri`：给分享用的 content:// 地址。

## 二、录音推送到坚果云（`RecordingSync`）

- **复用“数据备份”里的坚果云账号和应用密码**（`BackupRepository` 的实现里取，不另存密码）；没填账号时 `hasAccount = false`，不上传。
- 云端路径：`涛声/录音/<日期>/<HH-mm-ss> <时长>.ogg`，原话 `.txt` 同名；文件夹不存在自动建。和备份的目录分开。
- **什么时候传**：新录音段落盘后排队；`scope = Speech` 时等转写完成再传（判断为媒体 / 环境音已跳过 / 转写为空的不传）；`withText` 时 txt 在转写完成后传，之后重新转写（卡 071）则覆盖。
- 条件：`wifiOnly`（默认开）、`chargingOnly`（默认关）；用 WorkManager 约束，失败指数退避重试；一次批量上传，不要每段起一个任务。
- **只传不删**：本机原声过期删除时，云端不删；云端被用户删了也不重传（记已传过）。
- `backfill`：把手机里现有、原声还在的段补进队列（按 scope 过滤）。
- 状态：已传段数、待传段数、本月已上传字节、按最近 7 天估算的每月上传量、最后时间、最后错误（给人看的原因，如“坚果云账号或应用密码不对”“坚果云本月上传流量用完了”）。坚果云免费版每月上传 1 GB；HTTP 403/507 等按坚果云实际返回映射成明白的话。
- 问题记录（`ProblemReports.export`）加一节：开关与条件、已传/待传、本月字节、最近错误（不含账号、密码、文件内容）。

## 三、必测（适度，6～10 个）

- 打包：两天 3 段 → zip 结构、文件名、总表内容正确；`skipMedia` 生效；取消删半成品。
- 估算字节和段数正确。
- 同步：Speech 范围只传转写成功的人声段；未填账号不传；已传的不重复；原声删了不删云端。
- 错误映射：401 → 账号或应用密码不对；507/流量 → 本月流量用完。
- 用假 WebDAV（MockWebServer 或现有备份测试的做法），不连真实坚果云。
