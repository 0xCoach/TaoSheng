## 完成内容

分支 `codex/044-voiceprint-diag`。本次代码仅改后端 `voiceprint` 包及本卡测试；未改 `ui/`、`MainActivity.kt`、`VoiceprintContract.kt`、数据库结构，未操作手机、未联网、未推送远端。

1. 本地分析真实数据库、缓存、录音；脚本与复现方法在 `tools/voiceprint-diag/README.md`。每条怀疑的数字、成立程度、方法分布和证据缺口见 `044-排查报告.md`。
2. 在句时间并集内切连续 3 秒窗口，窗内 RMS 裁剪，至少 1.5 秒有效语音才算声纹。按每句与各窗的重叠时长投票；未知窗保留在分母，不能让少量高分覆盖整句。
3. 使用手动样本 Top-3 平均余弦，排除同一录音段的模板；自动样本完全不参与打分，避免反馈强化。多人模式继续保留第二名差距检查。手动身份、未知锁定与排除规则不被自动结果覆盖。
4. 自动补样本仅允许非播放段、非人工/不确定标记、单人模式；每个有效窗口均高置信且相互一致，最多保存一个 2～3 秒连续窗。仍用已有上限 40 条，按时间及 ID 淘汰最旧自动样本。可用手动中心就绪时清理超长或低一致性自动样本；本快照旧 40 条均超过 3 秒，符合清理条件。自动样本目前只作为受控记录，不进入下一轮模板。
5. 手动离群不删除，通过 `sampleHealth()` 标记；点击补样本只取所点句子的连续窗，多窗口两两余弦低于 0.65 时不补。已有人工样本被重新确认但无法提取一致声音时保留记录、标为 `line-review` 并停止用于识别；再次确认得到一致窗口可原 ID 恢复。用户明确删除/重置的原语义不变。
6. 新窗口缓存使用独立 `w2-` 键；复算复用缓存，不重用旧混合向量。隐私删除清理窗口缓存，重置期间的旧计算不能复活特征或结果。
7. 增加独立本地重算函数与 WorkManager，不调用云端转写/整理调度。最近范围内仅处理已有录音的 Done 段；录音已删除的身份与分数原样保留。

## 阈值与效果

`WindowedVoiceprint` 内集中定义：窗口 3000ms，最低有效语音 1500ms，Top-3 SURE 0.50，投票覆盖 0.75，离群提示 0.45，自动样本分数与组内中心一致性 0.85、最低 2000ms。多人差距仍为 0.08。

0.50 来自同段留出的真实对照：Top-3 的人工负例最高为 0.4545；0.45 已出现误认。最终包含多人差距与重叠投票的同一批源句：31 个正例认出 11 → 21，召回 35.48% → 67.74%；8 个真人负例均为 0 次误认。样本少且是弱标签，不承诺真实误认率为零。

`VoiceprintContract.kt` 完全未修改，旧 SURE=0.65 与 MAYBE=0.45 保留。新流程用独立的后端 SURE=0.50，`speakerScore` 仍是原始相似分数；**是否已确认身份应看 speakerName / speakerPersonId**，不要重新用旧 SURE 推断。投票未通过会压到后端 SURE 以下，现有 MAYBE 显示仍可提示用户。未来如统一界面阈值，请 Claude 在约定层决定，不把分数变成“概率”。

## Claude 接口与界面配合

无需改变当前约定即可从应用层调用：

```kotlin
val requestId = VoiceprintRecomputeWork.enqueue(context, days = 7)
// WorkManager.getInstance(context).getWorkInfoByIdFlow(requestId)
```

`days` 限制 1～30，默认 7。唯一任务名为 `voiceprint-recompute-v2`，APPEND_OR_REPLACE 保留后一次用户请求，不与正常声纹流程并行提交。Worker 失败退避 30 秒起，最多 3 次重试；支持协程取消。界面可观察 WorkInfo 的排队、运行、完成、失败状态。按钮和状态展示本卡未添加。

直接函数：`ResoundApp.voiceprintRepository.recomputeRecent(days): Boolean`，suspend，内部 IO 调度；true 表示本轮需要重试，false 表示无需重试，**不是处理条数**。样本未就绪时可能无可识别任务，界面应先检查 ready。不会重新整理旧事件，已有事件正文不会因声纹重算自动改写。

样本健康：`ResoundApp.voiceprintRepository.sampleHealth(): List<SampleHealth>`，返回 sampleId、automatic、outlier，不暴露原音或向量。手动异常只提示复核；不要让按钮直接删除人工样本。若希望只从 `VoiceprintRepository` 接口调用，请 Claude 后续扩展约定，本卡未改签名。

## 遗留与限制

- 没有逐窗口人工听辨和更多异人样本；0 个朗读样本与 0 个排除记录使音源切换和真实纠错负例无法验证。报告明确区分已证实、部分成立、无法判定。
- 3 秒窗仍可能含重叠人声，RMS 不是 VAD 分类器；不声称解决重叠分离或噪声识别。
- 保留既有人工“同组确认”交互语义；只限制补入的声音范围。只确认一句的界面/约定改动需 Claude 另行设计。
- 历史样本未批量改写成新窗，已有手动样本保留；新短窗样本就绪仍要求至少 3 条、30 秒有效人声，可能需要更多次确认。样本健康标记需要界面接入后才能显示。
- 本卡没有安装 APK 或测量手机耗电/推理时延；先由负责人验收再合并。
