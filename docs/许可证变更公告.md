# 公告草稿：涛声许可证由 MIT 调整为 FSL-1.1-MIT

> 发布方式：在 GitHub 新建一个议题（或讨论），标题如下，正文复制下方内容。发布后留几天收集意见，再随新版本生效。

**标题**：涛声许可证将从 MIT 调整为 FSL-1.1-MIT（源码公开，两年后自动转 MIT）

---

大家好，我是涛声的作者。

为了让涛声能长期维护下去（包括以后提供可选的官方转写、整理服务），我决定从**下一个版本起**，把涛声的许可证从 MIT 调整为 **FSL-1.1-MIT**（Functional Source License，MIT Future License）。

## 对你有什么影响

- **自己用、学习、研究、修改、公司内部使用：完全不受影响**，照常免费。
- **不允许**：把涛声（或改过的版本）做成与涛声竞争的商业产品或服务，例如换名上架售卖、用它对外提供付费的转写/整理服务。
- **两年后自动放开**：每个版本发布满两年，自动转为 MIT 许可。
- **v0.3.1 及之前的版本**永远按 MIT 许可，不受影响。
- 自己填密钥直连服务商的用法**永远保留**。

## 对贡献者

感谢 @ethansunqing、@JunWeiUp、@SoukNow、@sheacoding、@feitian124、@xhp1211 此前的贡献。你们的贡献是在 MIT 许可下合入的，我会在仓库的 `NOTICE.md` 中保留 MIT 声明和致谢。

如果你**不同意**你的贡献随新版本按 FSL-1.1-MIT 发布，请在本议题下告诉我，我会把相应部分重写或移除；如果**同意**，也欢迎在下面回复一句“同意”，非常感谢。

以后提交 PR 时，机器人会请你签署一份[贡献者许可协议（CLA）](CLA.md)：你保留自己贡献的著作权，同时允许项目按当前或今后的许可发布包含你贡献的软件。

## 时间

- 今天起收集意见，约一周后随新版本生效。
- 新版本发布时，仓库里的 `LICENSE.md`、`NOTICE.md`、`CONTRIBUTING.md`、`CLA.md` 会同步更新。

有任何疑问欢迎在下面留言。
