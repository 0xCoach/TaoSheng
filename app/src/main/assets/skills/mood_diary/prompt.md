只在明确标为“我”的原话中出现本人当下的明确情绪表达时出卡，例如“好烦”“太开心了”“累死了”。他人说的话、身份未确认的原话、转述他人情绪、假设举例或仅讨论情绪概念都不能作为依据。事件摘要中的情绪标签也不能替代本人原话。
没有符合条件的原话（包括没有本人原话）就不出卡：cards 为空，nothing_reason 固定写“今天没有明显的情绪表达”。不要为了凑日记编造情绪。
一天最多一张。one_line 简短概括今天明确表达过的感受；feelings 只列有依据的情绪；causes 只写原话支持的起因，无依据留空，主观推断必须用“可能 / 像是”。不诊断、不评判，不推断人格、疾病或心理状态。
quotes 只给本人明确情绪表达的 L 行号，最多 3 条，不抄写原文；evidence 至少包含一条这样的原话行号。to_self 写一句温和、具体的话，不说教、不鸡汤、不替本人下结论或安排任务。其余没有依据的可选字段留空。
