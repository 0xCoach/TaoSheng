# 用涛声记录每一通电话

打完电话，涛声会自动转写、整理成通话记录，标上对方是谁、聊了什么、约了什么，还能按客户名字或号码一搜就有。

原理很简单：**手机自己录，涛声来收**。安卓系统不允许其他 App 录通话，但手机自带的电话 App 可以自动录。涛声只是去读这些录音，原文件不动、不删。

## 三步设置

### 第 1 步：打开手机的自动通话录音

| 手机 | 怎么打开 |
|---|---|
| 小米 / 红米 | 电话 → 设置 → 通话录音 → 打开“自动录音所有通话” |
| 华为 / 荣耀 | 电话 → 右上角 ⋮ → 设置 → 打开“通话自动录音” → 选“所有通话” |
| OPPO / 一加 / 真我 | 电话 → 设置 → 通话录音 → 打开“自动录音” → 选“所有通话” |
| vivo / iQOO | 电话 → 设置 → 通话录音 → 打开“自动录音” → 选“所有通话” |
| 三星 | 电话 → 右上角 ⋮ → 设置 → 录制通话 → 打开“自动录制通话” |
| 其他品牌 | 电话 → 设置 → 找“通话录音”或“录制通话” → 打开自动录音 |

不同系统版本的叫法可能略有差别，找“通话录音”即可。

### 第 2 步：先打一通测试电话

没录过通话的手机，录音文件夹还不存在。随便打一通电话（比如打给自己的另一个号码，说几句话就挂），让手机先录一个。

### 第 3 步：在涛声里添加通话录音

涛声 → 设置 → 录音管理 → 自动导入文件夹 → 添加文件夹 → **通话录音** → 按提示选择文件夹。涛声会直接打开到你这款手机存录音的位置，点“使用此文件夹”就行。

然后选文件夹里**已有的录音**怎么处理：

- **只收新的**：以前的不管，从现在起的电话才收。
- **最近 7 天 / 最近 30 天**：这段时间的通话会转写整理；更早的也会列在时间线上，用到再转。
- **列出全部**：所有旧通话都出现在时间线上，先不转写、不花额度，点开哪通再转哪通。

设置完以后，每通电话挂断几分钟内就会出现在涛声里。

## 常见问题

**找不到录音文件夹？**
先确认第 1 步已打开，并且第 2 步打过一通电话。还找不到的话，在手机“文件管理”里搜“录音”或“Call”，看看录音存在哪。

**对方显示的是号码，不是名字？**
涛声不读你的通讯录，对方是谁全看录音的文件名：手机录音时把联系人名字写进文件名的，就显示名字；只写了号码的，就显示号码。按号码后几位也能搜到。

**老款一加手机**
老系统（氢OS）把通话录音放在系统保护的位置，涛声读不到；升级到 ColorOS 后就可以用了。

**数据安全吗？**
录音和号码都只存在你自己的手机里。转写和整理时，涛声不会把对方号码发给任何服务。

**合规提醒**
个人记录自己的通话一般没有问题。企业用来记录客户沟通时，请按公司规定和当地法规，必要时提前告知对方。
