# 任务卡 206：小米手机升级弹不出安装确认

执行：Codex（gpt-6.2-astra）后台；Claude 界面　审核：Claude
分支：`codex/206-miui-install`（基于卡 204 合并后的分支，开工时以派卡说明为准）　工作目录：`~/Developer/TaoSheng-206`

## 背景

#51：MIUI 14 上，App 内补丁升级“系统弹不出指引的面板”，只能卸载重装。

现在的流程（`app/.../update/`）：补丁合成完整安装包 → `PackageInstaller` 会话提交 → `UpdateInstallReceiver` 收到 `STATUS_PENDING_USER_ACTION` 后，**在广播接收器里**直接 `startActivity(确认页)`，同时发一条通知兜底（`UpdateNotifications.confirmation`）。

通行做法和已知问题：
- 收到 `STATUS_PENDING_USER_ACTION` 后，用系统给的确认页 Intent（要加 `FLAG_ACTIVITY_NEW_TASK`）拉起确认；
- 有开发者报告：从广播接收器直接拉确认页不可靠，改为先经过自己的一个 Activity 中转，再查会话结果，才稳定；
- MIUI 默认关着“后台弹出界面”，后台拉起页面在真机上会被拦（模拟器上正常）。

## 要做的

1. **前台中转页**：新增一个透明的中转 Activity，由它拉起系统确认页，并在返回后查会话结果（成功/取消/仍待确认）。
   - 用户在 App 里点了“安装”、App 在前台：直接由当前界面打开中转页，不走广播。
   - 收到 `PENDING_USER_ACTION` 时 App 在后台：只发高优先级通知“点这里完成安装”，点了先进中转页。广播里不再直接 `startActivity`。
2. **兜底：用系统安装器安装**
   - 提交后 30 秒内会话没有任何进展，或者结果是失败/被拦，或者用户从确认页回来时既没装也没取消：状态里给出“用系统安装器安装”。
   - 用的是**已经合成好的完整安装包**（不用重新下载）：先校验大小、哈希、签名，与现在的安装前校验一致；再通过 FileProvider 用 `ACTION_VIEW` 交给系统安装器。文件要保留到安装完成或用户放弃。
3. **小米/澎湃识别与提示**：识别 MIUI（`ro.miui.ui.version.name`）和澎湃 OS，给界面一个状态，用来提示去打开“后台弹出界面”和“安装未知应用”。
   - 提供直达 Intent：小米权限编辑页 `miui.intent.action.APP_PERM_EDITOR`（带包名）；打不开就退到应用详情页。都用 `runCatching`，失败也不崩溃。
4. **诊断**：每一步都写进 `UpdateDiagnostics`，问题记录里能看出卡在哪一步：提交、待确认、中转页拉起成功或失败、确认页返回、30 秒无进展、转用系统安装器、最终结果。
