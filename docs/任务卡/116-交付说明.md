# 卡 116 · 交付说明

## 做了什么

- 大模型、转写均支持按服务保存多组自定义请求头，复用 Android Keystore 的 AES-GCM 加密；大模型放在 `digest-secrets`，转写放在新增的 `transcribe-header-secrets`。
- 保存时校验 HTTP token 名称，禁止修改 Host、Content-Length、Content-Type、Transfer-Encoding、Connection（不区分大小写）。值禁止换行、控制字符；为兼容 OkHttp，仅接受可打印 ASCII 和制表符，中文需要先编码。错误提示不回显输入。
- 自定义 Authorization 替换自动 Bearer；其他重名头最后一项生效。支持只填自定义认证头、不填原密钥，包含备用模型的可用性判断。
- OpenCode Go 模板 id 为 `opencode-go`。首次向 Go 请求时生成随机 UUID，会话头不出现在 `headers()` 返回的用户列表；自动会话 ID 跨请求、进程重启保持一致，用户同名头优先。
- 请求头和自动会话 ID 进入现有 `secrets.json` 备份链路，恢复时用目标手机的 Keystore 重新加密。继承现有备份口令加密机制。
- `HeaderEntry.toString()` 仅显示名称；服务错误不回显响应原文；豆包响应的 log id 若包含自定义头值会被丢弃，防止经问题记录或诊断导出泄露。
- 版本为 `0.2.20`，versionCode 为 `58`。

## 界面接入

未修改 `ui/` 或 `MainActivity.kt`。仅按本卡许可向约定文件增加类型与默认方法，未改已有签名。

- `digest/MemoryContract.kt` 新增 `HeaderEntry(name, value)`。
- `DigestSettings.headers(presetId)` / `saveHeaders(presetId, entries)`：id 使用保存项的 `SavedProvider.id` / `LlmPreset.id`，不是模板 id。添加服务时先保存服务取得 id，再保存头；编辑时沿用该 id。空列表清除这一服务的头。
- `TranscribeSettings.headers(presetId)` / `saveHeaders(presetId, entries)`：id 使用现有 `TranscribeSource.name`，即 `Doubao` / `Custom` / `Local`（区分大小写）；本地模式不发网络请求。
- 保存失败抛出中文异常，界面捕获显示即可。读取会返回明文用于编辑，界面按要求遮挡值，不打印列表或写进状态日志；自动会话头不需要界面接入。
- 新建服务尚无 id 时，当前约定不提供草稿头参数：界面先保存服务与请求头，再做连接/模型检测。无需修改接口签名。
