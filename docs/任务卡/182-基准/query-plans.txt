  SCAN r USING INDEX index_import_records_startAt
  CORRELATED SCALAR SUBQUERY 3
  SEARCH s USING INDEX index_segments_importRecordId (importRecordId=?)
  CORRELATED SCALAR SUBQUERY 2
  CO-ROUTINE (subquery-1)

  SCAN (subquery-1)
