## 二、阻断级缺陷修复：迁移链缺环

`CaptureDatabase.MIGRATIONS` 数组漏挂 `MIGRATION_36_37` 与 `MIGRATION_38_39`（对象已定义未注册），导致任何 ≤38 库版本的升级路径直接抛「migration required but not found」——**已发布的 1.0.3/80 包受此影响，已随 1.0.4/82 重发修复**。

连带：`expected-delta.json` 夹具白名单停在 v41，本次补齐 v43（版本行、identity hash `94b5…`、新表 `idea_entries`、topics 新列、`index_topics_seriesKey` 索引）。
