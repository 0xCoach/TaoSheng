# 卡 114 · 交付说明

## 已完成

- 版本改为 `0.2.20`（versionCode 58）；仅在 `codex/114-backup-s3` 修改、提交，不推送。
- 新增 `RemoteStore`，备份仓库、恢复、日记上传统一依赖接口。WebDAV 保持英文目录、旧中文目录只读、临时上传再 MOVE、增量/分卷及保留策略。恢复列表补回旧 ZIP 入口。
- 坚果云固定地址；自定义 WebDAV 支持 HTTPS，HTTP 仅接受严格的 `10/8`、`172.16/12`、`192.168/16` IPv4 或 `.local`。拒绝地址内嵌账号密码、查询参数和片段。
- S3 使用现有 OkHttp 和 JCA 实现 SigV4，不增加依赖。支持 PUT / GET / HEAD / DELETE / ListObjectsV2 全部分页、路径式/虚拟主机式、UTF-8 对象键、prefix、分卷复制、保留清理和日记。单次 PUT 原子发布，超过 5 GiB 拒绝并显示“超过 5 GB，暂不支持分块上传”。
- S3 不跟随重定向；无权限和网络错误不会被当作空目录；分页异常不返回半份列表。时间、密钥、权限、区域、桶不存在等错误均转换为固定中文，不回显原响应。
- 设置按三种类型分别保存，切换不会删除旧设置。缺少 `cloud` 的旧配置默认坚果云，沿用旧 `account/password`；恢复旧备份时也明确选回坚果云。云端任务正在运行时拒绝改存储或清除账号，避免任务中途改变目的地。
- 密码及 S3 私有访问密钥继续使用 `backup-secrets` / Android Keystore AES-GCM。分卷备份经原 `BackupSettings` 解密导出、目标手机重新加密写入；三种配置及密钥全部随备份恢复，未出现的其他配置保留。
- Markdown 借用模式按发送时的当前选择读取凭据。S3 路径为 `prefix/Resound-Memory/...`（或原推送文件夹名），备份为 `prefix/Resound-Backup/...`，日记为 `prefix/Resound-Diary/...`。单独配置仍为 WebDAV。借用不复制密钥到推送配置；切换桶/前缀会重建同步指纹。录音附件也适配同一 S3 目的地。
- 未修改 `ui/`、`MainActivity.kt`、任何 `*Contract.kt` 或 `AudioSource.kt`。

## 界面接入（由 Claude 完成）

1. `BackupState.cloud` 三选一；通过 `saveCloud(kind, account, secret, webDavUrl, s3)` 保存。`state.account/hasPassword` 表示当前选项的账号/密钥状态。
2. 坚果云显示邮箱和应用密码；WebDAV 显示地址、用户名、密码；S3 显示服务商、Endpoint、region、bucket、prefix、路径式开关、访问密钥 ID、私有访问密钥。`s3Presets` 提供模板、区域和提示，先替换 `{region}`、`{accountId}`、`{host}` 再保存。`webDavUrl/s3` 保留已保存值，切换回来可复用。
3. `secret=null` 表示沿用该类型已存密钥；首次配置必须填写。切换回来仍需传该类型账号，不能将另一类型的 `state.account` 当成旧账号；当前约定没有查询非当前类型账号的入口，可在页面编辑状态中保留或让用户填写。若需持久化账号回显，需 Claude 追加约定，本卡未改签名。
4. `saveCloud` 校验/安全区错误写入 `state.lastError`；界面应展示并保持编辑页，不能无条件提示保存成功。`running` 时禁用存储切换和清除；测试/恢复返回的错误同样直接展示。
5. `PushChannel.useLinkedNutstore`、`saveWithSubscription(... useLinkedNutstore)`、`linkedNutstoreAccount` **保留原名和签名**，含义扩展为“使用数据备份中所选的云端存储”。旧 true 自动兼容，无需改 JSON。页面标题、借用提示和未配置提示去掉限定“坚果云”；独立配置仍显示 WebDAV 字段。借用 S3 不再填单独的账号密码。
6. 日记云同步提示也应改成“所选云端存储”。本卡没有改 `DiaryContract.kt` 的旧注释或任何界面文案。
