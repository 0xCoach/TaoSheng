首页与夜间模式焕新，新增桌面小组件与快捷语音待办；专题记录更好管理，长会议可以分段整理、中断续做，并减少全天聆听时的后台开销。

### 桌面小组件「涛声快捷」

- 在手机桌面的“小组件 / 添加小部件”里找到“涛声快捷”，放到桌面即可使用；不同桌面启动器的入口名称可能略有不同。
- 查看聆听和专题状态，直接添加待办、开始专题，以及暂停或恢复。
- 专题进行中，“开始专题”变成“记一下”，可随手标记重点；暂停 / 恢复按钮也会对应当前专题状态。

### 快捷语音待办

- 从通知栏、长按涛声桌面图标或桌面小组件点“加待办”，直接打开语音面板。
- 说完生成待办卡，确认后自动收起，不必先进入待办页面。

### 专题模式与记录管理

专题录音已在 0.2.22 推出，本版进一步完善操作、记录管理和长会议整理。

- 会议、培训、通话·访谈、口播稿、普通五种类型；支持暂停 / 继续、定时结束、预约，以及忘记开始后的时段补选。结束后合成一件事，按类型生成纪要；口播稿提供整理版和原话版。
- 重做专题面板：类型、结束时间、“预约专题”和“忘了点开始”入口更集中；进行中的专题显示计时和重点操作。
- 专题记录支持搜索、筛选和删除，未整理完成的记录显示进度及“继续整理”入口。
- “记一下”标出的重点支持撤销、删除；点击重点时间可跳到对应原话。已出纪要的专题修改重点后，可重新生成纪要。
- 删除已结束的专题时，会删除专题记录、合成事件和纪要，保留录音与原话，原话回到平常整理；进行中的专题需先结束或取消。

### 长会议分段整理与续做

- 长会议分段处理并显示进度，中断后继续时复用已完成的分段结果。
- 失败专题可用已有原话重试整理，无需重新转写。
- 重新生成期间保留原纪要，成功后再更新。

### 首页、夜间模式与设置

- 首页集中展示聆听、暂停和专题操作，减少查找入口的步骤。
- 深色模式采用纯黑背景、分层文字和柔和的橙色点缀，改善大字体显示。
- 新增设置搜索，支持“耗电”“不录”等常用说法；点击结果会定位并高亮对应选项。
- 设置首页增加体检提示，集中展示需要处理的问题及入口。

### 后台开销与稳定性

- 优化熄屏录音读取、人声检测和网络连接复用，减少后台界面刷新及无任务时的定时检查。
- 录音记录较多时，减少整表读取，加快队列和原话查询。
- “问题记录”新增线程 CPU 时间，方便定位耗电原因。实际续航改善因设备和使用方式而异。
- “会议速记”增加人数、时长和原话数量门槛，减少一两句闲聊误生成会议卡。
- 修复部分 GLM 模型的思考开关适配，以及录音试听快速切换、停止时的播放重叠问题。

### 外接设备试用

- 新增安克／飞书录音豆 D3200 试用驱动，已实现实时收音、离线补传、录音控制，以及录音豆 / 充电盒电量和存储查询；设备页按实际能力展示。
- 原贡献者验证包在 realme + 主固件 04.92、盒固件 1.2.2 上已有部分实测记录；迁移后的官方构建真机验收、长时间使用及其他固件仍待验证。
- 设备通过说明卡或独立驱动接入，复用涛声的转写、整理与记忆功能。欢迎厂商提供协议、SDK 和测试设备参与适配；TaoEcho 0.1 仍为协议草案。详见[硬件接入与协议适配](https://github.com/0xCoach/TaoSheng/blob/main/docs/硬件接入与协议适配.md)。

### 升级提醒
