# 卡 203：夜里（第二版）——草案，暂不开工

前提：卡 202 已在负责人手机上用了至少一周，门槛已用真机反馈校准过。到时再细化本卡。

1. **周报**：每周日早上推一封，内容是这周的作息（每天几点睡、几点起、睡了多久、规律不规律）、一个发现、一个建议试试的办法。
2. **“试试看”对比**：睡前可以标记当晚的情况（侧睡、没喝酒、换枕头、止鼾贴、感冒，也能自定义）。一天的线索里能看出的情况（比如白天说过喝了酒、说过很累）自动带上，由用户确认。几晚之后对比鼾声时长、睡眠时长。
3. **个人判断器**：用卡 202 存下的“是 / 不是”反馈和 527 类分数，在手机上训练一个很小的分类器，专门区分“你的鼾声”和“你卧室里的误报”。攒够几十段才启用；启用前后都要报告准确率。
4. **记梦**：早上醒来时问一句“要记一下梦吗？”，用户说一句，存进当晚的记录。
5. **最响 15 秒**：从确认过的鼾声里挑最响的 15 秒，一键分享。
6. **鼾声中断**：鼾声突然停 10 秒以上，接着一声大喘气。只标成“鼾声中断”，不下结论。如果反复出现，提示“建议找医生做睡眠检查”。上线前要用公开数据评测误报。
7. **一周作息趋势**、给医生的一页（最近一个月的情况，附几段确认过的典型录音）。
