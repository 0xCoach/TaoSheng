# 007 自身耗电估算交付说明

## 已实现

- 录音服务启动时建立基线，每 10 分钟采样，正常停止时补末次采样。保存时间、单调时钟、服务会话、进程累计 CPU 毫秒、UID 累计收发字节、累计真实麦克风开启毫秒、充电状态及切换序号、电池容量估算。
- 麦克风计时从 AudioRecord 成功开始录音至释放；等待其他 App 释放麦克风不计入，已打开但被静音的 MicBusy 仍计入。相邻累计值相减即该段开启时长。
- 相邻样本计算差值。丢弃负差值、流量接口不支持、跨会话、充电或充电状态未知、采样期间插拔电源、超过 20 分钟的缺口、明显系统时钟调整。会话隔离也防止重启后计数已超过旧值造成误算。
- 按自然日裁剪跨午夜区间，累计有效不充电时间不足 30 分钟返回 null；`DayStats.appPowerPerHour` 输出每小时电池容量百分点。原整机字段保留。
- 诊断导出包含系数、未校准声明和所有原始采样字段；跨日相邻样本可能在两天内重复列出。
- 未修改 `ui/`、`MainActivity.kt`、`*Contract.kt` 或 `AudioSource.kt`；未新增依赖。

## 系数、计算与误差

常量集中于 `AppPowerEstimator.kt`：

| 参数 | 当前值 | 依据与状态 |
| --- | --- | --- |
| a | 0.1 mAh / CPU 秒 | 工程暂定值，相当于 360 mA 的单 CPU 秒有效电流；不是本机测量结果，待校准 |
| b | 15 mAh / 麦克风小时（15 mA） | 按任务卡默认；系统未提供本 App 独立麦克风耗电，待真机复核 |
| c | 0.05 mAh / MB | 工程暂定值；不是本机测量结果，待校准 |
| 默认电池容量 | 4880 mAh | 任务卡指定，且整机统计 Capacity 为 4880 |

`mAh = CPU毫秒/1000 × a + 麦克风毫秒/3600000 × b + (上传字节+下载字节)/1000000 × c`。

`BATTERY_PROPERTY_CHARGE_COUNTER` 是剩余微安时，不能直接当总容量；这里使用 `剩余微安时 / 1000 / (电量百分比/100)` 推算总 mAh。不可用、电量为零或结果异常时回退 4880 mAh。每段耗电除以容量乘 100，汇总后除以有效不充电小时数。例：30 分钟内 CPU 3 秒、麦克风 30 分钟、流量 6 MB，估算 8.1 mAh，约 0.332 个百分点/小时。

后续有可用系统数据时：`a = UID CPU 分项mAh / (用户态秒+内核态秒)`；`c = UID Wi-Fi及移动网络分项mAh合计 / 同期收发MB合计`，分母为零则不能求系数。需要统一统计时间范围，不用 UID 总 mAh 同时反推多个未知量。

当前无法给出经过验证的误差百分比。CPU 频率/核型、无线信号及网络尾耗电、屏幕/GPU/磁盘、休眠与唤醒锁、系统进程代办工作都可能偏离本模型。只计服务运行期间的本进程 CPU 和 UID 流量，停止服务后的转写耗电不计；采样缺口和边界采用保守剔除，跨午夜按时间比例分摊。数值是粗估，不是系统计费级测量。
