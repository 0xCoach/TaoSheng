## 完整文案清单（本卡新增或替换）

| 情况 | 文案 |
|---|---|
| 找不到主机 | 找不到 {主机}：检查地址拼写；用 Tailscale 等内网地址时确认手机已连上 |
| 拒绝连接、无路由 | 连不上 {主机:端口}：确认电脑上的接收服务已启动、端口正确；局域网/Tailscale 地址需手机和电脑在同一网络 |
| 超时 | 等待超时：服务没有响应，检查网络或接收端是否卡住 |
| SSL、证书错误 | 安全连接失败：证书无效或过期；内网服务可改用 http:// |
| 地址无法解析 | 地址格式不对：需以 http:// 或 https:// 开头 |
| 400 | 服务拒绝了请求（400）：多为参数或格式不对，检查通道设置 |
| 401、403 | 认证失败（{码}）：检查密钥、Token 或权限 |
| 404 | 地址不存在（404）：检查接口路径 |
| 409 | 文件夹冲突（409）：检查父文件夹是否存在及路径是否正确 |
| 412 | 文件已被修改（412）：稍后重试，避免覆盖其他修改 |
| 413 | 内容太大（413）：接收端限制了大小 |
| 423 | 文件被锁定（423）：关闭占用文件的应用后重试 |
| 429 | 发送太频繁（429）：稍后再试，或检查当天额度 |
| 5xx | 服务出错（{码}）：对方服务器问题，稍后会自动重试 |
| 文件夹 503 | 坚果云暂时限流，稍后会自动续传 |
| 文件夹 507 | 存储空间不足（507）：清理坚果云空间或增加容量 |
| 3xx | 服务要求跳转（{码}），已停止发送：检查地址是否完整 |
| 其他 HTTP 失败 | 服务拒绝了请求（{码}）：检查通道设置 |
| 无法解析服务内容 | 服务返回了无法识别的内容：地址可能指向了网页而不是接口 |
| 服务拒绝 | {通道名}：{服务给的原因} |
| 无服务原因 | {通道名}：服务拒绝了消息，检查密钥和当天额度 |
| SMTP 530/534/535/538 | 邮件认证失败（{码}）：检查账号、授权码或 SMTP 权限 |
| SMTP 421/450/451/452 | 邮件服务暂时无法接收（{码}）：稍后再试，或检查当天额度 |
| SMTP 提前断开 | 邮件连接已断开：检查网络和 SMTP 服务后重试 |
| 其他异常 | 推送失败（{异常类名}）：检查通道设置 |

HTTP 非成功且带可解析服务 JSON 时，状态说明后追加“；{通道名}：{服务原因}”。Webhook 和 WebDAV 不回显响应体。原有必填项、配置校验和“推送服务响应过大”保护文案保留。

服务原因去除换行，先脱敏，再按 Unicode 字符截为最多 80 字。密钥、Token、授权码、签名密钥、Authorization 及其凭据部分、附加请求头值、Webhook 完整地址及路径令牌、URL 的 key/token/access_token/secret 参数替换为 `***`。服务原因中的完整 HTTP(S) URL 仅保留主机和端口，不显示路径或查询参数。错误中不保留原始异常链。

## 各通道服务原因字段

| 通道 | 字段优先顺序 |
|---|---|
| PushPlus | msg → errmsg → description → message |
| 企业微信、钉钉 | errmsg → msg → description → message |
| Telegram | description → msg → errmsg → message |
| Server酱、飞书 | msg → errmsg → description → message |
| Notion | message → msg → errmsg → description |
| SMTP | 认证及临时失败用固定状态文案；其余拒绝取响应码后的说明，按 message 处理 |
| 自定义 Webhook | HTTP 状态和异常分类，不解释成功响应体、不回显失败响应体 |
| 坚果云文件夹 | HTTP/WebDAV 状态和异常分类，不回显服务响应体 |
