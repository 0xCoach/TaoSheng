原话可以手改，长会议很快出纪要，录音能长期保留，新增千问转写

【原话可以改了】
长按一句原话 → “修改文字”，原地改好点“保存”，改过的句子标“已修正”。
· 这句已经整理进某件事的话，底部会提示“重新整理”，点一下就按改正后的文字重新生成；改字本身不会让已整理好的事件或专题纪要自动变。
· 正在播放时修改，字幕也立刻换成新的；同一说话人连续几句，可以长按中间任意一句修改、插入换行。
· 对改过的录音点“重新转写”时会提醒：手动改过的句子会换回机器识别的结果。

【专题会议：边开边整理，会后很快出纪要】
会议按 10 分钟一块，开会时录完就转写、整理好一块存一块；哪块内容变了只重做那一块。结束后只剩最后一块和汇总，长会议不再一直“整理中”。
· 总纪要按字数合并，两小时的培训从连调十几次模型减到三四次。
· 整理时写清进度和在等什么；30 分钟没进展会说明原因，可“先整理（剩下的不等了）”，没整理成的块可单独“补上”。
· 开会中可以展开看已整理出的要点。

【大模型更耐用：慢模型、思考模型也能整理完】
· 整理时边生成边接收，进度里显示“模型思考中 / 正在写结果 · 已收到 N 字”；太久没动静会把这一批切小再试，不再整批白等。
· 按模型记住一次交多少内容合适：慢的、爱思考的模型自动改小每批。
· 智谱可按“深度思考”开关降低思考强度；模型设置里新增“整理速度”检测。
· 回顾、技能卡、问问遇到主模型太慢，照常换备用模型。

【长期保留录音】
推送通道可以把录音推到网盘（坚果云 / WebDAV / S3）或手机里的文件夹（SD 卡、U 盘、网盘同步文件夹）。
· 开着推录音时，没推上去的录音到期也不删；想删随时能删，会再确认一次。
· 每天一份逐字稿，标出每句对应的录音文件；推完会核对。
· 可只在充电时推；通话录音、导入的录音默认不推。新增“只推文字”“长期保留录音”两个模板。
· 推出去的文件由你自己管理，涛声不会去删：做隐私删除时，会列出网盘 / 文件夹里需要你自己删的文件，可一键复制路径。

【语音转写】
· 自定义转写可选“阿里百炼（千问）”，地址和模型已预填，填 API Key 即可；自带说话人区分，用量里显示 token。
· OpenAI 兼容接口可选“分说话人”（diarized_json）。
· 密钥框显示“还没保存 / 已保存，未验证 / 已验证”，测试后说明能否分说话人；首页“转写未就绪”点一下直达测试。
· 语音转写设置拆成四张卡片：转写服务、什么时候转、外放的声音、说话人；测试按钮就在保存旁边，保存后自动测一次。

【更省电】
后台不再反复读全部历史：推录音的保留核算、已完成专题、待办提醒、推送记忆文件夹都改成只在需要时、按需读取；没开推录音时不再检查全部录音文件。

【其他】
· 首页搜索记录保留最近 10 个词，可单独删、可全部清除。
· 夜里“最响的几下”只算睡着时；修复部分手机（如魅族）夜里记录不开始的问题。
· 邮件推送更稳：连发几封只登录一次，被限流时会说明并自动重试；授权码错误不再误报成限流。
· 待办加到手机日历时改为从当前页面打开。
· 修复专题汇总偶尔显示“本地处理未完成”。
