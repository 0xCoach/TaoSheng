- 工作目录 `~/Developer/TaoSheng-132`，分支 `codex/132-onboarding`（从 `plan/0221` 拉出）。**不改 `ui/` 和 `MainActivity.kt`**；开箱向导和提示界面由 Claude 做。

## 背景

负责人要优化新手上手：第一次打开走 4 页开箱向导（欢迎 → 必要权限 + 后台自动准备本机转写 → 配置 DeepSeek → 现场说一句试试），之后在今天页按需提示可选设置。界面由 Claude 做，本卡提供界面需要的底层信号。

## 约定（Claude 已写，签名不要改）

`onboarding/OnboardingContract.kt`（`OnboardingTip`、`Onboarding`），`AppGraph.onboarding` / `isOnboardingReady`。注释即需求。

## 要做

1. 实现 `Onboarding`，在 `ResoundApp` 装配到 `AppGraph.onboarding`。状态存 SharedPreferences（新文件 `onboarding`），**不进备份**（换手机恢复后按新手机重新判断；但已完成过向导的用户恢复后不应再弹向导——向导完成标记由界面存在 `ui` 偏好里，界面会处理，本卡不用管）。
2. `firstTranscriptAt`：第一次出现非空转写句子时记下时间（监听转写入库；只记一次）。老用户升级上来时如果已有转写，直接取最早一句的时间，不要当成新手。
3. `tips`：
   - `KeepAlive`：录音服务被系统意外停止过（复用现有“已停止，点此恢复”判定的同一处，`CaptureWatchdog`/`CaptureBootReceiver` 等）后出现。
   - `Speakers`：区分说话人没开（看本机转写设置 `speakers-enabled` 与模型是否就绪；用云端转写时不提示），且最近 2 天内有录音段在说话人上明显是多人（用现有转写结果里能判断的信号，如云端/本机返回的说话人标签数 ≥2，或声纹认出“我”以外的人；没有可靠信号就不提示，宁缺毋滥）。
   - `Backup`：首次转写超过 3 天，且本机备份和云端备份都从没成功过。
   - 按 KeepAlive > Speakers > Backup 排序；`dismiss` 后永久不再出现；条件不再满足时自动消失。
4. `record` / `wizardFinished`：本地计数与耗时（如 `first_transcript_after_wizard_ms`），写进现有问题记录导出（与其他诊断同处），不记内容、不上传。
5. 性能：不新增轮询；用现有数据库变化通知或已有心跳。

## 必测（5～8 个用例）

- 首次转写只记一次；老用户已有转写时直接取最早时间。
- 三种提示的出现与消失、dismiss 后不再出现、排序。
- record 累加、wizardFinished 后首次转写耗时计算。
