# 016 本地转写与自定义服务

用户明确授权实施、测试并更新手机，包含设置 UI；覆盖仓库原有 Codex 不改界面的分工限制。保留现有服务选择，不能静默改成云端。

- 语音服务：豆包 / 本地 / 自定义（OpenAI 兼容 multipart 音频转写）。
- 本地 SenseVoice Small 2024-07-17 int8；CPU 和 NPU，默认 NPU。
- NPU 自动检查 Build.SOC_MODEL，首版只允许经过实测的 SM8650；其他芯片使用 CPU。
- 本机初始化和实际识别通过后显示检查通过，失败回退已下载 CPU；CPU 不在则明确要求下载。
- 模型从官方 GitHub Release 按需下载；SHA-256 固定校验、临时文件、断点续传、解压后原子发布。不将 ASR 权重放入 APK。
- 继续 30/45/60 分钟分批运行、手动立即转写；本地识别完成后释放独立进程，不持续流式推理。
- 本地无需联网，不计入云端上传用量；不影响后续云端文本整理需要网络。
- 自定义端点兼容根地址、/v1、完整 /audio/transcriptions；提供 GET /models 拉取与选择，保留手填。
- 新增 TranscribeSettings.ready 默认实现，旧实现/预览无需改签名；用于区分本地就绪与有无密钥。

验证：模型下载恢复及完整性、CPU/NPU 实机识别、失败回退、原有 VAD/声纹库兼容、队列持久化和离线调度、端点路径归一化。仅相关测试，不全量回归。
