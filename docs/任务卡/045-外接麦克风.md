# 卡 045 · 外接麦克风：系统认得的输入设备都能选（后端）

负责人定（10-24）：**默认手机麦克风**；同时支持外接麦克风，只要系统认得的都可以选（Type-C/USB 麦克风、大疆领夹麦接收器、有线耳机、蓝牙耳机如 AirPods、LE Audio 耳机）。后面的人声检测、切段、转写、整理都不变，换设备就是换一个 `AudioSource`。自定义蓝牙设备（FoloToy 胸牌）不在本卡。

**约定**：`audio/InputContract.kt`（新）：`InputKind`、`InputDevice`、`InputChoice`（Phone 默认 / AutoExternal / Device）、`InputStatus`、`InputDevices`。`AppGraph.inputs` / `isInputsReady` 已加。签名不要改。界面（录音与后台页“录音输入”、设置首页显示设备名）Claude 已在 main 做好。
**分支 / 工作树**：`codex/045-external-input`，`~/Developer/resound-codex-045`。

## 一、设备列表 `AndroidInputDevices`

1. 用 `AudioManager.getDevices(GET_DEVICES_INPUTS)` + `AudioDeviceCallback` 实时更新。
2. 归类：`TYPE_BUILTIN_MIC`（可能有好几个）只算一个“手机麦克风”（`InputDevices.PHONE`，key `"mic"`）；USB_DEVICE / USB_HEADSET / USB_ACCESSORY → Usb；WIRED_HEADSET → Wired；BLE_HEADSET → BluetoothLe；BLUETOOTH_SCO → BluetoothCall；TELEPHONY、REMOTE_SUBMIX、FM_TUNER、ECHO_REFERENCE、内置 TV 调谐等**不列**；其余 → Other。
3. `key` 必须拔插后不变：`<类别>:<productName>`，能拿到蓝牙地址就加上；同一设备系统给出多个条目（如 USB 耳机同时是输入输出、蓝牙的 SCO 和 BLE 都在）只列一个，**同一耳机同时有 LE 和 SCO 时优先 LE**。
4. `devices`：手机麦克风第一，其后接着的外接设备（最近接上的在前）；当前选中的 `Device` 没接着时也列出（connected=false，名字用保存时的）。
5. `choice` 存设置文件（随备份，卡 037 规则），默认 `Phone`。

## 二、外接来源 `ExternalAudioSource : AudioSource`

1. 输出照旧 16k、单声道、16 位、每帧 480 采样。设备不支持 16k 或只有立体声时，按设备原生格式打开再自行降采样/混成单声道（简单可靠即可）。
2. 用 `AudioRecord.setPreferredDevice` 指定设备；打开后检查 `routedDevice` **确实是目标设备**，否则视为不可用（不要悄悄录成手机麦克风还标成外接）。
3. 蓝牙（SCO / LE）：用 `AudioManager.setCommunicationDevice`（API 31+）+ 适合的音源（`VOICE_COMMUNICATION` 等，以真机能录到为准）；停止时 `clearCommunicationDevice`。需要 `BLUETOOTH_CONNECT` 权限的话加到清单，并在交付说明写清楚界面要在哪里申请（Claude 加）。
4. **让着别人**的规则保留：真实来电/通话时照旧让出（`MicYield`）；但回响自己为蓝牙录音设置的通话模式**不能被当成“在通话”**而把自己挂起。
5. `id` = 设备 key，写进 `SegmentEntity.sourceId`（手机仍是 `"mic"`）。

## 三、切换（`CaptureService.listen`）

1. 按 `choice` + 当前设备选来源：Phone → 手机；AutoExternal → 最近接上的外接，没有就手机；Device → 那个设备接着就用，没接着用手机。
2. 选择变化、设备接上 / 断开时：当前片段**按正常结束收尾**（不丢），从新来源开始新片段。外接设备 `Disconnected` 时**立即**换回手机麦克风，不要等 `MIC_RETRY_MS`。
3. `status`：using 是实际在录的设备；note 写原因，例如“DJI Mic Mini 断开了，已换回手机麦克风”“AirPods 现在不能录音，先用手机麦克风”。值班日志（watchdog）记一条 `InputSwitched`（新类型，详情写从哪到哪、原因），统计页不受影响。
4. 来回切换要防抖：同一设备 3 秒内反复断连只切一次。

## 四、声纹按设备

“我”的匹配：若有**同一 sourceId** 的人工样本 ≥3 条且 ≥30 秒，就只用这些样本；不够就用全部人工样本（卡 044 规则不变）。录入朗读（`VoiceprintRecorder`）仍用手机麦克风，不改。

## 五、必测（6～10 个）

1. 设备归类与 key 稳定（同一设备重复条目合并、LE 优先、内置麦合一、不列的类型）。
2. choice 存取、默认 Phone；`devices` 里选中但没接着的设备。
3. 选源逻辑：Phone / AutoExternal（最近接上的）/ Device 没接着用手机。
4. 外接断开立即回手机且片段正常收尾；防抖。
5. `MicYield`：自己的通话模式不让，真实来电照让。
6. 降采样/混单声道输出帧格式正确。
7. 声纹同设备样本够就只用同设备，不够用全部。
