## 做了什么

**服务端已全部落地并部署**，复用现有 `soundsound-auth` Worker + D1，未新建并行用户表。

| 项 | 实现 |
|---|---|
| 迁移 | `server/migrations/0002_membership.sql`，8 张增量表（plans/entitlements/usage_ledger/quota_adjustments/redeem_campaigns/redeem_codes/redeem_records/admin_sessions），`IF NOT EXISTS` 幂等，不动现有 5 表 |
| 会员模块 | `server/src/membership.js`，独立文件，`worker.js` 仅挂 3 行分发；未匹配的 `/auth/*` 与 `/admin/*` 全部放行回原路由 |
| 用户端 API | `GET /auth/membership`（套餐+能力行+当月用量）、`POST /auth/usage`（成功转写分钟上报，id 去重）、`POST /auth/redeem`（原子认领+request_id 幂等+同人重兑幂等+顺延规则） |
| 管理台 | `/console` 单页（HttpOnly+SameSite=Strict cookie + CSRF header），API 在 `/console/api/*`：用户列表/停用、Pro 发放/撤销、配额调整、批次创建/启用/停用、兑换记录、审计、用量概览 |
| 权益模型 | entitlements 按能力行存储（local_asr_minutes 等 4 能力），非 is_pro 布尔；Pro 到期取 MAX(expires_at)，已有 Pro 顺延 |
| Free 额度 | 每月 1800 分钟成功转写，usage_ledger 按 (id,user_id) 唯一去重，失败重试不重复计 |
