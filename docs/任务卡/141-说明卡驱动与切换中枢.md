# 卡 141：说明卡驱动（3 级）+ 运行路径切换到设备中枢

## 背景

先读：`docs/方案/外设驱动插口设计.md`、`devices/.../driver/DeviceDriverContract.kt`（不改签名）、`docs/任务卡/140-交付说明.md`（中枢状态机与接线说明）、`AGENTS.md` 末尾复用约定。

卡 140 做好了共用层 `DeviceHub` 和安卓插口，但 App 仍由旧 `ManagedDevices` 运行。本卡：把现有“说明卡设备”改写成一个实现 `DeviceDriver` 的**说明卡驱动**，把运行路径切到 `DeviceHub`，然后删除 `ManagedDevices`。

**这是录音链路上的改动，首要目标是行为不变。** 现有内置卡：Omi、ADeus（`app/src/main/assets/devices/`）。

## 要做的

1. **说明卡驱动**（`:devices` commonMain，`app.resound.devices.card` 包，纯 Kotlin）：
   - 每张启用的说明卡对应一个驱动实例，编号 `card:<卡 id>`，`tier = Card`，`stability` 按卡的 trial / verified。
   - `match`：保持现有 `matchingCard` 的语义（名字前缀、服务编号、厂商编号任一命中即算），命中返回 `Certain`；Trial 卡未启用时不参与。
   - `open`：按卡片连接参数工作（订阅、开始命令、心跳、写时钟、电量读取），实时声音把现有 `CardAudioSource` 的拆包、校验、解码、丢包统计逻辑搬过来，输出 `AudioChunk`（16 kHz 单声道），丢包换算成 `lostSamplesBefore`。解码只用 `session.toolbox.opusDecoder`，不再直接 new 安卓解码器。
   - 电量：映射为一个 `BatteryPart(part = 1)`，带读取时间。
   - 离线文件：`offline=files` 的卡通过一个“文件插口适配器”把现有 `FileSourcePlugin` 包成 `DeviceFiles`（`confirm` 为空操作、`Reclaim` 按插件 `caps.delete` 映射）。目前没有内置文件插件，但适配器要保留并有一个用假插件的测试。
   - 身份：`DeviceId("android:CardDevice:<地址>")`，`IdScope.PlatformLocal`，用卡 140 的 `AndroidDevicePlatform.legacyIdentity`（共用层拿不到地址时由平台层在 `HubConnector` 里提供）。
2. **切换运行路径**（`:app`）：
   - 新写一个桥接类（建议 `app.resound.devices.android.DeviceInputs`）基于 `DeviceHub`，**对外保持 `ManagedDevices` 现在被用到的全部行为**：
     - `CaptureService` 用的 `recording(Boolean)`、`audioSource(key)`；`AndroidInputDevices.attachCards` 用的设备列表；输入设备的 `key` 仍是 `ManagedDevices.deviceKey(address)` 的值（把这个函数挪到桥接类或工具处，结果不变）。
     - 界面用的 `Devices` 接口（`devices`、`found`、`startScan`、`stopScan`、`pair`、`forget`、`lastError`）继续可用，`DeviceState` 从 `HubDevice` 换算（电量取部件 1）。**界面代码不改**，卡 144 再换新界面。
     - 连接时机、“连通后才发布为可用、等待期间继续用手机麦克风”、断开后记录缺口（`gapStart`）、时钟偏差（`clockOffset`）、重连后补传缺口这些现有语义一个都不能丢。补传用 `hub.withConnection(..., Backfill)`，调 `DeviceSync`（不改其算法）。
     - 配对记录仍存在原来的 `devices` 配置里，格式不变（老用户升级后已配对设备照常出现）。
   - `ResoundApp` / `AppGraph` 的装配改为桥接类；扫描只走卡 140 的蓝牙中心。
   - 删除 `ManagedDevices.kt`、`DeviceAudioBus`、`CardAudioSource.kt` 中已搬走的部分、`AndroidDeviceRadio` 里不再需要的代码。保留 `DeviceSync`、`RemoteDeviceCards`、`DeviceCardsWork`。
3. **测试**：
   - 现有 `Device119Test`、`DeviceSync120Test` 里测行为的用例迁到新结构（假通道 / 假中枢），**断言不放宽**；只测 `ManagedDevices` 内部实现细节的用例可以删，交付说明里逐条列出删了哪些、为什么。
   - 新增：说明卡驱动用合成卡（`synthetic.json`）跑实时声音的正常流 + 丢包 + 坏校验；桥接类的“未连通前不发布音源”“断开记录缺口、重连后触发补传”各 1 个。
   - 只跑 `:devices:jvmTest` 和 `:app` 的 `app.resound.devices.*`、`app.resound.audio.*`、`app.resound.capture.*` 相关测试。
4. **不做**：不改 `ui/`、`MainActivity.kt`；不改录音服务的切段 / 人声检测逻辑（`CaptureService` 只允许改调用桥接类的那几行）；不改数据库结构；不接 PR #30；不做录包（卡 142 并行在做，避免改 `AndroidDevicePlatform` 的录包相关部分）。

## 验证
