## 完成内容

- 数据库 13 → 14，新增 `starred`（默认 0）和 `starredAt`（可空），导出 Room schema 14。旧事件不继承重点，`important` 原值保留。
- `setStarred` 原子更新星标和条目：标上时 Pending 待办、备忘沿用 `setItemStatus` 接受并放到进行中最前；取消只清星标和时间。事务中途失败可整体回滚。
- `starredEvents` 排除删除事件，按标星时间倒序、最多 500 条，带条目及 repeats。所有正式 `MemoryEvent` 映射均补齐星标字段；`importantEvents` 继续独立提供模型要紧事件。旧用户接口 `setImportant` 转接 `setStarred`，不再改模型字段。
- 问问支持 `search_events(starred_only=true)`，无关键词时按标星时间倒序；关键词和语义补召回共用重点过滤。查询结果提供布尔 `starred`、毫秒 `starred_at`，`get_day` 同步提供。`event_star` 先生成待确认卡，确认才落库；旧 `event_important` 操作不再执行。提示词、工具定义及离线 probe 同步。
- 每日回顾输入携带 `starred` / `starredAt`。结果处理保证当天重点优先进入“要紧的”，超过 3 件时上限增至 5；超过 5 件取最近标星的 5 件。模型遗漏重点时用真实事件标题补齐。
- `starred_stale`：截至回顾截止时刻，标星满 72 小时、仍有 Pending/Accepted 待办或约定、没有标星后的完成记录、没有后续相似事件时入选；最多 3 件，优先最早标星的。“值得留意”使用固定日期和真实标题提醒。当天无新事件时仍可在本地生成这类提醒，不调用模型。
- 相似进展复用已有本地事件向量（标题、摘要、要点构成的索引），只比较同模型且维度匹配的向量，余弦相似度 ≥ 0.80。不存在或损坏的向量退回条目判断，不触发下载或云请求。
- 每周技能升至版本 2，新增 Bullets 字段 `starred`“本周你标的重点”；按本周标星时间独立取数，包含更早发生的事件及条目状态、完成时间、状态变更时间。
- 每日记忆 JSON 事件增加 `starred`；Markdown 时间线标题前加 ★。用户主动标星的媒体/旁人事件可进入回顾；标星媒体也保留在时间线中。
