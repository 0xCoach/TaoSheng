## 复现与证据

模型测试脚本：`tools/ort-validation/smoke.py`。仅需 NumPy 和相应版本的 onnxruntime，读取项目内合成夹具和已下载、校验哈希的 BGE 模型，不访问网络或手机数据。

```sh
# 分别在独立的 1.23.2、1.25.1 Python 环境运行。缓存目录含 model_quantized.onnx 和 vocab.txt。
python tools/ort-validation/smoke.py --search-model-dir /path/to/bge-cache --output /tmp/ort-baseline.json
python tools/ort-validation/smoke.py --search-model-dir /path/to/bge-cache --output /tmp/ort1251.json --baseline /tmp/ort-baseline.npz
```

聚合模型与打包结果位于 `tools/ort-validation/results/`。本次本机日志为 `/tmp/taosheng-ort1251-build.log` 和 `/tmp/taosheng-ort1251-final-build.log`；首轮测试 XML 保存于 `/tmp/taosheng-ort1251-initial-tests/`，补跑 Input045Test XML 在 worktree 的 `app/build/test-results/testDebugUnitTest/`。

## 用户手机测试

本轮 `adb devices` 未发现连接手机，未安装、未访问手机数据。用户自行安装：

1. 先在应用内完成备份，再覆盖安装 UU 文件夹的 `涛声-v0.2.6-ORT1.25.1-测试版.apk`。不要卸载旧应用。如果提示签名冲突或禁止安装，停止并反馈，不能用卸载解决。
2. 确认显示版本 `0.2.6-ort1.25.1-test`。检查历史记录和已有声纹仍在。
3. 开始聆听，正常说话 1～2 分钟，检查生成录音/转写；锁屏 5～10 分钟继续说话，观察后台是否稳定。
4. 测试已有声纹识别；如方便，新增一条测试声纹样本，检查录入和识别是否正常。
5. 若已安装语义搜索模型，用一个历史内容相关但措辞不同的关键词搜索；若已启用本地转写，也做一段短转写。未下载的模型不作为已通过项目。
6. 记录手机型号、系统、出错操作和时间。用户手机通过后仍需由贡献者在 Find N6 上复测，才能确认本 PR 对应故障已解决。

电脑模型对照不是 Android ARM 指令兼容性验证，也不能证明所有机型性能和耗电无变化。本次产物仅进入手机验证阶段。
