# 109：本地声纹样本管理后端

按 PR #8 的维护者反馈拆分：只提供本机声纹的数据与操作层，不包含远端服务代码或界面。

## 已完成

- `samples(personId)`：样本来源、原话、时间、时长、状态和是否可回放；`lines(personId)`：人物最近原话及是否已加入声纹。
- `deleteSample(key)`：删除样本和回放副本；原话标注保留。原话来源的“我”样本写入已有排除表，防止自动学习补回，显式重新标注仍可重新录入。
- `sampleAudio(key)`：优先播放新增录入/标注时保存的 WAV，旧样本在原音频存在时回退截取。读取与删除/清除互斥，截取期间保护原录音。
- `sampleAudioBytes`：可观察的声音占用字节数，包括临时回放文件，不含识别向量、原录音和标记文件。
- `clearSampleAudio()`：删除全部样本回放副本和临时声音，持久化禁止旧样本回退的标记；不删除人物、向量、时长和标注。新录入的样本仍能保存声音。列表随声音变化刷新。
- 删除人物、重置“我”的声纹时清理对应声音，其他人物声音保留。文件操作失败会报告错误，不误报清理成功。
- 声音放在 `noBackupFilesDir/voiceprint-samples`，不进入系统或应用备份；恢复备份时删除本机残留声音并禁用旧样本原音频回退，避免 ID 重用后错播。
- WAV 写入工具位于本地声纹包，不依赖远端包。

## 接口与数据库

扩展 `VoiceprintRepository` 接口供维护者接界面；本 PR 不修改 ui 或 MainActivity。`VoiceprintDao.saveSample` 返回插入 ID，新增只读投影及查询，不更改实体、schema 或版本（仍为 29）。包名、签名、版本号与更新通道沿用主线。

“重置声纹”沿用原有只重置“我”的语义；“清除所有样本声音”作用于本机全部人物，不清除声纹向量。临时回放文件会被下次播放覆盖；清理/删除后界面应停止当前播放器并重新获取文件。自动学习的样本在原录音仍在时可回退播放，不额外复制整段录音。
