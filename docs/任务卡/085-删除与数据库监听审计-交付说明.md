# 删除与数据库监听审计

2026-11-02；基线 `c3fa8e6`，分支 `codex/things-token-saving`。审计范围为批量删除、隐私清理、环境音/录音/事件/寻物数据监听及关联展示，不是全项目安全审计。

本轮只增加问题复现测试与文档，没有修改生产逻辑、访问或删除手机数据、安装或发布版本。

## 按优先级排列的发现

### P1：文件删除失败仍报告成功，事件重试无法补清

位置：`privacy/RoomPrivacyActions.kt:99-109`。

数据库事务先删除事件与录音行，文件清理发生在事务提交后。`cleanup` 捕获文件删除异常，仅写日志；接口继续返回成功计数。再次按原事件 ID 删除时已找不到关联路径，不能补清文件。此流程也没有持久化失败清理任务。进程若在数据库提交后、文件清理前终止，同样会留下缺少关联行的文件窗口。

故障注入测试使用非空目录模拟删除失败，确认返回 `ForgetResult(1,1,1,0)`、路径仍在、数据库录音行已消失，再删同事件返回全 0 且路径仍在。该测试验证错误处理缺陷，并不证明用户手机已经发生残留；其他存储维护可能按自身规则回收文件，不能据此宣称文件永不清理。

建议：与删除事务一起持久化待清理路径，事务后执行并重试，实际清理失败需告知用户。不要依靠已删除的事件关联恢复待清理任务。

### P1：同类跨窗口读取风险不限于环境音

位置：`data/TranscribeDao.kt:51`、`envsound/EnvSoundDao.kt:19`、`things/ThingData.kt:30-31`、`data/MemoryDao.kt:284-288`。

这些列表查询缺少读事务。录音、环境音事件元数据、寻物记录是无数量上限的全表读取；事件/条目按天查询，但数据量也没有固定上限。批量删除会改动相应数据。数据跨越 CursorWindow 且同时写入时，存在与 084 所述机制相同的风险。录音队列常驻订阅 `observeSegments`，寻物首页与历史页独立订阅记录列表。

证据边界：确认了代码模式及消费者路径；用户提供的崩溃栈仍只有环境音，未声称其他模块已在手机崩溃。不能把所有未加 `@Transaction` 的小查询都判为故障；`TranscribeDao.day/exportSegments` 已有事务保护，不应重复修补。

建议：优先保护大结果集的完整读取，再按用途改为聚合/范围查询。逐条查询的一致性和多个 Flow 合并的一致性是不同问题。

### P2：批量删除忽略单条错误，直接退出确认和选择状态

位置：`ui/today/TodayScreen.kt:348-357`。

`runCatching` 结果未检查，每轮照常加进度，全部循环结束后关闭弹窗和多选。用户看不到失败条目或失败原因。

故障注入测试经真实首页多选/确认流程删除 6 条，让第 3 条抛异常。最终只删除 5 条，第 3 条仍存在，但确认框关闭。复现测试通过表示缺陷得到验证，并非修复通过。

建议：分开统计成功/失败，对失败项保留重试入口；这属于界面配合项，本轮没有修改 UI。

### P2：多处重复读取历史并重复做全量匹配

位置：`envsound/LocalEnvSoundRepository.kt:31-33,72-89`；`envsound/EnvSoundAggregation.kt:11-12,16-27`。

已有共享 rows/eventMetadata，但 presentation、按日声音、按小时统计等仍各自订阅 DAO 冷 Flow；录音或环境音变化会触发多个全表查询。每个事件匹配时遍历全部环境音行，按小时统计又反复匹配录音与环境音。日期筛选多在内存完成。

这是可由代码确认的重复工作，会随历史量增长增加本地计算和内存分配，也增加读写重叠机会；尚未做手机 CPU/耗电基准，不能量化下降幅度。这里是本地数据库开销，不是大模型 Token 请求。

建议：复用共享流；统计优先在数据库聚合并限制日期；按 segmentId 建映射，避免反复嵌套扫描。不要通过悄悄截断历史数据解决问题。

## 删除范围说明不完整（需保持既有语义）

`ui/today/TimelineSelection.kt:221` 提示会删除录音、原话和提取内容。但卡 079 明确要求已确认寻物记录保留 sourceText 并清空 sourceLineId；`things/ThingData.kt:76-88` 正按此实现，历史页也会显示该副本。`RoomPrivacyActions` 另明确保留回顾和问问历史。

这不是已确认寻物记录的实现漏删，不能擅自改成一并清空。应在删除范围说明中写清哪些历史/确认记录保留；如果要新增“彻底忘记”语义，单独设计覆盖范围及关联清理规则。
