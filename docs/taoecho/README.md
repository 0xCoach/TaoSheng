# 硬件适配规范

涛声提供设备说明卡和驱动插件的统一适配规范，帮助厂商与开发者接入不同录音硬件。

按规范接入后，可以复用现有的设备管理、转写、整理和记忆能力，减少重复开发。设备专属逻辑集中在对应适配模块中，减少对核心代码的改动，方便后续维护和扩展。

## 设备怎样接入涛声

| 方式 | 适合的设备 | 接入工作 |
| --- | --- | --- |
| 系统音频输入 | 普通蓝牙耳机、有线 / USB 麦克风 | 使用手机系统提供的音频输入，验证设备切换与断开行为 |
| 设备说明卡 | 协议公开、可用现有配置表达的设备，如 Omi | 描述设备识别、音频格式、数据帧和支持的状态字段 |
| 驱动插件 | 需要握手、加密、复杂控制或文件传输的设备，如 D3200 | 将设备协议转换为共用模型，声明实际能力，提供测试与维护人 |
| 文件导入 | 能导出录音文件的设备 | 将音频分享、导入或通过文件夹同步给涛声 |

## 接入约定

- **统一接口**：通过设备身份、能力、状态、实时声音和文件等共用模型与涛声交互；见[设备驱动接口](../../devices/src/commonMain/kotlin/app/resound/devices/driver/DeviceDriverContract.kt)。
- **能力按需声明**：实时收音、离线补传、电量、存储和录音控制分别声明，界面按实际能力展示；读取不到的状态保持未知。
- **设备逻辑独立维护**：品牌和固件特例放在对应适配模块中，通过平台提供的连接、存储等接口工作。新增公共能力时说明接口和兼容方案。
- **交付可验证**：提供录包、回放测试和真机报告，记录设备与固件版本，逐项列出已验证、未验证和不支持的能力；编译或回放通过不能代替真机验收。
