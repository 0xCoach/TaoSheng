## 约定签名与界面接入

新增 `app.resound.transcribe.PlaybackContract.kt`，从 AppGraph.playbackSettings、AppGraph.playbackSentences 取得实现。

```kotlin
enum class PlaybackMode { Digest, Transcribe, Skip }
enum class PlaybackOverride { Default, Digest, Transcribe, Skip, NotPlayback }

data class PlaybackPreferences(
    val mode: PlaybackMode = PlaybackMode.Digest,
    val apps: Map<String, PlaybackOverride> = emptyMap(),
) // fun rule(pkg: String?): PlaybackOverride

interface PlaybackSettings {
    val preferences: StateFlow<PlaybackPreferences>
    fun setDefault(mode: PlaybackMode)
    fun setApp(pkg: String, rule: PlaybackOverride)
}

data class SentencePlayback(
    val lineId: Long, val playing: Boolean, val appName: String? = null, val title: String? = null,
)

fun interface PlaybackSentences {
    suspend fun forSegment(segmentId: Long): List<SentencePlayback>
}
```

- Digest、Transcribe、Skip 对应“转写并整理”“只转写”“不记”。应用选 Default 即移除该包的例外，NotPlayback 为“它放的不算外放”。旧界面两个控件经兼容适配器读写统一设置，Claude 替换控件后可移除适配器。
- 逐句按 lineId 关联。playing 为真且无名称时只显示“外放”。原话或设置页切换资料开关后重新读取。
- 首页收集 `RemoteNotices.get(context).showPlaybackHint: Flow<Boolean>`，可读 `playbackHintSeen: Boolean`。实际展示时调用 `playbackHintShown(): Unit` 记一次已读。界面负责展示“外放也在转写和整理，按 App 可以关”及跳到外放设置。录音通知动作已在后台服务接通。
- `app.resound.night.NightContract.kt` 增加 `suspend fun resetPersonal(): Unit`。该方法属于 NightInsights，生产实现由 AppGraph.nightInsights 提供。旧预览实现沿用接口默认的不支持行为。
- `PersonalModelStatus(kind: PersonalKind, yes: Int, no: Int, active: Boolean, accuracy: Float?, ruleAccuracy: Float?, trainedAt: Long?, excludedCount: Int = 0)`。收集 `NightInsights.personal` 即可获得样本与否决计数。
- “昨晚”读取 NightDetail.events 里的 feedback 和 audioAvailable。改答仍调用 `NightRepository.feedback(eventId: Long, value: Feedback)`，撤销传先前的值。折叠行、6 秒撤销条、重学确认框及成本说明由 Claude 接入。

## 真机验收与边界

1. 分别在扬声器、零音量、耳机下录人声。连续切换两个媒体 App，验证逐句标签、App 例外、无通知读取权限回退默认、关闭资料开关隐藏节目名。
2. 将播放器设为“不记”，点击录音通知的“记下外放”。检查本次可整理，停播后再次播放恢复“不记”。分别验收普通录音与专题通知里的按钮排列。
3. 一天成功转写超过 30 分钟外放后展示一次提示，跳设置并重启验证已读。检查“只转写”的片段仍可在原话中逐段放行。
4. 在“昨晚”否认一段，再回听、改答、撤销；清空重学后核对历史答案、已排除段数和夜晚统计。
5. 旧段只有总时长。整段均外放或有重叠播放资料时可以回推；旧的部分外放片段若缺少时间资料，无法逐句还原。新录音的匿名外放标签有采样区间可用。播放会话的临时许可在录音服务结束时也会结束。
