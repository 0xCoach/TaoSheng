# 微信标题比例校准

## 现场证据

最新微信记录 2298 的标题误存为“8月20日 凌晨2:00”，说明姓名替换执行了，但标题识别错误。2297 未识别出标题，因此使用“对方”。

用户保持微信聊天页期间通过 adb 截取 1080×2400 实际画面；状态栏下沿由系统 Insets 确认为 y=126；标题栏背景在 y=256 附近结束；“文件传输助手”亮色文字包围框为 x=399..670、y=168..212。无障碍树没有提供有效文字节点，不能用节点标题作可靠依据。

对应屏幕高度比例：状态栏结束 5.25%，标题栏结束约 10.7%，标题文字约 7.0%～8.8%。这些是当前页面实测，不代表所有手机的固定边界。

## 修改

从实际状态栏下沿起，标题栏厚度按屏幕宽度的 12% 计算，同时不超过屏幕高度的 8%。当前设备约 y=126..255，贴近实测标题栏。既不写死像素，也不让键盘高度改变范围。OCR 与无障碍共用该比例函数。

标题候选继续选最居中有效文字；显式排除完整的聊天日期时间，保留表情。没有可靠标题时仍标“对方”，不猜联系人。上下文去重规则未改；历史错误记录不回填。

## 验证与限制

VoiceInputTitleTest 8 项、VoiceInputEmptyBoxContextTest 3 项、VoiceInput049Test 21 项通过，assembleDebug 成功，git diff --check 通过。比例测试覆盖 1080×2400、1440×3200、540×1200，以及键盘变化；另覆盖日期不能取代联系人。

这是依据当前竖屏微信页面校准的比例规则，其他厂商、大字体、横屏/分屏仍需实际验证；尚未宣称所有布局通用。手机安装后需要再采集一条新消息验证实际 OCR 姓名。
