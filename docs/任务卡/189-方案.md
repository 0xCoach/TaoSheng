## 文件与职责

- `shared/.../scheduling/PipelineCoordinator.kt`：模式映射、转写/声纹/整理顺序、跳过规则和结果聚合；阶段及时间通过参数注入。
- `transcribe/PipelineScheduler.kt`：安卓执行机会统一入口，复用唯一 PipelineGate；自动入口拿锁后重判、手动/实时撞锁重试、回顾等锁。条件采样与系统设施保留安卓侧。
- `transcribe/AndroidPipeline.kt`：现有 DAO、Runner、声纹稳定锁、进度与余额刷新适配。
- `transcribe/TranscribeScheduler.kt`：从 Worker 分离 WorkManager 请求安排，保留原接口、立即和攒批逻辑。
- `TranscribeWork.kt`：旧类名/包名/输入常量兼容，前台通知和 Worker 结果转换。
- `shared/.../digest/core/DigestOutcome.kt`：Done、NothingToDo、Retryable、NeedsUser 明确结果；取消仍抛 CancellationException，不转成功。
- `DigestRunner.kt`：保留 Boolean 包装；按原顺序抽出缓存核对、在途检查、分段分批，保留请求/事务/重放和技能 finally 顺序。
- `PipelineDiagnostics` 与 `BackgroundRecords`：一轮一行，持久化七天/2000 条，新增阶段耗时、原因与等锁。PipelineTimes 保留范围外调用的兼容入口，非流水线记录分开，不与新轮次记录混写。
