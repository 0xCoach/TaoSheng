# 涛声 0.4.0 · 2026-11-16

后台按时整理、首页搜索与新版本提示

【后台按时整理】
录音运行期间，涛声自己按设定间隔检查并执行转写和整理，不再只靠系统后台任务；亮屏、接上电源、打开应用时也会补一次，录音暂停时用闹钟兜底。主要改善鸿蒙等后台限制较严的手机，鸿蒙真机效果仍待验证。
密钥失效、余额不足时不再每分钟重试，按设定间隔再试，改好设置后自动恢复。
问题记录新增“自动转写/整理记录”，可看出每次由谁触发、各步骤用时和结果。

【华为、荣耀、鸿蒙】
保活设置里增加“应用启动管理改成手动”“休眠时保持网络连接”等项；在卓易通里使用会提示要对卓易通本身设置。系统长时间推迟后台时，首页会提示去设置。

【首页】
新增搜索：按关键词搜原话和整理出的事件，点原话跳到那一刻。
有新版本时首页直接弹出提示，可在面板里下载安装；点“稍后”同一版本 24 小时内不再弹出。

【模型服务】
切换服务商后立即生效，不用重启应用。
移除“使用旧网络实现”开关。

【备份】
更多用户设置会随备份恢复；上次运行时间、重试计数等本机状态不再带到新手机。旧备份包照常可以恢复。

【其他】
“导出问题记录”统一放在“设置 → 高级与诊断”。
足迹推送当天生成失败会自动重试，最多 3 次。
后台流程整理，更多出错情况会写进问题记录。
