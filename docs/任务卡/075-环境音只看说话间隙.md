## Claude 已查到的根因

2. **跳过/影视判定不变**：仍用原来的整段/头中尾窗口和原规则（保护有人说话的段不被误跳过）。
3. 解码只做一次（沿用 073 的共享 PCM），一轮内模型复用；不新增模型下载。
4. 门槛：先沿用卡 061 门槛；若间隙音频上明显误报（例如安静室内被贴“车流”），再按类别用本批数据给出新门槛，写清依据。
