# 卡 202：夜里第一版交付说明

本地分支 `codex/202-night`；数据库 39 → 40，一次迁移已预建卡 203 的标签、梦、个人判断器、周报和提醒表。未操作手机、未推送、未合并 main、未发版。

## 实现

- `:shared/night`：进入/确认/取消/退出、电量分档、运动门槛、睡眠估算、醒来合并、梦话归属条件、用户时间修正、入睡延迟中位数、可信度、早上那句话、昨晚 markdown/JSON、节奏判定、候选合并、最多 30 秒的有界旁路队列、Room 表及仓库。
- `app/night`：随录音服务注册屏幕广播及加速度传感器；复用手机录音 VAD 的全部帧，不另开麦克风。窗口按 16 kHz 样本数推进，录音缺口重置样本时钟。推理、编码、数据库操作在消费者执行，录音生产者只组窗和非阻塞投递。积压丢最老窗口并计诊断。
- 和白天共用 `EnvSoundModel`、同一串行推理入口；模型 batch 改为引用计数，避免白天结束批次时释放夜里持有的模型。
- 实时识别、低电量候选暂存和充电/空闲补识别，Opus 沿用现有编码器及 AAC 回退；鼾声代表片段、咳嗽上下文、压缩的 527 类分数和节奏特征落库。梦话引用现有人声段，转写和声纹更新由维护任务补入。
- “是”长期保存；“不是”去统计并持久排队删音频，保留反馈特征；七天过期只删未确认音频。整夜删除、按时间段隐私删除接现有清理事务；正在录音的旁路检测删除，设置隐私时间下限，避免沿用已删区间重新创建夜晚。
- 设置进备份；数据库快照包含夜里表，只把确认音频加入备份白名单，恢复使用相对路径。没有添加夜里音频推送字段。
- 每日线索在“今天概览”前加入“昨晚”；时间由 `ZoneHistory` 生成带偏移的字符串。推送关闭或历史隐私删除会重写封存文档中的夜里节。无夜里数据时旧序列化不增加字段。
- 录音通知加入“夜里记录中”，问题记录加入最近夜晚的状态、各档时长、推理、丢窗、电量、候选容量和反馈计数。

`NightContract.kt` 仅增加 `@Serializable`，用于共用层持久化；现有签名、字段及默认值没有修改。界面仍由 Claude 接 `AppGraph.night`，本次没有改 `ui/` 和 `MainActivity.kt`。

## 门槛

- 模型：16 kHz 单声道，2 秒不重叠，int8、2 线程；Snoring≥0.10、Cough≥0.50，来源原评测报告。
- 节奏：0.5 秒线性 RMS 包络，最多 30 秒，2～6 秒滞后去均值归一化相关≥0.7，标准差/均值≥0.3；三个阳性窗口启动，30 秒无阳性结束。结果不加入 Breathing。
- 粗筛：高于滚动背景≥6 dB，前后各 2 秒，单段≤60 秒，候选≤60 MiB。
- 运动：角度<5°且方差<0.02 (m/s²)² 为静止；角度>30°或方差>0.8持续两秒为拿起，其余为轻微晃动。5 Hz、约30秒批量；这些是经验初值。
- 时间：静止/没人声十分钟、暂定后二十分钟确认；亮屏两分钟或拿起取消。一次亮屏超过一分钟但不足两分钟后，重新等完整二十分钟确认；不永久卡在暂定。睡眠安静十五分钟、前后两分钟判断夜间说话、醒来五分钟合并、不足两分钟不计次数。
- 背景可信度：中位背景>-40 dBFS记较吵，>-25 dBFS仅供参考；中断累计≥30分钟、低电仅记时间、频繁晃动或候选满额降级。噪声及运动门槛需床头真机校准。
- 反馈：把握<0.8的事件中最多三段；把握由分数距门槛的归一化距离×0.7与相关值×0.3组成，不是概率。

## 验证与真机边界

`check_shared.py`、限定过滤的 `:shared:check`、夜里/相关线索与 schema 单测、`:app:assembleDebug` 已通过；iOS shared/devices 真机与模拟器编译检查已通过。新增测试为共用规则 8 项、安卓迁移/删除/压缩/备份 4 项；另外跑相关 DayThread200 和 Index183Comparator，不跑全量。schema 40 已导出，index183 差异白名单已更新。具体测试结果保存在本卡证据目录。

没有宣称真机可用、连续整夜准确率或耗电通过。负责人需要检查：床头传感器门槛、低声漏检、多人归属、停录/占麦/被杀、整夜耗电、不同设备 Opus/AAC 编码回退和后台调度时机。

## 问问现状

查阅 `AskTools`、`AskContext`、`AskPrefetch` 和共用 Ask 核心后，目前问问直接查询事件、原话、条目等数据库内容，没有读取 DayThread 每日线索的同一入口。因此本卡没有硬加一个新工具，也不能宣称“这周平均几点睡”已可回答。建议后续由 Claude 定问问的日期范围上下文入口，再接 NightSummary/昨晚文字；本卡已提供可复用的数据与纯文字构造器。
