# 096：模块复制面板视觉调整

## 修改

- 按用户确认方案重新布局选择面板：暖色内容卡片、整块点选，取消左侧方形复选框；选中时淡橙底、细边框、右上角圆形勾。
- 顶部“按模块 / 自由选字”胶囊切换；全选、清空为小文字按钮。底部固定已选计数和复制按钮，中间内容独立滚动。
- 选中背景和小勾轻量过渡，标记固定占位，文字不随选中移动。卡片保留可访问性多选语义，按钮提供真实禁用状态。
- 模块选择与自由选字保留各自状态及滚动位置；复制仍按原文顺序，全文复制、字段格式、日报/周报过滤规则未改变。
- 用户明确授权 UI 修改；未改 Contract 或生成/问答逻辑。
