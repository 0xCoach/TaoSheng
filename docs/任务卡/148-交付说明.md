# 卡 148 交付说明：首页、设置、专题页改版与暗色重做（界面）

完成日期：2026-11-12。分支 `claude/148-ui-polish`（已合入卡 147 底层 `codex/147-quick-backend`）。发布为 0.3.0-preview.2（versionCode 67）。

## 做了什么

- **暗色重做**（`ui/theme/Theme.kt`）：纯黑底、卡片 #1C1C1E + 白 7% 细边、面板 #2C2C2E；文字白 92/60/48%；新增 `elevated`（面板）、`fill`（按钮/输入框填充，夜间白 12%）、`hairline`（卡片细边）。94 处把页面底色当填充色的地方改用 `fill`。技能色、分类色各加暗色版。亮色三级文字加深到 #8A847C。
- **首页主卡**（新文件 `ui/today/OverviewCard.kt`）：状态行即控制条（「◉ 专题」+ 暂停键，异常状态只留一个按钮），声波在状态与按钮之间、两头淡出；专题进行中主卡变身（标题+计时、★ / 暂停 / 结束）；统计数字大单位小、间距相等，待确认可点；模型按钮显示服务商名并跳模型页；看前几天时回顾样式；亮色渐变压深（白字对比度 1.8→2.5～4.5）；暂停底部提示条「改时长 / 撤销」（`QuickPause.kt`）；数字滚动、轻震。首页标题旁主题开关去掉。
- **时间线**：时间默认灰色，标星和结束不到 30 分钟的用橙色；技能卡与事件同字号，「技能卡」胶囊 + 右侧图标。
- **设置首页**（新文件 `ui/settings/SettingsHome.kt`、`SettingsIcons.kt`）：体检卡（正常一行、有问题列出+去处理）、搜索、彩色图标按组同色系、只亮问题点、外观三段切换、外接设备一行、「高级与诊断」；备份没准备好整组不显示。
- **二级页**：录音与后台去掉旧大标题和主题开关，设备改一行入口，统计/守护/麦克风占用/导出移入新「高级与诊断」页；新增「外接设备」页；原话与转写设置平铺、热词并入；模型页改名「模型与整理时间」；声纹页底部给底栏留空；上边距统一 8。
- **专题页**（`ui/topic/TopicUi.kt`）：头部、主角区（进行中大计时+三按钮 / 完成纪要大卡 / 预约 / 失败重试 / 整理中）、时间轴、相关、调整（一组类型+名字）、操作按钮一排（剪掉一段原地展开、重新生成、取消点两次）。按负责人要求不做三级面板。
- **快捷入口**：长按快捷开关（专题 → 专题面板或开始专题；聆听 → 录音与后台）；记住上次暂停时长与专题类型。

## 随改随搬（为 iOS）
- `home/HomeRules.kt`：时长拆数字单位、主卡按钮选择、模型按钮文字、时间线是否用橙、暂停文字。
- `topic/TopicTimeline.kt`：时间轴分段、重点位置、计时文字。
- `ui/settings/SettingsIcons.kt`：图标为纯 SVG 路径字符串，iOS 可照搬。
