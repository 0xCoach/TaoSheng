# 019 问问历史对话

## 完成

按用户明确批准的方案，扩展 AskContract 并修改 UI。顶部增加历史对话和新对话；历史页沿用圆角卡片、浅色输入框、胶囊按钮，提供标题、末句摘要、时间、今天/昨天/更早分组，点击恢复聊天。列表按最近消息时间倒序，30 条一批，上滑加载；搜索标题和消息正文。更多菜单支持改名、删除前确认。

当前会话 ID 存在专用 SharedPreferences，重启恢复上次打开的对话。新对话直到首次发送才建表记录，旧的空对话不会列出。默认长期保留，不自动按数量或日期删除。删除仅级联删除聊天消息，录音、原话、事件不受影响。历史加载不调用模型；模型上下文仍只取最近 12 条消息。

切换/删除当前会话先取消并保存正在生成的回答，防止串话；改名和删除其他对话不会中断当前回答。
