睡眠声音能放大细看，更新一点就装，豆包可用 Agent Plan

【昨晚的声音图能放大了】
双指张开或双击就能放大，最细到 10 分钟一屏、每根柱 5 秒；放大后上面有整夜小图和取景框，拖动或点一下换位置。按住图左右滑，能看到几点几分几秒、比背景响多少分贝、是什么声音。右上角“最响”一点就跳到当晚最响的那一下，每晚多留最响的 3 段（约 15 秒）可以回听。

【夜里的声音和动静：按类别收起】
要你确认的放最上面；鼾声、鼾声中断、咳嗽、梦话、最响、醒来各收成一行，写着次数和时长，点开再看。播放键在左边，“是 / 不是”在右边，不容易点错；点哪一条，上面的图就移到哪里。

【鼾声中断：不再重复，能听能确认】
同一次鼾声中断以前会被记成好几条，现在一次只记一条，旧的会自动合并。每次中断都存一段录音（安静前 5 秒到鼾声回来后 8 秒），点时间就能听，并可点“是 / 不是”。确认过的夜里录音保留 90 天，没确认的 7 天。

【更新：准备好再提醒，点一下就装】
发现新版本后，在 WiFi 下（或差异包较小时）先在后台下载、备份好，再通知“已准备好，点一下安装”。6 小时内备份过就不再重复备份；系统把安装秒拒时会自动再试一次并弹出确认，不用连点好几次。

【豆包可用火山方舟 Agent Plan】
语音转写 → 豆包 → 接入方式，选“Agent Plan”并填订阅页的专属 API Key，就用套餐里的豆包语音识别。两种 Key 分开保存；Agent Plan 失败不会改走按量计费，实际扣费以方舟控制台为准。

【坚果云不再被频繁推送拖累】
同步文件夹的摘要以前每出一张卡就推一次，现在和整理结果一起按你设的间隔合并推；没有变化时不连坚果云；被限流后等 10 分钟再续传。

【备份更快】
导入旧通话录音后备份里有几百天，以前每次逐天检查很慢，现在一次列清。

【其他】
· 通话录音点“转写”失败时写清原因（需要重新授权、格式不支持等），能重试的有“重试”。
· “原声保留天数”和“录音包导出”挪到 设置 → 录音管理 → 录音存放。
· 备份页写成“记录跨 N 天（最早某年某月）”；删除导入录音时说明手机里的原录音不会被删。
· 问题记录从 1 MB 多减到约 300 KB，备份成功也记下用时。

升级提醒：本版不改数据库，可从 0.5.1、0.5.2 直接升级；从 0.5.0 及更早升级会升级数据库，不能直接装回旧版。
