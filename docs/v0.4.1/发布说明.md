# 涛声 0.4.1 · 2026-11-16

长录音断点续转、搜索全部内容、复制给智能体

【本地转写断点续转】
本地转写中途被系统打断（切到后台被冻结、进程被结束）时，下次从断开的地方接着转，已经转好的部分不再重做。同一段录音连续被打断两次，改到亮屏或充电时再转，其余时候先转别的段。被打断不算转写失败，不占用重试次数。主要改善鸿蒙等手机上一分钟以上的长录音，鸿蒙真机效果仍待验证。

【搜索】
搜索从原话、事件扩展到待办、记忆、寻物、专题、回顾和问问，所有日期都能搜。结果按类别分开，每类单独计数；可按最近几天或自选日期筛选，滑到底自动加载更早的。待办页、记忆页也加了搜索按钮。

【给智能体读记忆】
设置 → 推送 → 同步文件夹 新增“复制给智能体”：复制一段话粘贴给 Claude Code、Codex 等能运行命令的智能体，它就能只读你的涛声记忆库。文件夹里的 README 补充了给智能体的读取须知。

【其他】
小米、魅族等手机在涛声录音时，语音助手的唤醒词可能没反应：首页提示一次，设置 → 录音与后台 里有说明，可改用长按电源键唤醒。
原话与转写页滑远后，右侧出现回到顶部按钮。
外放时跳过的片段会显示原声还保留几天。

升级提醒：本版不改数据库，可从 0.4.0、0.3.x 直接升级。
