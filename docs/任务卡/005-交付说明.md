# 005 交付说明

## 做了什么

新增纯 JVM JUnit4 测试，不使用 Robolectric、不增加依赖，时间换算显式使用 `Asia/Shanghai`。

- `DigestPromptTest`：15 项测试，覆盖日历 22 行及日期标签、原话编号与录音分隔、说话人优先级和换行替换；JSON 事件映射及首句开始/最大结束时间；越界、倒置、排序和重叠范围；人物过滤、情绪强度；提取项归属、最近事件、类别及内容过滤、媒体/旁人过滤、非待办 kind；代码围栏、格式错误、截止时间。
- `DigestRunnerTest`：3 项测试，覆盖空输入、10 分钟边界前后、段内最大结束时间及拆段后的继续合并。
- 未修改 `app/src/main`、界面、约定文件或构建配置。`CARD.md` 不纳入提交。

## 怎么验证的

执行任务卡指定命令：

```sh
JAVA_HOME=/opt/homebrew/opt/openjdk@21 ./gradlew testDebugUnitTest --tests 'app.resound.digest.*'
```

首次尝试被沙箱拦截于 Gradle 缓存锁文件；经本次提权审批后执行成功进入测试。仅执行 digest 包测试，没有运行全量测试或重复回归。

Gradle 实际测试构建耗时 6 秒，共 18 项：16 项通过、2 项失败。失败是部分越界事件处理与任务卡不符，不是编译问题。失败用例保留原始期望，未忽略或反向断言来使构建变绿。详见 [005-测试发现.md](005-测试发现.md)。

本地 HTML 报告：`app/build/reports/tests/testDebugUnitTest/index.html`（构建产物不提交）。

## 真机需要注意什么

本卡仅验证纯逻辑，无需真机即可复现上述结果。未验证真实模型响应、网络、数据库写入、后台运行及界面展示；这些不属于本卡覆盖范围。

## 遗留问题

负责人需确认部分越界事件应丢弃还是裁剪。按当前任务卡期望保留的两项测试会使指定测试命令失败；生产代码按要求未修复。
