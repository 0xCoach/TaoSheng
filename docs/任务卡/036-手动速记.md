# 卡 036 · 手动速记

按一下，说一段话，出一张速记卡（借鉴 DayoTag 的“手动速记”）。后端 + 技能本卡做；界面（今天页按钮、录音中的提示条）Claude 做。

**约定**：`capture/QuickNoteContract.kt`（新）、`skills/SkillContract.kt` 新增 `runWindow`。签名不要改。
**分支 / 工作树**：`codex/036-quick-note`，`~/Developer/resound-codex-036`。

## 一、已定方案

1. **开始 / 结束**：`toggle()` 开始；结束条件任一：再按一下、开始后连续安静 ≥ 4 秒（沿用现有人声检测）、满 2 分钟。录音本身不另开麦克风——录音服务一直在听，速记只是给这段时间打上标记，并**强制把这段切成独立的录音段**（开始和结束各切一刀，不等普通的静音切段），这样转写和整理只处理这一段。
   - 录音没开 / 已暂停 / 麦克风被占用：返回失败原因（“回响没在录音，先打开录音”等），不偷偷开麦。
   - 开始时轻震一下；常驻通知文字变成“正在速记…（再按一下结束）”。
2. **之后的处理**：这一段**插队优先转写**（转写队列里排到最前，不等 15 分钟一轮）；转写完成后调用 `skills.runWindow("quick_note", start, end)` 出卡；成功后发本地通知“速记已记下：<标题>”，点开 `resound://card?open=card&id=<id>`；`state.lastCardId` 更新。失败（没说话、网络、没密钥）→ `lastError` 写人话原因，并发一条通知说明，录音照常留在普通流程里。
   - 这段原话照常进入时间线整理（不重复出事件也没关系，整理逻辑不动）。
3. **入口**（后端负责的部分）：
   - 常驻通知加一个“速记”按钮（放在“暂停 30 分钟”前面），速记中变成“结束速记”。
   - 新的控制中心开关 `QuickNoteTileService`“回响速记”：点一下开始/结束；速记中显示为激活状态。
   - App 内按钮由 Claude 做，调用 `AppGraph.quickNote.toggle()`。
4. **技能 `quick_note`**（写进 `assets/skills/quick_note/`）：名字“手动速记”，icon `mic`，触发 `Manual`，scope `SinceLastRun` 不用（走 runWindow），只用这段原话（所有人，带原话），每天最多 20 张，推送默认关（出卡通知由速记流程自己发）。
   - 字段：`summary` 一句话总结（Text，必填）、`points` 补充要点（Bullets）、`todos` 里面提到的待办（Checklist）、`original` 原话整理（Paragraph：把口语整理成通顺的文字，像输入法那样，保留原意不扩写）。
   - 要求要点：这是用户主动按键记下的一段话，通常是灵感、待办或备忘；结论先行；原话整理去掉嗯啊重复，不加原文没有的内容；空内容（只有噪音或几个字）不出卡，原因写“没听到要记的内容”。
5. **`runWindow`**：在 `LocalSkillRepository` 实现：取 [from, to] 内的原话作为输入（不受每日自动次数上限，记一次运行），按普通规则出卡、存库，entity 用开始时间，不推送。
6. **装配**：`AppGraph.quickNote` + `isQuickNoteReady`。

## 二、必测（6～10 个）

1. toggle 开始 / 再按结束；安静 4 秒自动结束；满 2 分钟结束；录音没开时返回失败。
2. 速记段被切成独立录音段，并排到转写队列最前。
3. 转写完成后调用 runWindow，出卡并更新 lastCardId；没说话时不出卡、lastError 有原因。
4. runWindow 只取窗口内原话。
