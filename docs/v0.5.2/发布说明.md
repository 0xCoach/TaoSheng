# 涛声 0.5.2 · 2026-11-18

修复备份，“昨晚”早上就能推送

【本机备份修复】
本机备份文件夹里旧数据较多时，备份偶尔会失败并误报“备份文件夹的授权已失效”，“立即备份”也会一直卡住。现在读取备份文件夹一次就能拿全文件信息，遇到刚被清理的旧文件会跳过，不再整次失败。

【夜间睡眠也进备份】
0.5.1 的夜里记录（睡眠时间、鼾声、标签、周报等）之前没有进入本机和云端备份，本版补上。

【坚果云备份更稳】
坚果云免费账号有请求次数限制，和推送共用时容易被限流。现在被限流会按坚果云要求的时间等一会儿再试，不再直接失败；备份时向坚果云发的请求也少了很多。提示分清“限流”和“服务器出错”。

【“昨晚”早上就推】
夜里整理好后，“昨晚”一节马上写进当天每日文档的开头（坚果云同步文件夹、Notion、自定义接口），不用再等到第二天凌晨。

升级提醒：本版不改数据库，可从 0.5.1 直接升级；从 0.5.0 及更早升级会升级数据库，不能直接装回旧版。
