# 周报主题化与手机安装

用户已要求修改、测试并安装到连接手机；本次只安装预览版，不发布更新渠道。

## 改动

- 内置周报版本从 2 升至 3，新生成内容分为“这周一句话 / 本周进展 / 还挂着的事 / 下周留意”。同一事项按主题合并，进展最多三个重点，用户标星信息融入对应主题，未完成与已完成分开。
- 保留用户自定义提示词，不自动覆盖。旧报告正文不重新生成，不改写已保存事实。
- 彻底移除周报逐事件环境明细和展开入口，读取旧卡片时也去除旧动态环境字段。
- 页尾用“本周声音印象”标签，实际出现过的声音去重、最多三个，优先特别声音；没有记录就隐藏。不推断时长、地点、情绪，不额外请求模型。
- 保留日报橙色、周报紫色及此前寻物共用整理请求的优化。
- 预览安装包版本：0.2.15-preview.4，versionCode 43。数据库 schema 未改。

## 验证

- 5 项针对性测试通过：ReportPresentationTest 1、环境呈现与设置开关 1、ReviewPreparation053Test 3。构建总耗时 6m31s，未跑全量回归。
- 浅/深色实际 Compose 渲染已检查；使用内置新版周报字段绘制，验证旧逐事件环境字段不显示、没有展开入口，声音标签正常。
- 预览 APK 通过 ZIP 完整性及 apksigner 签名验证，新旧签名一致。
- `adb install -r` 返回 Success；手机读回 versionName=0.2.15-preview.4、versionCode=43。首次安装时间仍为 2026-10-28 20:12:46，未执行卸载或清除数据。
- 安装前 CaptureService 为前台运行。安装后已启动 MainActivity，但手机锁屏（showing=true）；页面及录音恢复检查等待用户解锁。此处不将进程存在当作页面验收通过。
- 安装包：app/build/outputs/apk/release/app-release.apk。未推送 Git、未发布更新渠道。

## 生效范围

旧周报立即移除逐事件环境附录，但正文不自动改写。默认技能新生成的周报按四个栏目组织；已保存的自定义周报提示词仍保持用户原设置。
