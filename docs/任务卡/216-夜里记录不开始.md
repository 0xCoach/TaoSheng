# 卡 216：#59 魅族手机夜里记录一直不开始（Claude 直接做）

## 判断
夜里开始的前提是“在时段内 + 屏幕已关”。屏幕状态原来只靠系统亮屏/熄屏广播；涛声启动时屏幕亮着、之后系统（魅族等）又不把熄屏广播送到时，程序一直以为屏幕亮着：不注册加速度计、不进入暂定、不报错。与反馈完全吻合（零记录、无暂定取消、无 night/ 失败、传感器从未注册、录音转写正常）。反馈者提出的“主循环被 Error 打断”会导致闪退（无异常处理器），与“无闪退”不符，基本排除；恢复循环在库里无夜间记录时不会出错。

## 改法
- 每次检查（10 秒）直接问 `PowerManager.isInteractive` 兜底屏幕状态；广播正常时不影响。
- 加速度计不存在或注册被拒：不标记已注册、记 `night/sensor`，下次再试；没有传感器也按“静止”照常记录。
- 主循环 `runPulse` 改为接住所有 Throwable 并记录；启动恢复出错只记 `night/recover`，不影响主循环。
- “问题记录”夜里一段加实时状态：上次检查时间、屏幕开关、所在时段、应开/已注册传感器、这一夜状态、档位、靠查询补到熄屏的次数、最近错误。

## 验证
编译通过；夜里相关 13 个已有用例通过。真机：魅族用户装包后睡一夜，或导出问题记录看“夜里实时状态”里“靠查询补到熄屏”次数。
