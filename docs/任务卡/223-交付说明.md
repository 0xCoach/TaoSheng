# 卡 223 交付说明：三项默认设置（转写方式、备份、录音输入）

## 起因
从"什么都不设置的新手也能用好"出发，重新检查默认值。原则：不意外花钱、不悄悄外发隐私、不明显费电占空间，在此前提下效果最好。

## 1. 默认转写方式：本机识别
- 原来代码默认值是"豆包"（要密钥）。正常走完开箱向导会切到本机，但在第一页点"换手机了？从备份恢复"会跳过这一步，没恢复的话就停在没密钥的豆包上，录音一直等着转写。
- 现在：没存过转写方式的默认本机识别；**填过豆包密钥的老用户仍是豆包**（`encryptedKey` / `planEncryptedKey` 存在）。第一次决定后存下。
- 首页"继续完善"清单：开始聆听后如果还没准备本机转写，自动准备一次（和向导第 2 步一样）；用流量时不自动下，按钮照常可点。

## 2. 默认备份：Download（下载）/TaoSheng
- 新装的、以及**从没设过任何备份**（云端没填、本机没选文件夹）的老用户：自动存到 `Download/TaoSheng/<yyyyMMdd-HHmm-4位随机码>/`，每晚一次、留 7 份。设过备份的一律不动；只做一次，用户关掉后不再打开。
- 子文件夹：每次安装一个，用日期命名好认；随机码防止一分钟内卸载重装撞名（安卓不让新安装改旧安装的文件）。
- 卡 123 已选"下载/备份"的安装继续用原位置（`downloads-backup-installation` 存在）。
- 第一次备份成功后首页提示一次：在哪、能防什么（卸载重装、清数据）、不能防什么（丢手机、坏手机），建议再开云端。
- **重装后的恢复**：安卓不让新安装读旧安装存在 Download 里的文件，App 里列表为空（卡 123 已知）。备份页新增"找回以前的备份"：系统选择器直接打开 Download/TaoSheng，选日期最新的文件夹，再点"从本机文件夹恢复全部"。
- 备份不加密（口令只能用户自己设，App 替设了重装后解不开）。文案统一成"Download（下载）/…"。

## 3. 录音输入：一个"自动" + 顺序列表
- 原来：手机麦克风（默认）/ 自动（USB、有线）/ 自动（含蓝牙，所有蓝牙都抢）/ 指定某个设备。
- 现在：**自动**（新装默认）/ **只用手机麦克风** / 只用某台专用录音设备（录音卡，行为不变）。
- 自动时列表"从上往下，用第一个开着又接着的"：默认 USB、有线、其他外接麦开着；蓝牙按设备逐个开关，新连上的加到末尾、默认关；↑ 和上一行换位置；手机麦克风永远在最后。每行显示"✓ 正在用 / 接着 / 没接着"。
- 打开蓝牙那一行时申请"附近设备"权限。"放视频音乐自动让出蓝牙麦"不变。
- 迁移：旧"自动"→ 自动；旧"自动（含蓝牙）"→ 自动且新连上的蓝牙默认开；指定的普通麦克风 → 自动、它排第一；指定的专用设备不变；没选过的老用户保持手机麦克风。
- 行为变化：同时接着 USB 和有线时，原来用最后接上的，现在按列表顺序（默认 USB 在前）。
