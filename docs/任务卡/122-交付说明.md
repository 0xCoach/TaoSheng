# 卡 122 交付说明

## 改动

- 验签统一为系统 `KeyFactory("EC")`、`Signature("SHA256withECDSA")`，限制 P-256 曲线。公钥格式为 X.509 SubjectPublicKeyInfo DER 的 hex；签名是 DER 二进制，长度可变，下载上限同步改为 72 字节。
- 删除 `bcprov-jdk18on:1.81` 及仅为它增加的 OSGi MANIFEST 排除项；保留原有 JNI 打包配置。
- 签名脚本改用 `ec.SECP256R1()` 对应的 P-256 密钥和 SHA-256，输出 DER 签名、SPKI DER hex 公钥；只读取已有 PEM/PKCS8 私钥，不再自动创建。仍拒绝符号链接、非 600 权限、其他算法/曲线及覆盖不同公钥。
- 删除 103 行 `BootstrapCardParser.kt`，说明卡只由 `devices/core/CardParser` 解析。公开 `parse` 仍拒绝高于当前 App 的卡；内部目录入口共用同一解析实现，先校验整表，再筛选兼容卡，保留“未来版本卡不阻止其他卡更新”的行为。JSON 表封装的三个小辅助函数移到加载器私有范围。
- 声云 `FileFrames` 删除自写 CRC、帧头/长度/校验字段编码与载荷拆包，改为 `FrameCodec`。发送序号交给编码器递增。文件协议原有小端行为保持；接收保留不按音频序号去重的行为，避免改变文件同步语义。
- 仅保留声云文件命令参数及 BLE 半帧/多帧缓存：按 LEN 切成完整包，再由 `FrameCodec.accept` 校验和拆包。卡 118 的实时通道端序试探实现未改。
- 未改 `ui/`、`MainActivity.kt`、任何契约文件、`audio/`、`capture/`、版本号；未修改蓝牙连接逻辑。

## 负责人生成正式私钥、公钥和签名

**本次没有生成、读取或写入正式私钥，也没有把测试公钥当作正式信任根。** 原仓库没有 `assets/device-cards-public-key.hex`；须由 Claude 在主会话执行以下初始化，再将正式公钥随 APK 发布。旧 Ed25519 公钥和签名不可继续使用。

只执行一次（Python 环境需安装 `cryptography`；已存在任何密钥时会拒绝覆盖）：

```sh
python3 - <<'PY'
import os
from pathlib import Path
from cryptography.hazmat.primitives import serialization
from cryptography.hazmat.primitives.asymmetric import ec

path = Path.home() / '.config/taosheng/cards-signing.key'
path.parent.mkdir(parents=True, exist_ok=True, mode=0o700)
# O_EXCL 同时拒绝已有文件及符号链接，不覆盖旧钥。
fd = os.open(path, os.O_WRONLY | os.O_CREAT | os.O_EXCL, 0o600)
with os.fdopen(fd, 'wb') as output:
    key = ec.generate_private_key(ec.SECP256R1())
    output.write(key.private_bytes(serialization.Encoding.PEM,
        serialization.PrivateFormat.PKCS8, serialization.NoEncryption()))
    output.flush()
    os.fsync(output.fileno())
print('已创建 P-256 私钥，请离线备份。')
PY

python3 scripts/sign_device_cards.py device-cards.json \
  --public-key-out app/src/main/assets/device-cards-public-key.hex
```

- 若已有旧密钥，由负责人先确认并备份、协调换钥，不能覆盖或直接复用 Ed25519 密钥。
- 只提交公钥和 `device-cards.json.sig`，私钥留在原指定位置、权限 600 并离线备份。此后运行 `python3 scripts/sign_device_cards.py device-cards.json` 签名。
- 修改表内容时递增表版本，修改卡内容时也递增卡版本；签名后不再格式化文件。JSON 与 `.sig` 同步发布。本次没有推送或上传。
- 缺少正式公钥时仍拒绝远程表；旧算法缓存会验签失败并回退包内卡，负责人发布前需重新签署参数表并构建带正式公钥的 APK。
