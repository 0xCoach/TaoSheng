## 对三个问题的直接回答

**1. FSL-1.1-MIT 范围内的源码还有多少被保留/修改使用？**
**绝大多数。** 全树 3468 文件：2876 个与 v0.4.0 **逐字节相同**（82.9%）、488 个修改（14.1%）、104 个新增（3.0%）。源码口径（app+shared+devices，1089 个 .kt/.java）：859 同（78.9%）+ 161 改（14.8%）+ 69 新增（6.3%）。
用户点名的 Pipeline 调度/RecordSearch/HomeNotices/FailureNotes 等"未专项重写"文件，经 blob SHA 核实**逐字节未改**——"约 20 个增量功能文件"的记录属实。

**2. 自主模块是否完整覆盖上游功能？**
上游 29 个功能区：**26 FULL_PARITY + 3 IMPROVED/CHANGED + 0 MISSING + 0 REGRESSION**。新增能力（M1/M2/M2+/R4）15 项全部有代码+测试证据。功能等价成立；但**这不等于源码自主化**——新增模块全部构建在上游衍生代码之上。

**3. 还有哪些风险？**
- 源码自主化：未发生。SoundSound = 上游 FSL 代码 + 合规声明 + ~6% 自主模块的**衍生作品**。商用前需独立法律审查；不能靠改写率宣称许可清零。
- 数据/权限：MCP 越权、备份覆盖、崩溃恢复等 R4 问题已修并有负向测试。
- 未验证项：见下方 D/NOT_TESTED。
