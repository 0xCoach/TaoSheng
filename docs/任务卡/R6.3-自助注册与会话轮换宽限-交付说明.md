# R6.3 自助注册与 refresh 轮换宽限 — 交付说明

## 背景

两个用户报告的痛点，同一次交付：

1. **反复点击"开始聆听/整理/总结"无反应无报错**：本地授权失效后，"归属暂不"的 24h 冷却在登出态也生效，受保护入口被静默吞掉（底层修复见提交 `aacaa89c`，本次在此基础上补服务端侧根因之一）。
2. **为什么会突然失效**：服务端 refresh token 每次刷新都轮换；一旦某次刷新响应在回传途中丢失，手机里的旧票下次再刷就被拒 → 本地会话被清。审计显示同一台 PGU110 在 2026-11-19 晚反复新建会话，与轮换失步吻合。其他可能：30 天未联网刷新过期、会话被撤销、账号停用。
3. **没有自助注册**：`/console/api/users` 只有管理台能建号，用户注册全靠人工开号。

## 做了什么

### 服务端（Cloudflare Worker + D1，已部署 version `3b73b7a3`）

- **`POST /auth/register`**（`server/src/worker.js`）：用户名 3~24 位 `[A-Za-z0-9_-]`、密码 8~128 位；注册即 `active` + `CAPS_DEFAULT`（Free 档：每月 1800 分钟转写 + 官方 AI 100 点，点数由既有 Free 周期发放逻辑覆盖）；返回与登录同构的 `account + access/refresh + license`，客户端按登录同一路径落会话。`OPEN_REGISTRATION` 环境开关可随时关闸。
- **风控**：`login_attempts` 表复用，键 `reg|<CF-IP>`，默认每 IP 每小时 5 个（`REGISTER_RATE_LIMIT=5` / `REGISTER_RATE_WINDOW_SECONDS=3600`，可在 wrangler.toml 调）。重复用户名 409、参数非法 400、超频 429，全部落 `audit_log`（不记密码）。
- **refresh 轮换宽限**（迁移 `0005_register_and_refresh_grace.sql`，已应用）：`sessions` 新增 `prev_refresh_hash` + `prev_valid_until`；每次轮换把上一张票的散列保留 `REFRESH_GRACE_SECONDS=60` 秒。旧票宽限期内重放仍走正常轮换发新票（响应丢失重发安全），宽限外照旧 401。不削弱撤销：`revoked_at` 检查照旧、宽限只救"已轮换但未失效"的上一张票。

### Android

- `AuthApi.register()` + `AuthGate.register()/RegisterOutcome`（409→UsernameTaken、429→RateLimited、403→Closed、400→Invalid）。
- 登录面板 `LoginSheet` 顶部加「登录｜注册」页签：注册页含账号/密码/确认密码三栏、两次密码一致性校验、错误文案中文化；**注册成功直接落会话并 `afterAuthSuccess()` 回放被拦动作**（点"开始聆听"→注册→直接开录）。登录页签与激活码路径原样保留。
- **会话失效全局主动提示**（补 `aacaa89c` 的剩余半边）：`AuthGate.expireSession` 统一处理"服务端判会话死亡"（refresh 401-403、checkStatus 401-403）——清会话 + 停敏感任务 + **立即置 `loginRequested`（App 在前台直接弹登录面板）** + 触发 `onSessionExpired` 回调；`ResoundApp` 把它挂到 `LocalNotifier` 新通道 `auth-expired` 发系统通知（后台失效也能看到，点开 App 登录面板已在等）。不再出现"会话悄悄没了、点什么都没反应"。

## 验证

- **服务端单测** `membership-test.mjs`：**35/35 PASS**——注册发会话+凭证、重名 409、短名/短密码 400、注册即 Free 1800 分钟、轮换发新票、宽限内旧票重放成功、更旧票被拒、同 IP 第 6 个注册 429；**生命周期回归 L1-L9**：注册 license 仅基础 6 能力 → 授 Pro 后 license 含 pro 能力+pro_until、membership 切 Pro → 到期回 Free 基础能力+1800 分钟 → 停用 refresh/login 均 403 → 恢复可登录。
- `official-ai-test.mjs`：**37/37 PASS**——新增「Pro 到期后点数回 Free 档（每月 100）」。
- **管理台修复**：aioff 段外层模板字面量里 `\'` 只发出 `'`，导致页面内联脚本 `missing ) after argument list`、登录按钮失效（`login is not a function`）。改 `\\'` 发出 `\'`，部署 `a056a4ce`，线上抓取脚本 `node --check` 通过。
- shim 修复：`SELECT expires_at ... capability='pro'`（worker `effectiveProUntil` 查询）两测试文件缺 pattern，被 try/catch 吞成 pro_until=null——补齐后 license pro_until 断言生效。
- **线上冒烟**（自定义域 `soundsound.gdfactory.cn`）：注册→拿到 account/session/license ✓；刷新轮换 ✓；**宽限内重放旧票仍发新票** ✓；>60s 后重放正确 401 ✓。
- **Android**：`AuthRegisterTest` 3/3（409/429/400 映射）；`AuthGatePromptTest` 新增失效主动提示回归（`expireSession` → 清会话 + 弹登录请求 + 通知回调；SecretStore 依赖 AndroidKeyStore 无法单测注入 token，401 链路在服务端测试覆盖）；auth 包全部既有测试回归通过；`assembleDebug` 绿。
- **环境坑记录**：仓库在中文路径下（`声声不息`）时 JDK21 的 Gradle worker argfile 无法加载测试类（全部 ClassNotFound）；一律走 `D:\ts-link` junction 路径跑 Gradle——本卡验证均在此路径完成。

## 真机验收点（待负责人在小米 14 Pro 实测）

1. 登录面板 →「注册」页签 → 新账号注册 → 注册成功直接回到被拦动作（如"开始聆听"）。
2. 注册后设置页「账号与会员」显示 Free + 每月 1800 分钟。
3. 授权过期点受保护动作弹登录（非归属确认），取消登录后**再点仍弹**（不复发旧 bug）。
3b. **会话被服务端判死时**：前台应立即弹登录面板（带"登录授权已过期"原因），后台应收到「登录授权已失效」系统通知，点开 App 登录面板已在等。
4. 长用 1~2 天观察是否还有"会话莫名消失"（宽限应消除丢包型误登出；30 天未刷新/被撤销仍会登出，属预期）。
