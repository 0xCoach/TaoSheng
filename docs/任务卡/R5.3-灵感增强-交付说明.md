## 数据改动（DB 42→43，幂等迁移）

- `idea_entries`：轨迹表。`kind`（Seed/Note/Line/Status/Merged/Todo/Project）、`origin`（User/Digest/System——AI 整理与用户原话分开）、来源（lineId/segmentId/itemId）、时间；FK 级联删除。
- `ideas.noMergeIdsJson`：用户标过“不相关”的灵感 id 列表。
- `topics.seriesId`：周期排期链锚，修 R5.1 缺陷——两条不同排期链都叫“周例会”会共享 seriesKey 互相串场。续场继承首场锚点；首场自锚。**同名≠同系列**从此由“链锚优先、散列才按名归组”保证。

## 实现内容

- `IdeaRepository.append / appendFromLine / entries / dismissDuplicate`；`create` 写 Seed 种子条，`setStatus/merge/convertToTodo/convertToProject` 各写一条轨迹。
- `convertToTodo`/`convertToProject` 幂等：已转化直接返回原 id，重复点击不重复建。
- `convertToProject`：建 `ProjectRow` + `project_links(Idea)` 互挂，走既有项目体系。
- UI（`IdeaScreen` 详情页）：「继续补充」卡（文字框+语音按钮）、「发展轨迹」时间线卡（User=紫点 / 其他=灰点，标注补充/原话/状态/合并/转化/AI整理）、「相关灵感」加「不相关」、「转为新项目」；转写页长按菜单加「补到灵感…」选择器。沿用 `RsCard/RsType/Pill` 紫调体系。
- 修复：`duplicatesOf` 过滤已标不相关项；轨迹展示过滤 Seed（旧数据无种子条，append 单条也能显示）。
