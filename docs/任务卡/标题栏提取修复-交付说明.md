- 标题栏从应用内容顶部（排除系统状态栏）起，取屏幕高度的 8%，不随键盘高度变化。只接受完整落在范围内的候选，选择水平中心最接近屏幕中心的文字。

- 未修改界面、接口约定或数据库；不回写旧记录。
