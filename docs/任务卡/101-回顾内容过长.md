# 101：生成回顾报“生成失败：LlmInputLimitException”

## 原因（Claude 已查明）

- 0.2.16 手动生成回顾时，界面提示 `生成失败：LlmInputLimitException`。
- `LlmClient.chatJson()` 对所有模型统一限制 `system + user ≤ MAX_JSON_INPUT_CHARS = 64_000` 字符，超过就直接抛异常。`DigestRunner.kt:157` 也用了同一个常量。
- 回顾会把窗口内全部事件（summary、points、提取项）发给模型。录音多的日子很容易超过 6.4 万字。
- 现在的模型容量远大于这个数：例如默认的 `deepseek-flash` 和 `deepseek-v4-pro` 上下文都是 100 万 token，最大输出 38.4 万（官方价格页，2026-11-07 核对）。是 6.4 万这个上限定得太小，不是内容太多。
- 回顾的兜底 `catch` 把异常类名直接显示给用户（`ManualReviewGeneration.kt:53/62/63/67`、`RoomReviewRepository.kt:59/153`）。

## 方案（用户已拍板：不精简内容，摘要、要点都要保留）

1. **输入上限按模型来定，取消统一的 64,000。**
   - 在 `app/src/main/assets/llm-providers.json` 里给每个内置模型补上下文容量（例如 `"contextTokens": {"deepseek-flash": 1000000, ...}`，结构自定，解析时要兼容旧数据）。**数值以各家官方文档为准**，逐个核对，交付说明里列出“模型 → 容量 → 来源链接”。查不到官方数字的，按未知处理。
   - 未知模型和自定义模型默认 128,000 token。本卡不做设置界面。
   - 可用输入字符数 = `(上下文 token − MAX_JSON_OUTPUT_TOKENS − 安全余量) × 换算系数`。按 1 个字符算 1 个 token 保守估计（中文和 JSON 符号都这么算）；安全余量取上下文的 5% 或至少 4,000，取较大值。
   - `LlmClient.chatJson()`、`DigestRunner` 里的上限检查都改成用当前所选模型的上限。`LlmInputLimitException` 保留，只用于真正超出模型容量的情况。
   - **不要改** `DigestRunner.MAX_BATCH_CHARS = 12_000` 和 `MAX_LINES`：那是为了整理质量设的分批大小，与容量无关。`MAX_JSON_OUTPUT_TOKENS` 也不改。
2. **回顾内容原样完整发送，不删摘要、要点、提取项。**
   - 只有输入超出当前模型的上限时，才启用保险方案：按顺序去掉普通事件的 `points`，再截短普通事件的 `summary`。`starred`、`important` 事件、未完成的待办/约定、`starred_stale` 始终完整保留，所有 `id` 必须真实。启用后在输入 JSON 里加说明字段，例如 `"compressed": "内容超出模型容量，部分普通事件省略了细节"`。
   - 保险方案处理后仍然超限，提示“内容超出所选模型的容量，请换用容量更大的模型”，不显示英文。
3. **失败文案改成中文。** 回顾相关的兜底提示都改成中文，例如“生成失败，请稍后重试”。界面上不再出现任何英文异常类名。
4. **检查长输入会不会超时。** 现在 `readTimeout` 是 180 秒、`callTimeout` 是 200 秒，评估十几万字的输入会不会因此超时。只有确实需要才调大，交付说明里写清理由。
5. **其他调用点**（技能、问答、重新整理、导入纪要、寻物、手动待办）只要走 `chatJson`，就会自动用上新上限，不需要单独加精简逻辑。交付说明里列一张简表：调用点 → 改动。

不改数据库版本、不改 Contract、不改回顾输出结构和各栏目条数上限。

## 测试（适度）

新增 `ReviewInputLimit101Test`，4～6 个用例：
- `deepseek-flash` 下，约 15 万字的回顾输入完整发送：`points` 和 `summary` 都在，不压缩、不抛异常。
- 未知或自定义模型用 128k 默认值；对内容超过上限的情况，启用保险方案后，重要事件、未完成待办完整保留，`id` 真实，并带说明字段。
- 保险方案处理后仍超限 → 中文提示，不出现异常类名。
- 解析 `llm-providers.json`：读出容量；旧格式没有容量字段时用默认值。
- 回顾兜底失败的文案是中文。
