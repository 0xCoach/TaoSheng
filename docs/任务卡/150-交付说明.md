### 基础插口

共用定义位于 `shared/src/commonMain/kotlin/app/resound/platform/`，签名按任务卡：

| 插口 | 安卓实现 | 装配字段 |
|---|---|---|
| NowMillis | SystemNow | platform.now |
| ZoneProvider | SystemZone | platform.zone |
| Logger | AndroidLogger | platform.logger |
| KeyValueStore | PrefsKeyValueStore（传入 SharedPreferences） | platform.keyValueStore |
| FileStore / FileRef | LocalFileStore（绝对路径，注入调度器） | platform.files |
| AppDispatchers | AndroidDispatchers | platform.dispatchers |

`SharedJson` 配置为 ignoreUnknownKeys=true、explicitNulls=false、encodeDefaults=true，本卡不替换任何现有 JSON 调用。

`PlatformServices` 是 app 层小数据类，字段只暴露共用插口；`AppGraph.platform` / `isPlatformReady` 按既有装配方式提供。ResoundApp.onCreate 在 super 后创建，声纹重跑由 AppGraph 传入调度器，无隐藏安卓默认值。LocalFileStore 在 io 调度器执行；不自动创建父目录、不递归删除、不吞读写异常，size 沿用 File.length 的缺失文件返回 0 语义。
