## 搬家方法（与卡 154 相同）
1. shared 里定义本包需要的存储接口（只用基本类型、共用数据类、`kotlinx.datetime`），规则只依赖接口 + `platform` 插口 + `net`。
2. 安卓 Room 实现改成实现接口，DAO/实体/SQL 不动。
3. 时间用 `NowMillis`/`ZoneProvider`；JSON 用 `SharedJson`/`WireJson`，**输出到大模型的提示词与 JSON 文本必须与原来逐字一致**（测试断言）。
4. 系统相关（Worker、闹钟、Keystore/`SecretStore`、语音输入、SharedPreferences 设置读写）留安卓。
