# 涛声 0.3.1 · 2026-11-14

定时整理补漏与 D3200 收音修复

【定时整理更可靠】
修复指定时间点整理迟到超过 30 分钟就跳过的问题。任务会保留待处理记录，重新打开应用、录音运行期间或系统允许后台执行时检查补漏；漏掉多个时间点时合并处理，避免重复整理。
网络等临时失败会保留进度并重试。问题记录增加等待联网、等待其他任务、实际延迟和中断等信息。
首次安装本版后从当前时间开始跟踪，不追溯升级前的漏点。后台执行仍受系统限制，不保证被强行停止或禁止后台运行后准点触发；鸿蒙真机效果尚待验证。

【安克／飞书录音豆 D3200（试用）】
修复开启灯控后可能收不到声音的问题；完善关灯状态下的实时收音及离线补传。
手动补传离开页面仍继续，可显式暂停并保留续传进度；防止重复启动，显示任务项及字节进度。
新增主机／充电盒固件与灯控范围说明，导入详情可导出录音。
贡献者已在 realme Android、D3200 04.92／盒 1.2.2 上提供真机验收；并不代表所有机型、固件均已验证。重连可能短暂亮灯，仅连接期间控灯。

【稳定性】
修复更新下载中误触发更新检查的问题，更新后台任务组件，包含前台服务启停竞态修复。

升级提醒：建议先备份重要记录。本版沿用 0.3.0 数据库结构；从更早版本升级仍涉及数据库迁移。0.3.0 起已移除原内置声云适配，使用声云设备的用户请暂缓升级。
