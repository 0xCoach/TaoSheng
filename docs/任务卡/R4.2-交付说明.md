# R4.2 交付说明：安静自动整理 + UI 实际挂载

## 做了什么

### A. 安静自动整理（独立开关，不改 DigestTimingContract）

- `shared/.../digest/QuietDigestRules.kt`：纯逻辑判定，输入全注入。状态机覆盖：Disabled/NotListening/Paused/PrivacyPaused/MicInterrupted/WaitingForSilence/WaitingForTranscript/WaitingForCooldown/NoContent/AuthRequired/AiNotConfigured/Running/Trigger。
- 关键守卫（对应"不能只按 20 分钟没新录音算安静"）：
  - `listening` 只认 CaptureState.Listening/Recording（服务前台活着）；
  - `speechActive`（Recording，段落开着）→ 说话中不算安静；
  - 隐私暂停/手动暂停/麦克风被占（MicBusy/NoPermission）→ 各自原因不触发；
  - 转写积压 → WaitingForTranscript，不误判"无内容"；
  - 冷却（默认 60min）+ lastQuietDigestAt 先记后发：进程被杀也不会重复发起同批。
- `CaptureDao.latestSpeechEndAt()`：segments 表 MAX(endAt)，排除导入音频。
- `QuietDigestWatcher`（app/digest）：ResoundApp 作用域每 60s 评估一次，无额外 WakeLock；触发走 `scheduler.runDigestNow()`——**同一套 DigestRunner 快照/pendingDigests/inflight 幂等**，Interval/TimePoints/手动/安静四种来源不会重复整理同批内容。配置存 `digest` prefs（随备份），运行时状态存 `digest-state`（已排除备份）。
- `DigestRunner.ready()`：公开配置可用性检查，与 runOutcome 同口径。
- 授权：`AppGraph.auth.allowed(Capability.AiAnalysis)`，未授权不触发（AuthRequired）。

### B. UI 实际挂载（用户明确要求本轮接上，越过 Codex/Claude 分工）

- `AuthLoginHost()`：挂 `MainActivity` 根（ImportHost 旁），loginRequested 非空即弹登录 BottomSheet，登录成功自动回放被拦动作。
- `MyAccountSection()`：挂 设置→模型页底部（我的账号：状态/设备管理/退出）。
- `KnockSettingsSection()`：挂 设置→录音页底部（VerifyScreen 是 LazyColumn，用 weight Box 钉底不嵌套滚动）。
- `QuietDigestSection`：挂 设置→模型页（DigestTimingCard 下），含开关/10-20-30-60 分钟阈值/冷却/当前状态/上次时间/现在整理按钮（复用 memory.runNow 同入口）。
