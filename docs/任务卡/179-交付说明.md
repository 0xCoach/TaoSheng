# 卡 179 交付说明：专题面板与专题记录重做、专题可删除、夜间橙色点缀

负责人 11-13 反馈：专题按钮打开后的面板和专题记录页太丑；专题要能删除；夜间全是黑白灰太单调，尤其时间线滑动、快速定位时，还是用橙色好看。

## 专题面板

- 类型改成一排图标方块（会议 / 培训 / 通话·访谈 / 口播稿 / 普通），选中是橙色描边加浅橙底。
- “什么时候结束”直接排出四个胶囊（我来结束 / 30 分钟 / 1 小时 / 2 小时），不用再点开；选了定时才出现滑杆。
- 下方两个次要入口并排成两块：“预约专题”“忘了点开始”，各带一句说明。
- 顶部两格切换改成圆角胶囊，夜间滑块加亮，看得出选的是哪一格。

## 专题记录

- 每场专题一张卡片：类型图标、名字、时间 · 时长 · 类型，右侧状态小胶囊（已完成绿、没整理完 / 整理中橙、其余灰）。
- 没整理完的专题在卡片下半部显示进度条和“继续整理”按钮；顶部有一条浅橙提示“N 场专题没整理完 · 只看这些”。
- 搜索框带放大镜和清除；显示“共 N 场”；跨年显示年份；空状态有图标和说明。
- **删除**：右上“管理”→ 每张卡片右侧出现“删除”，再点一次“确定删除？”才删（4 秒不点自动复原）。进行中的专题不显示删除。
- 专题详情右上“⋯”里，已结束的专题原来的“取消专题”改为“删除专题”；进行中的仍是“取消专题”。

删除的含义：合成的那件事和纪要一并删除，这段原话回到平常整理；录音和原话保留；记录本身（含时段、重点、断点文件）删除。已取消的专题删除时只删记录。

## 夜间配色

- 主题色从“近白”改回橙色（#F08A4B，比日间略亮略淡），只做小面积点缀：链接字、进度条、指示点、时间线左滑标重点、待办页快速定位的滑块和气泡、底部选项卡选中字、小号操作胶囊。橙底上的字用深色（对比度约 7）。
- 底色、卡片、分段选中、**整行主要按钮仍是黑白灰**（新增 `primary` / `onPrimary` 两个颜色令牌：日间橙底白字，夜间略灰的白底深字）。
- 浅橙底 `accentSoft` 夜间改为实色深橙褐，不用半透明。
- 日间配色不变。

## 底层与复用

- `TopicRepository.delete(topicId)`、`TopicStore.deleteTopic`（规则在 `:shared`）；安卓 `TopicDao.deleteTopic`，时段和重点靠已有外键级联删除。**数据库结构和版本不变。**
- 本卡没有可再搬的纯规则（界面为主）；删除规则直接写在共用仓库里。
