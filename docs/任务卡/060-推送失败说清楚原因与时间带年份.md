# 卡 060 · 推送失败说清楚原因；文件时间一律带年份（后端）

App 名叫“涛声”。给用户看的文字一律写“涛声”，只说结果和该怎么做。
推送页已经会显示失败文案（测试结果、推送记录），**本卡不改 `ui/` 和 `MainActivity.kt`**；如果需要界面配合（如文案太长需要多行），写进交付说明。

## 一、推送失败要写明具体原因

### 问题（已查明）
`PushTransport.send` 最后一层 `catch (_: Exception)` 统一报“推送失败，请检查通道配置”，用户看不出是什么问题。会落到这里的常见情况：地址格式不对（`builder.url()` 抛异常）、服务返回的不是 JSON（如被网关拦截返回网页）、缺少必填项等。另外：
- `execute()` 除 401/403/429/3xx 外，其他状态码都写成“推送服务暂时不可用”，**404、400 也这么写，会误导**；
- 服务明确拒绝时（PushPlus `code≠200`、企业微信/钉钉 `errcode≠0`、Telegram `ok≠true`、Server 酱 `code≠0`），一律写“请检查密钥、额度和通道配置”，**丢掉了服务自己给的原因**（如“token 无效”“超出每日次数”“chat not found”）。
- 网络错误一律写“网络连接失败或超时”，分不清是连不上、超时还是找不到地址。

### 已定方案
失败文案统一为“**一句结论 + 可能原因或怎么做**”，必要时带状态码。抽一个共用函数（可参考 `transcribe/ModelServiceError.kt` 的做法，按异常链分类）：

| 情况 | 文案 |
|---|---|
| 找不到主机 | 找不到 {主机}：检查地址拼写；用 Tailscale 等内网地址时确认手机已连上 |
| 拒绝连接 / 无路由 | 连不上 {主机:端口}：确认电脑上的接收服务已启动、端口正确；局域网/Tailscale 地址需手机和电脑在同一网络 |
| 超时 | 等待超时：服务没有响应，检查网络或接收端是否卡住 |
| 证书错误（SSLHandshake 等） | 安全连接失败：证书无效或过期；内网服务可改用 http:// |
| 地址格式不对 | 地址格式不对：需以 http:// 或 https:// 开头 |
| 400 | 服务拒绝了请求（400）：多为参数或格式不对，检查通道设置 |
| 401 / 403 | 认证失败（{码}）：检查密钥、Token 或权限 |
| 404 | 地址不存在（404）：检查接口路径 |
| 413 | 内容太大（413）：接收端限制了大小 |
| 429 | 发送太频繁（429）：稍后再试，或检查当天额度 |
| 5xx | 服务出错（{码}）：对方服务器问题，稍后会自动重试 |
| 3xx | 服务要求跳转（{码}），已停止发送：检查地址是否完整 |
| 返回内容看不懂 | 服务返回了无法识别的内容：地址可能指向了网页而不是接口 |
| 服务明确拒绝 | **{通道名}：{服务给的原因}**，如“PushPlus：token 不存在”。服务原因取 `msg` / `errmsg` / `description` / `message`，去掉换行，最多 80 字；为空时退回“服务拒绝了消息，检查密钥和当天额度” |
| 其他 | 推送失败（{异常类名}）：检查通道设置 |

规则：
- **不回显密钥**：服务原因和任何文案里如出现通道里存的密钥、Token、Webhook 地址中的 key 参数，一律替换成 `***`。不回显完整 URL（只写主机和端口）。
- 邮件（SMTP）、Notion、坚果云文件夹三条多步通道也接上同一套分类（SMTP 的认证失败、Notion 的 `message`、WebDAV 的 401/403/404/409/423/507 等），坚果云 503 写“坚果云暂时限流，稍后会自动续传”。
- 推送记录（`log.error`）和测试结果用同一段文案。
- 可重试的（超时、5xx、429、坚果云 503）照旧走现有重试，不改重试策略。

## 二、文件、导出、推送正文里的时间一律带年份

用户确认：长期保存的内容一律写年份，格式用短横线：
- 事件：`2026-10-29 周四 14:05–14:32`；跨天：`2026-10-29 周四 23:50–2026-10-30 周五 00:20`
- 单个时刻：`2026-10-29 14:05`

只改 `OutputTime.kt`（卡 059 的共用函数），所有用到它的地方自然跟着变；去掉“今年不写年份”的分支。同步更新受影响测试的预期字符串，并**重跑这些测试**（059 曾改了预期没重跑）。

## 三、必测（适度，6～8 个）

- 拒绝连接、找不到主机各 1 个（文案带主机端口）。
- 404 → “地址不存在（404）”。
- PushPlus 返回 `{"code":900,"msg":"token 不存在"}` → “PushPlus：token 不存在”；msg 里含密钥时被替换为 `***`。
- 服务返回网页（非 JSON）→ “服务返回了无法识别的内容…”。
- 坚果云 503 文案。
- `OutputTime`：事件同日、跨天各 1 个（带年份）。
