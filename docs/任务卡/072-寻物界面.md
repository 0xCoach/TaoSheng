## 一、总原则

1. **风格**：浅色、精致、动效丰富，跟现有页面一致。控件用卡片和胶囊点选，不用下拉框和系统对话框。深色模式要能看。
2. **只用现有组件**：
   - `RsCard`、`RsSheet`（会变长变短的面板加 `fixedHeight = true`）、`SheetInput`、`ActionButton` / `ActionKind`；
   - `Choice` / `Label`（`ui/items/TodoSheets.kt`）、`springClick`、`formatStamp` / `formatClock`（`ui/verify`）；
   - `Capsules` / `Empty` / `PageTitle`（`ItemsScreens.kt` 里是 private，需要时改成 internal，**不要复制一份**）；
   - `SmallPill`（`TodayScreen.kt` 里 private，改成 internal）。
   - 新写的全部放进 **`ui/things/ThingsUi.kt`**（太长可拆 `ThingSheets.kt`），别的文件只做接线。
3. **文案只说结果**，不讲机制：不出现“模型”“置信度”“识别”“判断”“自动提取”这类词。时间用 `formatStamp`（今天 21:12 / 昨天 09:03 / 10月28日 21:12）。
4. **寻物的颜色**：浅色 `0xFF3A8FB7`，深色 `0xFF7DBBDA`，写一个 `@Composable internal fun thingColor(): Color`（照 `categoryColor` 的写法用 `Rs.colors.isDark`）。小标签底色用它的 13% 透明度，与 `CategoryChip` 同款。
5. 取仓库：`val things = if (AppGraph.isThingsReady) AppGraph.things else FakeThings`（`FakeThings` 见第七节）。所有 Flow 用 `remember(...) { ... }.collectAsState(initial = ...)`，与现有代码一致。

## 二、状态的说法（统一用一个函数 `fun Thing.statusLine(): String` 和 `fun ThingRecord.actionLine(): String`）

| latest.action | 卡片主行 `statusLine` | 右上角状态小标签 |
|---|---|---|
| Placed | `place` | “放着”（寻物色） |
| Lent | “借给 {who} · 已 N 天”（N = 今天与 at 相差天数，当天写“今天借的”） | “借出”（`c.warning`） |
| TakenAway | “带走了 · 最后在 {lastPlace}”；`lastPlace` 为空就只写“带走了” | “带走了”（`c.textSecondary`） |
| Returned | 有 place：“已还回 · 放在 {place}”；没有：“已还回” | “已还回”（`c.good`） |

`actionLine`（一条记录的说法，历史和确认卡用）：

| 动作 | 写法 |
|---|---|
| Placed | “放在 {place}” |
| Lent | “借给 {who}”，有 place 再加“ · 放在 {place}” |
| TakenAway | “带走了” |
| Returned | “还回来了”，有 place 再加“ · 放在 {place}” |

## 三、记忆页「寻物」选项卡（`ItemsScreens.kt` 接线）

- `MEMORY_TABS` 里插在“重点”后面：`Tab("寻物", Grouping.Mentioned) { flowOf(emptyList()) }`。
- `MemoryScreen` 按类分支里加 `else if (tab.name == "寻物") { thingsTab(...) }`。`thingsTab` 是写在 `ThingsUi.kt` 的 `LazyListScope` 扩展；它需要的状态（搜索词、筛选、打开了哪样）在 `MemoryScreen` 里用 `rememberSaveable` 存，作为参数传进去。
- 页面从上到下：
  1. **搜索框**（item key `thingSearch`）：
     - 卡片底色圆角 16，和 `SheetInput` 同样式，但底色用 `c.card`（页面底色是 `c.background`）；
     - 提示文字“找东西，或搜地方：书柜、抽屉…”；右侧有字时显示“×”清空；
     - 输入防抖 300 毫秒后调用 `things.search(query)`，空串调 `things.things()`。
  2. **筛选小胶囊**（照“卡片”分类第二排小胶囊的写法：caption 字号、选中 `accentSoft` 底）：
     - 全部 / 借出去的 / 带走了；
     - 在界面里按 `latest.action` 过滤（Lent / TakenAway）。
  3. **待确认提示条**（有待确认时才出现）：
     - 一行 `accentSoft` 底的圆角胶囊卡：“有 N 条位置等你确认”，右侧“›”；
     - 点开 **待确认面板**（第五节）。
  4. **东西卡片**：一样东西一张 `RsCard`，卡之间间距 12，`Modifier.animateItem()`。卡里：
     - 第一行：名字（`RsType.headline` 或 body 加粗，选和页面最协调的）+ 归属不是“我的”时紧跟一个小标签（“家人的 / 别人的”，`c.textSecondary` 13% 底）+ 右侧状态小标签（第二节表格）。
     - 第二行：`statusLine()`，`RsType.body`、`c.text`，最多 2 行。
     - 第三行：caption、`c.textTertiary`：
       - 先写 `formatStamp(latest.at)`，后面跟“说的”（Live）或“记的”（Typed / Voice）；
       - `records > 1` 且 `lastPlace` 与当前位置不同、动作是 Placed 时，再加“ · 之前在 {上一条放在的位置}”。上一条要从 `history` 取，只在卡片可见时取会卡顿，所以**只用 `lastPlace` 判断**：当前是 Placed 时不显示“之前在”；TakenAway / Lent 时 statusLine 里已经有最后位置。
     - `hasPending` 时右下角小字“有新位置待确认”（寻物色）。
     - 当前是 Lent 时，卡片右下角一个 `SmallPill("已还", filled = false)`，点了调用 `markReturned(id)`，并 Toast“已记为还回来了”。
     - 点卡片打开 **东西详情**（第四节）。
  5. **空状态**（用 `Empty`）：
     - 没有任何东西：“说过“钥匙放抽屉了”这类话，就会记在这里。也可以点右下角，自己记一下。”
     - 搜索没结果：“没找到“{query}”。去问问里问一句，会从原话里帮你找。”
     - 筛选没结果：“没有借出去的东西” / “没有带走的东西”。
- **右下角添加按钮**：只在按类且当前是“寻物”选项卡时显示。在 `MemoryScreen` 最外层 `Box` 里调用 `AddHost`，参数：
  - `AddWords("记录", "addThingHintShown", "记一下东西放哪", "像平时说话一样写，几样东西写在一起也行。", "例如：护照放书柜第二层了，充电宝借给老王了", "生成")`；
  - `process` 里调用 `things.draft(text)`：
    - 结果为空，Toast“没能生成，请再试一次”；
    - 否则打开 **添加确认面板**（第六节）。
  - 列表底部要给按钮留出空间：`contentPadding.bottom` 在寻物选项卡时多加 80.dp。

## 四、东西详情面板 `ThingSheet(thingId, things, onDismiss)`

`RsSheet(title = 名字, subtitle = statusLine(), fixedHeight = true)`；东西被删了（`thing(id)` 发出 null）就自动关闭。内容从上到下：

1. **归属**：`Label("归属")` + 三个 `Choice`（我的 / 家人的 / 别人的），点了调用 `setOwner`。
2. **改名**：名字那一行右侧小字“改名”（accent），点了变成 `SheetInput` + “保存”小胶囊。空名不能存。保存调用 `rename`。
3. **经过**：`Label("经过")` 下一张卡（`c.background` 底，圆角 18），列出 `history(thingId)`，新的在前，行间 0.5dp 分隔线。每行：
   - 第一行：`actionLine()`（body）；
   - 第二行：caption 灰色：`formatStamp(at)`，`sourceText` 不为空时下面再起一行，写成““{sourceText}””，最多 3 行；
   - 行尾小字“删”（`c.critical`）：第一次点变成“确认删除”，3 秒内再点调用 `deleteRecord`；超时恢复。照 `TodoScreen` 里 `ignoreArmed` 的写法；
   - 点一行其他位置：打开 **编辑面板**（第六节），保存时调用 `editRecord(record.id, edit)`。
4. **按钮区**（`ActionButton`，纵向排列，间距 10）：
   - 当前是 Lent：Primary“已还回来了”，调用 `markReturned`；
   - Secondary“记个新位置”：打开编辑面板。预填名字、动作 Placed、归属同这样东西；保存时调用 `add(listOf(ThingDraft(name, action, place, who, owner, thingId = id)), ThingOrigin.Typed, "手动记的")`；
   - Danger“删除这样东西”：二次确认同上（按钮文字变“再点一次删除”，3 秒恢复），调用 `deleteThing` 后关闭面板；
   - 最下面一行 caption 灰字：“删除只删这里的记录，原话还在。”

## 五、首页待确认（`TodayScreen.kt` 接线）

- 取 `things.pending()`，只要 `at` 在 3 天内的（3 天前的只在寻物页的待确认面板里，收在“更早”里）。
- 和现有待办的待确认**放进同一个“待确认”区、同一个 `LazyRow`**：
  - 把两种合成一个列表，按时间新的在前（待办用 `MemoryItem.at`，寻物用 `ThingRecord.at`）；
  - key 分别用 `"i${id}"`、`"t${id}"` 防冲突；
  - 标题右边的条数、`OverviewCard` 的 `pendingCount`、`timelineIndex()` 里的判断，都改成两种加起来。
- **寻物确认卡 `ThingPendingCard`**：尺寸、底色、圆角、字号和现有 `PendingCard` 完全一致（`accentSoft` 底，两张并排）。
  - 顶行：左边“寻物”小标签（寻物色），右边 `formatClock(at)`；不是今天的用 `formatStamp`。
  - 中间两行（固定 `minLines = 2, maxLines = 2`）：
    - Placed：“{name} → {place}”
    - Lent：“{name} 借给 {who}”
    - TakenAway：“{name} 带走了”
    - Returned：“{name} 还回来了”
  - 底部按钮：
    - 没有 `sameAs`：`SmallPill("忽略")` + `SmallPill("记下", filled = true)`，分别调用 `ignore(id)` 和 `accept(id)`；
    - 有 `sameAs`：中间第二行换成“是之前的「{sameAs.thingName}」吗？”（第一行照常），按钮换成 `SmallPill("新的一样")`（`accept(id, asNew = true)`）+ `SmallPill("是", filled = true)`（`accept(id)`）。
  - 点卡片其他位置：打开 **确认面板** `ThingConfirmSheet`：
    - `RsSheet("确认位置", fixedHeight = true)`；
    - 最上面一张 `RsCard`：caption 写 `formatStamp(at)` 加“说的”，下面 body 写““{sourceText}””（为空就不显示这张卡）；
    - 下面是第六节的编辑字段，预填这一条；
    - 有 `sameAs` 时，编辑字段上方加一行 `Label("是之前的「X」吗？")` + 两个 `Choice`（“是，更新位置”默认选中 / “不是，新的一样”）；
    - 按钮：Primary“记下”：没改过就 `accept(id, asNew = …)`，改过就 `accept(id, edit, asNew = …)`。Secondary“不对，忽略”：`ignore(id)`。
- 卡片出现、消失用 `animateItem()`，与现有一致。
- **寻物页的待确认面板 `ThingPendingSheet`**：`RsSheet("待确认", fixedHeight = true)`。
  - 列出全部 `pending()`：3 天内的在上；3 天前的收在一行“更早的 N 条 ›”里，点开展开。照 `TodoScreen` 的 `olderOpen`。
  - 每条一行：`actionLine` 加名字，下面一行灰字写时间和原话；右侧“忽略”“记下”两个小胶囊；点行打开确认面板。
  - 底部两个 `ActionButton`：“全部记下”（`setAll(ids, Accepted)`）和“全部忽略”（`setAll(ids, Ignored)`）。全部忽略要二次确认，同上。

## 六、编辑字段（一个组件 `ThingEditFields(state)`，确认面板、编辑面板、添加确认面板共用）

用一个 `class ThingEditState(初值)`，字段都是 `mutableStateOf`，有一个 `toEdit(): ThingEdit`，有一个 `valid` 判断。从上到下：

1. `Label("东西")` + `SheetInput`，提示“如：车钥匙”。
2. `Label("怎么了")` + 4 个 `Choice`，用 `ThingAction.title`（放在 / 借给 / 还回来了 / 带走了），用 `FlowRow` 排。
3. 按动作显示后面的字段，切换时用 `AnimatedVisibility` 展开、收起：
   - Placed：`Label("放在哪")` + 输入框，**必填**；提示“如：鞋柜第二个抽屉”。
   - Lent：`Label("借给谁")` + 输入框，**必填**。再加 `Label("放在哪（可不填）")` + 输入框。
   - Returned：`Label("还回来放哪了（可不填）")` + 输入框。
   - TakenAway：没有。
4. `Label("归属")` + 三个 `Choice`。

`valid`：名字不空，并且 Placed 的位置不空、Lent 的借给谁不空。保存按钮在 `!valid` 时 `enabled = false`。

- **编辑面板 `ThingEditSheet(title, initial, onSave)`**：`RsSheet(title, fixedHeight = true)`，下面是字段和 Primary“保存”。
- **添加确认面板 `ThingDraftSheet(drafts, source, onConfirm)`**：照 `AddTodo.kt` 的 `DraftSheet` 做。
  - 标题：多条时写“生成了 N 条”，一条时写“确认一下”。
  - 副标题：`parsed = true` 时写“改好后点记下。”；`false` 时写“没能自动拆开，已按原话生成，改好后点记下。”
  - 第一行灰字写“"{source}"”。
  - 每条一张卡：`c.background` 底、圆角 18，多条时右上角有“删掉”。
  - 按钮 Primary 写“记下”，多条时写“记下 N 条”。确认时调用 `add(drafts, origin, source)`，然后 Toast“已记下 N 条”。
