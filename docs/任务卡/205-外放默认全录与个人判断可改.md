# 任务卡 205：外放默认全部录（按 App 例外、只标记不过滤）＋个人判断点错能改

执行：Codex（gpt-6.2-astra）后台与规则；Claude 界面　审核：Claude
分支：`codex/205-playback`（基于卡 204 合并后的分支，开工时以派卡说明为准）　工作目录：`~/Developer/TaoSheng-205`

## 背景（负责人已定）

#51 反馈 0.5.0 后“经常漏掉说的话”。现在外放的处理是**整段一刀切**：一段里一半以上时间系统报“扬声器在外放”，整段不转写（`skipPlayback` 默认开），也不整理（`includePlaybackDigest` 默认关）。挂着静音播放器的 App 会让系统一直报外放，真人说的话因此被跳过。

负责人定：**外放的声音、真人说的话，全部录下来、转写、整理；默认全开，用户自己去关。** 不按真人过滤，只做标记让整理分得清。外加按 App 例外、“记下外放”、首次大量外放提示一次。另外个人判断：答案能改、“不是”的录音留 7 天、加“清空重学”。

## 一、外放（Codex）

**1. 设置合并成一个“外放的声音”**（放 `:shared`，平台无关）
- 默认处理：`转写并整理`（默认）/ `只转写` / `不记`。
- 按 App 例外：包名 → `跟默认` / `不记` / `只转写` / `转写并整理` / `它放的不算外放`。
- 老用户迁移：两个旧键（`skipPlayback`、`includePlaybackDigest`）**都没写过**的 → 用新默认；`includePlaybackDigest=true` → 转写并整理；`skipPlayback=false` → 只转写；其余 → 不记。迁移只做一次，写测试。
- 旧的 `PlaybackSkipSettings` / `PlaybackDigestSettings` 退役，调用方全部改用新设置。原话里逐段“仍要转写/放行”的入口保留。

**2. 每段怎么处理**
- 外放占多数的片段，看当时是哪个 App 在放：优先用 `playback_rows`（屏幕时间/外放归属已经记录了包名和时间）；拿不到包名就用默认处理。同一段有多个 App，取外放时间最长的那个。
- `不记` = 现在的跳过（可在原话里逐段放行）；`只转写` = 转写但 `playbackDigest=1`；`转写并整理` = `playbackDigest=2`；`它放的不算外放` = 那段时间不算外放。
- **媒体音量为 0 时不算外放**：`PlaybackMonitor` 判定时加 `STREAM_MUSIC` 音量为 0 → `speakerPlaying=false`，`playing` 照旧。

**3. 句子级“外放”标记（只标记、不过滤）**
- 每句原话能知道自己是否落在外放期间、是哪个 App 或节目。先看能不能从现有数据算出来（`playback_rows` 的时间段 + 片段 `playbackMillis`），算不出来再记录片段内的外放区间。需要升库就升到 41，严格按 `AGENTS.md` 的迁移规则写（`CaptureDatabase.MIGRATIONS`、`VERSION`）。能不升就不升。
- 给界面一个读取接口：某段原话的每句是否在外放、是哪个 App/节目名（App 名受现有“整理时带上 App 与播放信息”开关约束，关掉时只给“外放”）。
- **整理提示词**：外放期间的句子带标记交给大模型。在 `app/src/main/assets/prompts/digest.md` 现有“媒体”规则基础上写清楚：
  - 写成“看/听 ××时听到……”，不写成“你说……”；
  - 不能只凭外放句子生成待办或约定；本人接着说了（如“那我明天交”）照常生成；
  - 真人对话里夹着外放照旧按真人对话标。
- 改提示词按 `fix-root-cause` 原则：用**新的**几个测试用例（视频里说“明天记得交报告”不生成待办、边看视频边和人约饭照常生成约定、听播客记成“听了一档关于……的播客”）验证，不要只为某一句调提示词。

**4. “记下外放”**
- 当前在放的 App 处理为 `不记` 时，录音通知里显示“记下外放”。点了以后，到这次播放停止前都按 `转写并整理` 处理（记成一段临时例外，播放停止自动结束）。
- 不是 `不记` 时不显示这个按钮。

**5. 首次大量外放提示一次**
- 默认全开后，一天里外放转写累计超过 30 分钟时，首页提示一次：“外放也在转写和整理，按 App 可以关”。每个用户只提示一次，点了跳到设置。后台给一个状态（要不要显示、已看过），界面 Claude 做；复用现有首页通知的机制。

## 二、个人判断（Codex 后台）

1. **“不是”的录音留 7 天**：点“不是”后不再立即删录音文件，过期时间设为 7 天后，走现有过期清理；7 天内回听、改答案都可以。改回“是”就照现在的“已确认”永久保留。`NightStore.feedback` 里立即排隐私清理的那段要改。
2. **答案能改**：是 ↔ 不是来回改，训练样本跟着更新（`night_feedback` 已按 eventId 唯一覆盖）。改答案算新材料（卡 204 已做的话核对一下）。
3. **清空重学**：新接口，清掉个人判断学到的模型和学习样本（`night_personal`、`night_feedback`），所有否决标记清零并重新整理受影响的晚上；**事件上已经点过的是/不是答案保留显示**。之后新点的答案从头开始攒。
4. **排除了多少段**：`PersonalModelStatus` 增加“已被个人判断排除的段数”，带默认值，不破坏旧调用。
