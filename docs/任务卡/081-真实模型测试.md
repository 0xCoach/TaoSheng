## 最终结果

19 句新原话加 1 句已处理上下文，分 3 组；预期 11 条物品事实，最终 11 条均入库，无额外误报。涵盖静态位置、多个物品、跨句代词、跨批完成确认、借出、归还、带走、方言、显式记住以及计划/命令/假设/影视/设计讨论排除。已知电钻正确关联，主动记住标记正确。

模型回复通过生产 DigestRunner、DigestThingExtraction、ThingPrompt 和 Room 入库处理；每组只调用一次共用请求，时间线覆盖所有新原话。每条物品通过 FindThingsTool 查询存在且原话 ID 正确。这验证了“问问”的本地工具链路，不等于手机语音提问或问答模型整段回答已验收。

## 发现与修复

初轮漏掉跨批完成确认：前批确定物品与位置，新批确认收妥，但后面的设计讨论使模型将整段概括成示例，things 为空。第一次仅补判断规则仍失败；最终将旧上下文放在新原话之前，明确先输出 things 再输出 events，并明确旧上下文可以补全对象位置、只是不能作为 source ID。样例和验收断言未降低，最终复验通过。

模型还曾把带走者填入借用人 who。解析层现在对 Placed/TakenAway 清空 who，仅借还保留，避免语义污染。

3 轮实际请求共 15 次（9 + 3 + 3）；后两轮只重发修改后的新版请求，旧基线复用首轮结果并标记 reusedBaseline。首轮和第二轮失败结果保存在 app/build/things-live/initial-results.json、second-results.json；最终结果 results.json。均为被 Git 忽略的本地合成测试产物，不含密钥。
