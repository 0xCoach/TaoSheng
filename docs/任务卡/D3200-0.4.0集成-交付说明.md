# D3200归档、清理与Wi-Fi快传：0.4.0集成

代码基线为官方v0.4.0的ddd3306a，提交时已同步主分支c03d8e75（之后两次提交仅修改README与发布记录）。此前基于0.3.1完成的功能及真机验收保留在原分支，本提交分支迁移其独立提交；未覆盖手机官方App，也未修改0.4.0版本号、许可证、贡献约定或CLA检查。

## 新版兼容

- 0.4.0的后台流水线188/189继续持有转写和整理执行机会；设备补传及完整归档维护独立运行，实际导入仍走官方持久化导入队列，完成凭据仍要求解码入库完成。没有把新流水线回退为旧调度。
- DeviceSync与DeviceInputs的冲突同时保留新版FailureNotes异常记录、本轮断线/取消/错误状态及已提交进度。ImportWork保留新版资源引用、失败记录，以及本轮加急任务在Android 10/11所需的前台通知。
- 新版设置备份分类和密钥解码规则保留；完整原声继续使用独立device-archives命名空间和独立读回凭据。还原其他安装环境不继承设备原件删除资格。
- 新功能默认关闭自动清理与Wi-Fi；已有设置保留。清理时机可选校验后空闲维护、再留24小时/3天/7天，旧策略在用户确认切换前不缩短。
- 没有改动既有Contract.kt或AudioSource签名。通用保留规则在shared，D3200传输协议在devices，系统入网、USB、文件和调度在Android。

## 验证范围

既有真机证据来自同分支功能的0.3.1独立验证构建：两文件Wi-Fi断网/蓝牙回退/持久化续传、完整归档和电脑备份读回、锁屏时新导入，以及显式USB恢复后的全程后台清理。最后一轮只删除19.42秒专用测试原件，35次前后台采样均未进入App前台；手机与电脑完整副本删除后再次读回及哈希核对通过。自动清理已关闭。详细成功和失败轮次见对应交付记录。
