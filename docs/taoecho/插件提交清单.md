# 4 级插件提交清单

录包会公开在仓库里。录包内容不做限制，提交前请维护人自行确认。

每个插件必须同时交付以下四项：

- [ ] **录包与回放测试**：至少两段 v1 录包，分别覆盖实时收音和补传；注明对应硬件/固件，提供运行命令及关键断言（采样/缺口、文件清单/内容/续传）。如屏蔽随机数或时间戳字节，注明位置与原因。
- [ ] **真机报告**：填写下方模板，明确实测、未测与不支持的能力；不能以电脑回放代替实测。
- [ ] **维护人**：`meta.maintainer` 填 GitHub 账号，说明后续问题由谁处理。
- [ ] **不改核心**：品牌/固件特例放本插件目录；只使用会话提供的能力，不直接访问系统、路径、网络或界面，不改约定签名和核心分发逻辑。新公共接口需求先提清单及兼容方案。
