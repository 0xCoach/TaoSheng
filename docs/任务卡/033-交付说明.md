## 做了什么

- 完成“云端 0 份”回归测试：小写百分号编码、直接中文、完整 URL 均能识别；按解码路径比较，同时检查协议、主机和端口。恢复列表合并新旧目录，成功备份后云端份数也统计两者。
- 新目录固定 `Resound-Backup/`、日记目录固定 `Resound-Diary/`，文件固定 `resound-yyyy-MM-dd-HHmm-ssSSS-xxxxxxxx.zip(.enc)`。旧 `回响备份/`、`回响-` 不依赖当前应用名称，继续列出和下载；上传、删除禁止写旧目录，保留策略仅处理新目录。错放的新旧前缀文件不会被错误路由删除。
- 扫描落盘/导出命名，将日记导出改为 `resound-diary_….md`、诊断导出改为 `resound-diagnostics-….txt`。归档内部路径及原有恢复快照目录已经是英文，保留其兼容路径；界面和通知文案未改。
- 实现本机文件夹授权、列表、立即备份、自动备份、1/3/7 份保留（默认 3）、单份导出、从文件及文件夹恢复。配置和状态存 `backup.xml` 的 `local*` 英文键；用 DocumentFile 读写目录，失去权限返回“本机文件夹无法访问，请重新选择”。显示名称取所选文件夹名。
- 本机先写 `.part`、关闭后回读校验 SHA-256，再改正式文件名，成功后才清理超额英文备份。无关文件、不合法日期文件、旧中文备份不删；失败不清除恢复快照。
- 云端、本机、导出共用 `generateBackup`；三种恢复来源共用 `BackupRestore.restoreFile`，依次校验、迁移、保存原机快照、准备替换、关闭数据库、请求重启。加密由文件内容识别，用户改扩展名也能导入；缺口令返回“这份备份加了密，请输入口令”。密钥清空和启动时替换沿用原流程。
- 云端和本机各有独立 WorkManager 夜间任务（均约 03:10，充电且空闲），互不取消、互不传播失败；本机无需网络，云端仍要求非计量网络。即时本机备份也不要求网络。操作通过同一互斥锁串行，避免备份和恢复同时替换数据。
