# 任务卡 010：坚果云（WebDAV）自动备份

## 目标

每晚自动把回响的本地数据备份到负责人的坚果云，手机丢了或重装也能找回。本地库和备份都**不加密**（已定），密码放系统安全区。

## 约定（Claude 已写，不要改签名）

- `backup/BackupContract.kt`：`BackupRepository`、`BackupState`。
- `AppGraph` 只加 `backup: BackupRepository` 和 `isBackupReady`，在 `ResoundApp` 装配。**不要改 `ui/`、`MainActivity.kt`、数据库版本。**

## 要做的

1. **连接**：坚果云 WebDAV 地址 `https://dav.jianguoyun.com/dav/`，账号为邮箱，密码是“第三方应用密码”。用 OkHttp 实现 PROPFIND / MKCOL / PUT / DELETE 和 Basic 认证；地址集中成配置（以后可换其他 WebDAV）。远端目录 `回响备份/`（目录名用 App 显示名 `context.appName` + “备份”）。
2. **备份内容**：一个 zip：数据库一致快照（先 `PRAGMA wal_checkpoint(TRUNCATE)` 或用 `VACUUM INTO` 生成副本，**不能**直接拷正在写的文件）、声纹特征缓存目录、`shared_prefs` 里**不含密钥**的设置文件（排除所有加密密钥文件）、一个 `manifest.json`（时间、App 版本、库版本、各文件大小与 SHA-256）。录音音频**不备份**（转写后一天就删，且体积大）。
3. **时机**：WorkManager 每天一次，约束：充电 + 不计流量网络 + 设备空闲（尽量凌晨）；`backupNow()` 立即一次（只要求联网）。同一时间只跑一个。
4. **保留**：远端只留最近 7 份，多余的删除最旧的；文件名 `回响-2026-10-23-0310.zip` 这种格式。
5. **上传可靠**：先传成 `.part` 再 MOVE 成正式名；失败重试按 WorkManager 退避；不要因一次失败删掉旧备份。
6. **状态**：`BackupState` 实时反映；错误用固定中文文案（“账号或应用密码不对”“网络不通”“坚果云空间不足”等），不带服务端原文、不带密码。
7. **恢复**：本卡只写一个内部函数 `restoreLatest()`（下载最新 zip、校验 SHA-256、关库后替换、重启进程），先不接界面，单元测试覆盖即可，交付说明写清楚怎么手动触发。

## 测试

- 单元测试用 MockWebServer：PROPFIND 解析、MKCOL、PUT→MOVE、保留 7 份删除逻辑、401/507/网络错误分类、zip 内容与 manifest 校验、排除密钥文件、快照一致性（Robolectric + 写入中的库）。只跑本卡相关；`./gradlew assembleDebug` 通过（`JAVA_HOME=/opt/homebrew/opt/openjdk@21`）。
- 本卡**不连真实坚果云**（负责人还没给账号）；真机与真实账号的验证写进交付说明。
