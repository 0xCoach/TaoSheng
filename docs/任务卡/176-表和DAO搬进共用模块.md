### 第 2 步：拆文件

把混着安卓逻辑的文件拆成“表 + DAO”（可搬）和“其余”（留安卓）两部分，**先在 `:app` 里原地拆，不换模块**，编译通过、相关测试通过后单独提交。重点是 `location/Location.kt`、`location/Places.kt`、`importer/ImportFingerprint.kt`、`skills/SkillDao.kt`、`search/EmbeddingStore.kt`、`search/SearchIndex.kt`、`redo/RedoData.kt`、`push/PushRecords.kt`。

规则：

- 实体的字段、表名、列名、索引、外键、默认值**一个字符都不改**。
- DAO 的 SQL 文本一个字符都不改（卡 175 用脚本比对过字符串常量，本卡同样比对，见“验证”）。
- DAO 里的具体方法（非 `@Query` 的辅助函数）如果用了 `java.*`、`org.json`、`android.*`：能改成纯 Kotlin / kotlinx 的就改（按 `AGENTS.md` 第 1、5 条）；改不了的挪到安卓这边的扩展函数或仓储里，DAO 只留查询。JSON 用 kotlinx.serialization，**输出的 JSON 文本必须与原来逐字相同**（列里存的是 JSON 字符串，变了就是改了用户数据），为每个改动的编解码写逐字对照用例。
- 时间一律用毫秒 `Long` 或 kotlinx-datetime，由参数传入，不在 DAO / 实体里取当前时间。
- `trainingAt` 改成挂起函数。调用方是录音 / 转写装配里的同步回调：先读清 `AndroidAsrSpeedSettings` 和转写装配怎么用它，选一个**不引入阻塞等待、不改变判断结果**的接法（例如由专题仓库维护一个“当前是否培训专题”的状态供同步读取）。把方案和理由写进交付说明；拿不准就停下问，不要用 `runBlocking` 糊过去。

### 第 3 步：搬进 `:shared`

- 实体、DAO、`CaptureDatabase`、`MIGRATIONS`、四组回调及它们用到的建表 / 建触发器 / 分词 SQL 生成函数、`DatabaseSql.kt` 里的挂起封装，搬到 `shared/src/commonMain/kotlin/` 下，**包名保持不变**（`app.resound.data`、`app.resound.topic` 等），这样 `:app` 里的 import 基本不用动。
- `CaptureDatabase` 加多平台需要的 `@ConstructedBy` 和 `expect object … : RoomDatabaseConstructor<CaptureDatabase>`（由 KSP 在各目标生成 `actual`）。
- 建库入口留安卓：`CaptureDatabase.open(context, name)` 改成安卓侧的函数（放 `shared/src/androidMain` 或 `:app`，哪个改动小用哪个），仍然 `setDriver(AndroidSQLiteDriver())`、注册同样的迁移和回调、同样记录 `filePath`。数据库文件名和路径不变（`capture.db`）。
- 阻塞适配（`readSqlBlocking` 及各处 `runBlocking`）**不进 commonMain**，留在安卓侧。本卡不要求消除它们（卡 177 处理），但不许新增。
- 可见性：搬过去后 `:app` 要用的 `internal` 声明改成 `public`。只放开确实被 `:app` 用到的；纯内部辅助保持 `internal`。
- 结构文件：`app/schemas/` 整体挪到 `shared/schemas/`（用 `git mv` 保留历史），`:app` 测试里引用结构文件的地方（`AppPowerMigrationTest`、`VoiceInput048Test`、`ImportKinds077Test`、`FolderImports117Test`、`Driver175FixturesTest`、`TriggerHistory181Test`、`tools/trigger-audit-181/freeze_history.py`、`app/src/test/observer182_plans.py` 等）改指新位置。1～32 的历史结构文件内容不许变。
- `:app` 去掉 Room 的 KSP 处理（如果 `:app` 里已没有 `@Database` / `@Dao`）；`room-runtime` 依赖按需保留。
- 更新 `tools/check_shared.py`：允许清单加上 `androidx.room`、`androidx.sqlite` 的多平台 API，同时显式禁止安卓专属的旧接口（`androidx.sqlite.db`、`SupportSQLite`、`SimpleSQLiteQuery`、`openHelper`、`androidx.room.withTransaction`）。检查脚本自己的单测如果有，一并更新。
