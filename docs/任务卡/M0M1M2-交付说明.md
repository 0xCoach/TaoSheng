# M0–M2 个人 AI 助手全量开发 · 交付说明

基线：v0.4.0（`ddd3306a`），分支 `dev/m0-m1-m2`，数据库版本 34 → 35。

## 做了什么

### M0（复用上游，已验证可构建）
- 固定 tag、建开发分支、补齐 Windows 构建环境（JDK21、SDK、`android.overridePathCheck`）。
- `assembleDebug` 成功产出 `app-debug.apk`。本地语音链（Silero VAD / SenseVoice / sherpa-onnx / CAM++ / Room / 失败重试 / 后台录音）为上游已有实现，未改动。

### M1（大部分复用上游 + 新分析落地）
- Provider 体系（OpenAI 兼容 BaseURL/Model/Key/测试/切换/超时/失败分类/备用链路）为上游 `LlmProviders` 已有能力，未重复造轮子。
- 新增「分析」模块可视为每日整理的通用化：`AnalysisRepository` 组装材料 → 模板渲染 → `failover.request` 走真实模型 → 结果落库。未配置模型时运行落为 `Failed(未配置模型服务)`，材料可导出、结果可导入，不伪造 AI 输出。

### M2（本次新增主体）
- `shared/` 新增四组实体 + DAO + Schema + 规则：`inbox`（ideas）、`projects`（projects/project_links/project_marks）、`analysis`（analysis_templates/analysis_runs）、`agent`（agent_endpoints/agent_tasks）。迁移 34→35 进 `CaptureDatabase.MIGRATIONS`，全部 `CREATE TABLE IF NOT EXISTS`（幂等）。
- `app/` 新增 `IdeaRepository` / `ProjectRepository` / `AnalysisRepository` / `AgentBridge` / `AgentDispatchWork`（WorkManager 15 分钟兜底 + 应用内 60 秒驱动）。
- AgentBridge：端点管理（URL 校验：公网强制 https，私网/Tailscale 允许 http）、密钥存 `SecretStore`（Keystore，不进库不进日志）、任务状态机 `Pending→Confirmed→Running→Succeeded/Failed/Cancelled`、唯一 `taskId` + `claimForSend` CAS 防重发、回执保存、指数退避重试、状态回查、人工收尾、JSON 导出。只发送用户确认过的文本载荷，不触碰音频。
- UI：底栏新增「助手」页（设置移到第 6 位，`ShellNav.go(4)→go(5)` 已同步改），内含灵感/项目/分析/任务四个子页，全部中文、含空态/失败态/等待配置提示；转写页长按原话新增「标为灵感」。
