# 卡 061 · 环境音识别：真实数据评测与调优（研究卡，不改 App）

App 名叫“涛声”。本卡**只在电脑上做评测和调参，不改 `app/` 下任何代码**。产出是一份评测报告和一套推荐参数，负责人验收后再写开发卡。

## 一、背景

负责人计划三期一起做进 App：
1. **过滤**：跳过纯音乐、纯环境音（不送转写）；“疑似影视外放”可选 照常记录 / 标记为媒体 / 不转写。被跳过的录音可找回；认出“我”在说话时不当外放处理（声纹兜底）。
2. **环境标签**：把“室内 / 车上 / 嘈杂 / 键盘声”等写进事件，可按环境搜索。
3. **重要声音**：婴儿哭、烟雾报警、门铃、敲门、警笛等，默认关闭，先只记一条记录。

负责人已做过一轮小测试（20 段真实录音 + 模拟样本），结论：
- 候选模型（sherpa-onnx 音频标签，int8）：`zipformer-small-audio-tagging-2024-04-15`（27 MB）、`ced-small`（22 MB）、`ced-mini`（10 MB）。CED 一次最多约 10 秒，需切 10 秒窗口、每类取各窗口最大值。
- Zipformer-small 区分最清楚：真实电视剧（有配乐）Music 0.97～0.99，日常对话 Music ≈ 0；环境音标签也最准。CED 多一个 Television 信号但真实录音里只有 0.05～0.23。
- **三个模型都分不出“没有配乐的外放人声”**（新闻、口播）。
- 现成脚本：`tools/audio-tagging-probe/probe.py`；虚拟环境 `~/.venvs/audiotag`（已装 sherpa-onnx 2.0.1）；模型已下载在 `~/.claude/jobs/3b8dcfaa/tmp/at/`（可复制到你的数据目录，或重新下载）。

## 二、要做的事

### 1. 收集真实测试数据（从网上下载公开数据集）
- 放在 `~/Datasets/taosheng-audio/`，**不要放进仓库、不要提交**。总下载量控制在 **8 GB 以内**。
- 只用**许可允许研究使用**的公开数据，在报告里列出每个数据集的名字、来源、许可、用了多少条。可选（自行判断可用性）：ESC-50、FSD50K / FSDKaggle、UrbanSound8K、MUSAN（音乐 / 语音 / 噪声）、DEMAND / 其他噪声集、AudioSet 评测集里能合法获取的部分、公开的中文对话 / 播客 / 新闻语音集、房间冲激响应（RIR）数据集。
- 需要覆盖的类别（每类尽量 ≥ 30 条，中文优先）：
  - **真人对话**：安静室内、嘈杂（饭店 / 咖啡馆 / 街道 / 车内）、背景有音乐的真人对话。
  - **影视外放**：有配乐的影视对白；**没有配乐的外放人声**（新闻、访谈、短视频口播、有声书）。
  - **纯音乐**：各种风格，含外放效果。
  - **纯环境音**：交通、雨、厨房、键盘、空调 / 风扇、人群嘈杂、宠物。
  - **重要声音**：婴儿哭、烟雾 / 火灾报警、门铃、敲门、警笛、玻璃碎、狗叫；**以及影视里出现的同类声音**（用来测误报）。
- 用 RIR + 喇叭频响（如 300 Hz–5 kHz 带通、轻微失真）把一部分干净素材**做成“手机录到的外放 / 房间”效果**，和原始素材分开统计。
- 负责人本机已有 20 段**真实录音**（`~/Downloads/回响身份识别验证-20261023/`、`~/Downloads/回响本地转写独立验证-20261023/`；其中 132、137、138 是电视剧对白，其余主要是日常对话，142 不确定）。**只在本机使用，不上传、不复制进仓库**，单独作为“真实手机录音”一组统计。

### 2. 评测
- 三个模型都测；窗口策略至少比较：整段（Zipformer）/ 10 秒滑窗取最大 / 只抽开头、中间、结尾各 10 秒。
- 每个功能给出**规则 + 阈值**，并报告查准率 / 查全率 / 误判数：
  1. **跳过纯音乐、纯环境音**：重点是**几乎不误伤真人说话**（目标：真人说话被误跳过 ≤ 1%）。
  2. **疑似影视外放**：报告有配乐 / 无配乐两类各自能抓到多少；背景有音乐的真人对话被误判多少。
  3. **重要声音**：每类的查全率；影视里同类声音和日常噪声造成的误报数。
  4. **环境标签**：把 527 类归并成十几个对用户有意义的标签（如 室内、户外、车上、交通、嘈杂人声、音乐、键盘、厨房、雨、宠物），给出归并表和每个标签的阈值。
- 试一下能否**补上“无配乐外放人声”**的漏洞，结合现有信号做简单规则即可，不训练新模型。例如：Television / Radio 分数、语音占比、频谱是否被削（喇叭缺低频）、音量是否稳定、语速等。做不到就如实写“做不到”，不要硬凑。
- **耗时**：电脑上每分钟录音的处理时间；估算小米 14 Pro（骁龙 8 Gen 3，CPU 2 线程）的耗时（可按电脑和手机单核性能比估算，并写清估算方法）。

### 3. 调优
- 在上面基础上调阈值、调窗口、组合信号，给出**一套推荐配置**（模型、窗口、每个功能的规则和阈值）。
- **防止只对这批数据有效**：留一部分数据（≥ 30%）只用来最后验证，调参时不看；报告里分开写调参集和验证集的结果。
