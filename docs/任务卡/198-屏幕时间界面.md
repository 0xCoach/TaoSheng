# 卡 198：屏幕时间界面统一与默认开启

执行：Claude。基线：main（数据库 38，含 #50）。目标版本 0.5.0。不改数据库。

## 用户已定
- 首页：录音卡统计改成 人声 · 屏幕 · 事件；“待确认”不在录音卡里重复（下面有“待确认”一栏），卡片不加高。
- 今日节奏：方案 A，说话柱下面一条手机使用色带（越深用得越多），不加图例、不加左侧小图标；按住柱子时提示里带“手机 N 分钟”。
- 事件下面标“当时在用 某 App N 分”（用了 ≥2 分钟且 ≥ 事件时长五分之一）。
- 详情：按日 / 按周；比近 7 天平均（只算有数据的天）多 / 少；24 小时柱状图点选小时，下面列这小时的 App 和事件（可点开）；App 用时用真实图标；时间线按小时分组、合并碎片；设备播放卡片；缺口一行灰字。
- 默认全开：屏幕时间、记录播放标题、首页显示、事件当时在用、整理时带上 App 与播放信息。
- 权限：首页提醒卡列出缺的权限，每项“去开启”直达系统设置（跳不过去退到应用详情页），回来自动重查，开齐自动消失；“暂不需要”关掉缺权限的功能。设置页同样显示授权状态。
- 每日推送带节目名：不改。

## 实现
- `shared/.../screentime/ScreenTimeView.kt`：按小时分钟、当时在用、某段时间各 App、时间线合并、平均与对比（`ScreenTimeViewTest`）。
- `ScreenTimeSettings`：默认开；新增 `showOnHome`、`eventInUse`（`screen-time` 偏好，随备份）。`PlaybackTitleSettings` 默认开。0.4.2 及以前没有这两个开关，升级用户直接得到默认开。
- 界面：`ui/screentime/ScreenDay.kt`（读一天数据、权限检测与直达）、`ScreenTimeSheet.kt`（详情）、`ScreenTimePage.kt`（设置）、`HomeNotices.ScreenTimePermissionNotice`；旧 `ui/today/ScreenTimeCard.kt`、`ScreenTimeSheet.kt` 删除。
