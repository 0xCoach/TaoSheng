# 卡 035 · 陌生声音归组离线实验

只处理 Claude 已拷到本机的数据，不需要原音，不联网，不操作手机，不改 App。

## 输入与复现

需要 Python 3.10+、本机已有的 NumPy。本次环境 Python 3、NumPy 已具备，没有下载或安装依赖。缺依赖时应停止，不能为本卡联网安装。

输入放在此目录的 `private/`（整个目录已被 `.gitignore` 忽略）：

```text
private/
  capture.db
  capture.db-wal
  features/
    <生产缓存的 SHA-256 文件名>
```

在仓库根目录执行：

```bash
OPENBLAS_NUM_THREADS=1 python3 tools/voice-groups-probe/probe.py
python3 -m unittest discover -s tools/voice-groups-probe -p 'test_probe.py'
```

默认观察配置为增量+每 20 个输入及末尾合并，加入/合并阈值均 0.70，最短有效人声 3 秒。`--threshold 0.65` 可以切换明细配置，完整扫描始终覆盖三种方法 × 0.45～0.75（步长 0.05）。报告中的 0.70 建议只适用于本次快照；换数据后需重新解读，不能把生成的文字当自动验收结论。

脚本会覆盖本次实验输出：

- `private/report.md`：完整统计、观察配置所有组的出现时间、原话与试听定位候选，另含 0.65 下触发门槛的私有案例。
- `private/results.json`：输入 SHA-256、全部扫描数字、每组的单元数/去重出现次数/累计秒数、敏感性对照；只留本机。
- `../../docs/任务卡/035-实验报告.md`：由统计字段白名单生成，只有统计与结论，不含原话、姓名、时间、录音路径、内部记录标识或输入指纹。

不要提交 `private/`，不要用 `git add -f`。终端只输出数量和校验结果。

## 实验口径

- 先复制 DB/WAL 到 `private/` 内临时目录，再用 SQLite `mode=ro`、`query_only=ON` 查询。临时 shm 随目录清理。不能对原副本执行 checkpoint，也不能用可能忽略 WAL 的 `immutable=1`。
- 输入文件执行前后全部 SHA-256 比较；差异会阻止写报告。文件哈希只写入私有结果。
- 缓存格式与 `VoiceprintFeatureCache.kt` 一致：大端版本 int、时长 long、存在标记 byte、192 个大端 float。数据库 `voiceprint_samples.vector` 是小端；本实验不读取它、不混用两种格式、不用注册样本填补缓存缺失。
- 缓存键与生产代码一致，句子按 `startAt,id`；空 speakerTag 按句 ID 独立，不能把所有空 tag 合成同一人。有效缓存单元全部纳入盘点，缺失、空向量、损坏、孤立文件分别计数。
- 聚类只看单位向量，不使用原话或人名；等权更新成员向量之和。中心凝聚不是 average linkage；每次取最高中心余弦，合并后重算候选。增量的时间排序和相似度平局选择均确定，另跑倒序及固定随机种子 35。
- 真正陌生池排除全部已知标签。“我”只查询最终陌生中心而不训练中心；人工/自动标签分别报告，不能把相似命中直接说成真实误归。已知姓名另与陌生单元混合、隐藏标签聚类，检查拆分；没有多个姓名就不能评估跨人混淆。
- 出现次数按独立录音段去重；同一段多个 tag 合并后只算一次，时长按缓存有效人声累计并以句子并集封顶。不能把段次数当成独立见面次数。
- 缺乏原音、SNR、RMS 与人工听辨，当前只检查短人声、播放标记、不确定说话人、身份冲突及异常时长，不声称已验证音质门槛。

11 个合成单测覆盖缓存读写契约、WAL、关键过滤、三种聚类、合并权重、出现次数与门槛、负样本不污染中心和标签隔离。不跑 Android 编译或全量测试。
