# 卡 146：技能出卡门槛交付说明

已在 `codex/146-skill-gate` 实现。未修改 `*Contract.kt`、`AudioSource.kt`、界面、数据库实体、查询或迁移；不推送远端。

## 做了什么

- `SkillJson` 支持可选 `gate`，读取、整份保存和生成器解析共用范围校验：人数 1～20、分钟 0～600、句数 0～5000。数字必须为整数，布尔值必须为布尔类型；非法门槛拒绝，不悄悄取消门槛。
- 仅官方 `meeting` 加入 2 人 / 10 分钟 / 20 句 / 排除语音输入的默认门槛。`import_meeting` 与其他官方技能未改，会议卡字段和提示词未改。
- `LocalSkillRepository` 在组织输入和调用模型之前判断完整范围，在入库、合并、推送、试跑返回之前逐卡复核。手动、自动、后台生成、试跑共用此入口。
- `RedoFactory` 中“重新整理”独立生成技能卡的入口也接入同一门槛，防止绕过。
- 自定义技能生成器只通过提示词让模型为会议、访谈、例会等场景选择合理门槛，不增加关键词分类代码；输出门槛非法会沿用原有格式重试流程。
- 有门槛且每天最多一张的技能保留模型给出的真实卡片起止时间，避免原来“一日总结放在运行时刻”的逻辑导致复核误拒；无门槛的一日总结行为不变。

`SkillGateRules.kt` 的统计、校验、失败原因和时段筛选只使用 Kotlin 基本类型与已有 `SkillGate`。`SkillGateJson.kt` 使用可跨平台的 kotlinx.serialization。两份新文件均无安卓、Room、JDK、org.json、网络或系统时钟依赖；数据库实体到基本数据的转换留在现有 `SkillInputs` 适配层。App 显式依赖 serialization-json 1.9.0，与现有共用模块版本一致，没有升级其他依赖。本卡未引入 iOS 编译，也不据此宣称 iOS 已可运行。

## 统计口径

1. “上次以来”沿用现有事件创建时间游标及归属日，统计本轮选中事件的全部原话；按日/按周取相应日历范围的原话。`MeOnly` 仍先限定为明确标为“我”的原话。
2. 门槛统计先于 `boundedLines`。即使 `includeLines=false` 或按周输入不附原话，也会读取完整范围做判断，不改变送给模型的原话策略。
3. 一条 `transcript_lines` 记录算一句，不按标点拆句。时间跨度为计入句子的最大 `startAt` 减最小 `startAt`，按毫秒与分钟门槛比较；空集合跨度为 0，不以录音段长度或最后一句结束时间补足时长。
4. 人数按 `SkillInputs.speaker()` 返回的文字去重，仅排除“待确认”，不另猜身份；“可能是我（未确认）”按现有返回值计为一个标签，不与“我”合并。
5. `countVoiceInput=false` 时，只要 `voiceInputJson != null` 就整句排除，句数、跨度、人数都不计；元数据损坏也不因此把输入文字当成现场发言。设为 `true` 才计入。
6. 首个失败原因按“跨度 → 人数 → 句数”选择，例如“没出卡：讨论不到 10 分钟”“没出卡：只有 1 个人在说”“没出卡：原话只有 6 句”。前置不达标返回 `Nothing`，本次模型调用为 0，token 为 0。

## “没填 / 明确不要”的存法

保留 `formatVersion=1`，不迁移旧文件。文件元数据 `SkillDefinition.gateSpecified` 记录是否真的出现过 `gate`，不进入界面约定或数据库。

| skill.json 内容 | 生效规则 |
| --- | --- |
| 省略 `gate` 且有 `sourceId` | 每次加载继承该官方技能的当前门槛，与 `sourceVersion` 无关 |
| 省略 `gate` 且无 `sourceId` | 无门槛，兼容旧的独立自建技能 |
| `"gate": null` | 明确关闭，官方以后加门槛也不继承 |
| `"gate": {...}` | 固定采用用户设置，不被官方更新覆盖 |

新复制的“我的版本”省略 `gate`。旧的官方副本没有此字段，因此自动继承。改名、改提示词或字段后整份保存时，如果门槛仍等于当前继承值，继续省略字段；改成其他门槛则写对象，改成 `null` 则显式写 `null`。已显式设置的版本再次保存也保留显式状态。

后续门槛编辑器需要保留这三个状态。现有 `saveMine(Skill, prompt)` 只能看到生效值，无法表达“保持数值不变，但从继承改成固定”或“恢复继承”的编辑意图；文件层已经能表达（分别写对象、删除字段），本卡不变更界面约定。尤其不要仅凭 `Skill.gate == null` 推断文件是否省略了字段。

## 逐卡复核与日志

- 使用本次完整原话快照，按句子开始时间取闭区间 `[at, endAt ?: at]`，再使用同一统计规则。未给结束时间的卡只有单个时刻，不能靠整轮大窗口通过时长门槛。
- 先逐卡过滤，再执行日限额、合并和推送；部分通过只保留通过者，全部丢弃返回 `Nothing`，原因采用首张失败卡的首个失败项，例如“没出卡：整理出的讨论不到 10 分钟”。不自动删除以前已经保存的卡。
- 普通技能运行沿用 `skill_runs.result`，追加“；门槛复核丢弃 N 张”，包括部分保留和试跑。模型已调用时仍正常记 token。
- 重新整理入口没有技能运行记录，使用 `UpdateDiagnostics` 记录一行技能 id 与丢弃数量；前置拒绝也记录一句原因，不记录原话。

## 验证结果

仅执行技能相关测试，模型全部使用假实现。新增 `SkillGate146Test` 共 15 个用例：

| 用例 | 断言 |
| --- | --- |
| 2 人、1 分钟、2 句闲聊 | `Nothing`，模型 0 次，token 0 |
| 1 人、15 分钟、40 句 | 原因含“1 个人”，模型 0 次 |
| 2 人、20 分钟、30 句全是语音输入 | 默认模型 0 次且三项统计全 0；显式计入后调用 1 次并出卡 |
| 1 个确认标签及大量 uncertain 标签 | 人数仍为 1，模型 0 次 |
| 3 人、15 分钟、40 句真会议，文本超过裁剪上限 | 裁剪后不足 20 句，完整范围仍通过，模型 1 次并入库 |
| 2 小时范围里模型只返回 3 分钟、5 句的卡 | 自动运行模型 1 次，复核丢弃，无入库、无推送，日志记 1 张 |
| 试跑同时返回无 end 的卡与合格卡 | 只保留合格卡，模型 1 次，日志记 1 张，无入库 |
| 2 人、15 分钟、6 句 | 原因含“原话只有 6 句”，模型 0 次 |
| 老文件缺 gate | 原有行为继续调用模型；import_meeting 无门槛 |
| 我的版本未填门槛，改名/提示词后官方门槛更新 | 继续继承新值，不达标模型 0 次 |
| 我的版本明确关闭 / 自设门槛 | 重载和官方更新后仍保持，各调用模型并出卡 |
| JSON 往返与校验 | 合法边界保留，越界、小数、字符串数字、伪布尔拒绝 |
| 生成器解析 | 接受合理门槛，越界拒绝 |
| 按周、不传原话、每天一张，恰好 2 人/10 分钟/20 句 | 读取原话做判断，保留真实 at，模型 1 次并出卡 |
