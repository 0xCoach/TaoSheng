# 卡 071 · 重做（重新转写 / 重新整理）与导入时选转写模型（后端，关键）

App 名叫“涛声”。在 **`env-sound` 分支**上继续开发（在卡 070 之后，数据库已是 23）。**本卡不改 `ui/` 和 `MainActivity.kt`**，界面由 Claude 做。
约定：`app/src/main/java/app/resound/redo/RedoContract.kt`（新）、`importer/ImportContract.kt` 新增的 `start(id, startAt, asr)`。签名不要自行改；确需改在交付说明提出。`AppGraph.redo` 已预留，由 `ResoundApp` 装配。

## 一、要做什么（负责人已确认）

1. **首页多选事件 → 重做**：两种
   - **只重新整理**：原话不动，用选定的整理模型把这些事件覆盖的时间段重新整理。
   - **重新转写 + 重新整理**：先用选定的转写方式把这些时间段内的录音段重新转写，再重新整理。
2. **原话页多选录音段 → 重新转写**（`TranscribeOnly`）：只换原话，不动事件；完成后提示可以再去重新整理。
3. **导入外部录音时选转写方式**：导入确认时可选豆包 / 本地 / 自定义（只列能用的），只对这次导入生效，不改设置。
4. 转写方式、整理模型都**只列已配好能用的**（`AsrOption.ready` / `LlmOption.ready`），默认选上次在重做/导入里选的，没选过用设置里当前的。

## 二、规则

- **范围**：按选中事件的时间范围（取并集，相邻/重叠合并）整体重做；新结果替换这段时间里的旧事件。大模型可能把事情拆开或合并，这是正常的。
- **原声过期**：没有原声的段不能重新转写。`TranscribeAndDigest` 时这些段保留原文字照常参与整理，`estimate` 里报 `expiredEvents/expiredSegments`；全部过期时只能选只重新整理（`estimate` 照实返回，界面处理）。
- **保留用户的东西**：
  - 重点（★）：新事件与旧的重点事件时间重叠最多的，继承重点。
  - 已确认 / 已完成 / 已忽略的待办、约定：保留原条目和状态，新整理出的同义条目按现有去重逻辑合并，不重复生成；未处理的旧条目随旧事件替换。
  - 手动编辑过的事件：照样覆盖（界面会先提醒），`estimate.editedEvents` 报数量。
  - 技能卡（会议纪要等）：这段时间内的按新事件重新生成；用户手动改过的卡不动。
- **撤销**：每次重做前快照这段时间的事件、条目、相关技能卡和（若重转写）原话；`undo` 恢复到重做前。只保留最近一次重做的快照，新重做开始或 1 天后丢弃。已推送出去的内容不撤回。
- **后台任务**：仿照卡 069 导出（`AndroidExportJobs` / WorkManager）：前台通知带进度和“取消”；同一时间一个，其余排队；App 被杀后从头重跑当前任务；完成通知点开带 `EXTRA_REDO_JOB`。阶段文案如“重新转写 3/12 段”“重新整理”。
- **取消**：已重新转写好的段保留新文字；整理没完成就不替换事件（保持旧的）。
- **转写**：沿用现有转写流程（热词、卡 066 本地同音纠正、声纹认人、卡 070 环境音判断不重跑）；指定的转写方式只对这次生效，**不改** `TranscribeSettings`。云端失败按现有重试与失败状态处理。
- **整理**：用指定的 `LlmPreset`（不改设置里当前选中的），沿用现有整理提示词与解析；失败时任务 Failed，事件保持旧的。
- **估算** `AsrChooser.estimate`：本机识别按本机实测速度（`PipelineTimes` 或现有统计）；云端按经验速度；花费按现有用量统计里的单价（`AsrUsage` 等，云端转写有价、本机为 0、自定义无价时为 null）。`RedoService.estimate` 汇总转写 + 整理的预计时间与花费（整理花费估不出可为 null）。
- **导入**：`start(id, startAt, asr)` 把这次导入的段标记为用指定方式转写（只影响这批段），`AsrChooser.remember` 由界面在确认时调用。

## 三、必测（适度，8～12 个）

- 只重新整理：替换时间段内事件；重点继承；已完成待办保留不重复。
- 重转写 + 整理：有原声的段换新文字；过期的段沿用旧文字；`estimate` 计数正确。
- `TranscribeOnly` 不动事件。
- 撤销恢复事件、条目、原话；第二次重做后第一次不可撤销。
- 取消：整理前取消不替换事件。
- 指定转写方式 / 整理模型不改设置。
- 导入指定转写方式只影响这批段。
- options 只把配好的标为 ready。
