# 任务卡 013：手机外放时录的片段不转写（等 012 合并后再派）

## 背景与已定方案（负责人选：照录，但不转写）

手机用**扬声器**外放视频/音乐时，麦克风录到的主要是外放声音。照常录音，但这些片段标为“外放时录的”，**不送转写和整理**；录音保留 1 天后删除（与其他已处理片段一致）；用户可在原话页点“仍然转写”。戴有线/蓝牙耳机时声音不外漏，照常转写。设置里有开关（默认开）。

## 约定（Claude 已写）

- `TranscriptStatus.SkippedPlayback`；`TranscriptRepository.transcribeAnyway(segmentId)`（接口里有空默认实现，请在 `RoomTranscriptRepository` 实现：改回 Pending 并 runNow）。
- 设置：`TranscribeSettings` **不改签名**；开关先放 SharedPreferences `transcribe` 的 `skipPlayback`（默认 true），并提供 `AppGraph` 可读写的一个小接口 `PlaybackSkipSettings { val enabled: StateFlow<Boolean>; fun setEnabled(Boolean) }`（放 `capture/` 下，AppGraph 加 `playbackSkip` 与 `isPlaybackSkipReady`）。界面由 Claude 做。

## 要做的

1. **检测外放**：录音服务里用 `AudioManager.registerAudioPlaybackCallback` 跟踪活跃播放（`usage` 为 MEDIA / GAME / UNKNOWN，排除本 App、通知、闹钟、导航提示音等短声音）；输出设备判断：API 33+ 用 `AudioPlaybackConfiguration.getAudioDeviceInfo()`，否则用当前输出设备列表（有有线耳机、蓝牙 A2DP/LE 耳机连着即视为不外放）。只有“经扬声器外放”才算。
2. **标记片段**：片段录制期间外放时长占片段时长 ≥ 50% 时，入库为 `SkippedPlayback`（数据库升 v8，`segments` 加 `playbackMillis` 记录外放时长，写 Migration 7→8 并跑一次 1→8 整链）。开关关闭时照常 Pending。
3. **转写队列**跳过 `SkippedPlayback`；1 天后按现有规则删录音；`transcribeAnyway` 后正常转写、整理。
4. 守护记录/诊断里记一条“外放期间 N 段未转写”的计数即可，不要每段一条。

5. **5 分钟硬切不丢字**（负责人要求任何长度的对话都能完整转写，聊天半小时以上很常见）：`SpeechSegmenter` 在达到 `MAX_SEGMENT_SAMPLES` 硬切时，新片段带上前一片段末尾 **1 秒**重叠（目前是无重叠硬切，切口可能把字切断）。整理/问问合并相邻片段时，重叠的那 1 秒可能出现重复的一两个字，可接受；在交付说明里写明。自然结束（2 秒静音）的规则不变。

## 测试（适度）

新增测试 **不超过 7 个**：外放占比判定、耳机时不算外放、跳过入队、transcribeAnyway 改回 Pending、Migration、硬切 1 秒重叠。`./gradlew assembleDebug` 通过。
