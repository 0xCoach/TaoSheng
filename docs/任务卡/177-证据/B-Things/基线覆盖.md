旧实现为 32115d4 的 app/things/RoomThingRepository.kt；ThingRepository177Test 在旧类上录制后，已删除写夹具分支。夹具保存整个调用顺序的所有输出，文件为 app/src/test/resources/repo177/RoomThingRepository/outputs.txt。

| 覆盖 | 录制内容 |
|---|---|
| autoDetect / setAutoDetect | 默认、关闭与开启；每次等待流确认；末尾保存 watermark/revision |
| things / search / thing / history / pending | 列表、空搜索、带 % _ 反斜线的字面量搜索、单条/缺失、历史、待确认前后 |
| draft | 成功与原离线兜底 |

| markReturned / deleteRecord / deleteThing | 归还记录、删记录、删物品及最终可见列表 |
| propose / flush | 真实事务内提案输出；每次异步命令等待同一个队列屏障 |
