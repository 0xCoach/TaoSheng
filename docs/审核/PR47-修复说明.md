# PR47 修复说明

## 修改范围

1. 隐私删除：事件遗忘、单段、批量删除在数据库事务内按所选录音段的各自时间范围清理屏幕事件、播放记录和覆盖缺口；不把不相邻片段之间的时间合并删除。按时间删除也清理两类来源的覆盖缺口，无录音时同样生效。播放记录沿用既有边界截断规则；与区间重叠的缺口整条清除。保留 `archiveFiles`、`extraFiles`、文件清理队列及重试逻辑。
2. 标题采集：通知监听服务连接后先观察设置；关闭时不注册媒体会话回调、不读 metadata、不启动心跳。运行中关闭时注销会话与回调、取消心跳；重新开启时查询当前会话并补记。回调读取与心跳读取前再次检查当前设置；断连和销毁复用清理动作。开关协调规则位于 shared。
3. 问题记录：采集协程的失败统一进入 `FailureNotes`，包括 `PlaybackRecorder` 上抛的落库异常。固定位置加异常类型，沿用同处同类十分钟持久化限流，不写异常原文、标题或包名。
4. 提示词：用户允许整理的外放片段可形成“收听/观看的节目内容”事件；禁止写成本人经历、禁止据节目生成待办或约定，未允许整理的片段仍不进整理。`DigestRunner` 和 `RedoFactory` 已通过同一适配器引用 shared 规则，无需复制规则。

数据库版本仍为 37；未修改 ui、MainActivity、约定文件签名或设备状态，未推送。
