# 任务卡 024：隐私开关（删除最近 10 分钟、这段别记）+ 通知栏快捷开关（后端）

## 背景与已定方案（负责人已拍板）

说明书 4.12 隐私开关：暂停录音（时长可选）、一键删除最近 10 分钟、任意记录“这段别记”彻底删除；另有下拉通知栏快捷开关。删除都是**彻底删除**，不进回收站。界面（确认面板、按钮位置）由 Claude 做，**本卡不改 `ui/` 下的文件**。

## 约定（Claude 已写，签名不要改）

- `privacy/PrivacyContract.kt`：`PrivacyActions`（`deleteRecent`、`forgetEvent`、`forgetSegment`）与 `ForgetResult`。注释里写了删除范围，按注释实现。
- `AppGraph`：已加 `privacy` / `isPrivacyReady`，在 `ResoundApp` 里赋值。
- 暂停沿用已有的 `CaptureController.pause(minutes)` / `resume()`，不改。

## 要做的

1. **`RoomPrivacyActions`**（放 `privacy/` 下）
   - 一个数据库事务里删：`segments`、`transcript_lines`、`memory_items`、`memory_events`，规则见约定注释；录音文件在事务成功后删，删不掉只记诊断不报错。
   - 声纹：被删原话产生的声纹样本（`voiceprint_samples` 里 segmentId 对应的）一起删；声纹特征缓存目录里对应文件也删。
   - 问问历史里引用了被删内容的出处不用改（点开时显示“已删除”由界面处理）。
   - `deleteRecent`：正在录的那一段立即结束并丢弃（通过 CaptureService 发一个内部动作，不要重启服务）；还没转写的片段一并删除，不再转写。
   - 已生成的当天回顾不重写（交付说明里写明）。
2. **常驻通知加按钮**：现有“暂停 1 小时 / 恢复”保留，改为“暂停 30 分钟 / 恢复”；新增“删最近 10 分钟”——**不直接删**，点了打开 App 并带上 `open=deleteRecent`（MainActivity 里先只解析并存到一个 `StateFlow<String?>` 请求里，界面由 Claude 接；参考已有的 `open=review` 写法）。
3. **通知栏快捷开关（TileService）**：名称取 `context.appName`；状态跟随录音（聆听中 = 亮，暂停/停止 = 暗，副标题“聆听中 / 已暂停到 14:30 / 已停止”）。点一下：聆听中 → 暂停 30 分钟；暂停中 → 恢复；已停止 → 开始。长按打开 App（系统默认行为，配好 `android.service.quicksettings.TOGGLEABLE_TILE` 与 PREFERENCES 即可）。图标用现有通知的单色图标。
4. 删除后，今天页、记忆页的数据流应自动刷新（Room 的 Flow 自然会刷），不需要额外广播。

## 测试（适度，共不超过 7 个）

`deleteRecent` 跨事件时只删部分原话、整件在内时删事件；条目随原话删除；`forgetEvent` 删干净（含声纹样本）；`forgetSegment` 让空事件消失；快捷开关三种状态下的点击动作（纯逻辑测试即可）。`./gradlew assembleDebug` 通过。**不要跑全量测试，不要反复重跑。**
