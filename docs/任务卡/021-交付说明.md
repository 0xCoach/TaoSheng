# 021 本地转写会话、停顿切段与密钥指纹

## 交付行为

- 下载完成后校验模型并记录 SHA-256、文件大小、修改时间及 tokens 文件元数据。加载只读小标记和元数据；旧版纯 SHA 标记首次加载时再校验一次并升级。元数据改变后标记失效，需要重新下载。
- 一个共享绑定连接对应独立的 `:local_asr` 进程。请求进入串行队列，等待期间不计入识别执行超时；同后端复用原生模型，多人分段模型也在会话内复用。最后一个请求完成后空闲 60 秒释放绑定，服务销毁并退出进程。新请求会取消空闲计时。
- 保留 NPU 检查失败后回退 CPU；修复绑定超时后旧连接阻碍后续 CPU 绑定的问题。请求取消会通知服务跳过队列项，正在执行的 JNI 调用结束后停止继续切片。
- 每块最多 28 秒，在最后 5 秒中寻找最近至少 200 毫秒的低能量停顿。没有停顿时选最安静位置，前后重叠 1 秒，依据重叠文字及时间去重。切片不跨说话人边界。
- 使用模型输出的 CTC token 起点形成逐句时间，标点、较长停顿和人物变化触发分句。句尾由下一 token 或最多 400 毫秒估算，因此不是人工校准的精确字音边界。模型未提供 token 时间时保留整块时间，不伪造逐句时间。
- 原话逐句显示时间，长按可指定人物；按用户最后决定，取消句子点击播放。录音清理仍按既有策略：完成转写后满 24 小时可清理，保留文本。
- 设置身份比较只包含密钥 SHA-256 指纹，避免比较字符串携带明文密钥。
- 合并 020 的界面修订：每人独立卡片、总人数、直接输入姓名指定人物、标签从左到右自动换行、管理与清空按钮同排。
