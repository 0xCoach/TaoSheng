范围：spool/音频持久化、密钥存储、导出分享、备份加密、权限与导出组件、MCP 服务、更新通道、网络出向。

## 审查结论（按面）

| 面 | 结论 | 依据 |
|---|---|---|
| 原始音频/spool | PASS | `filesDir/segment-spool` + `filesDir/segments`，应用私有目录，无外部存储写入；`privacy-spool` prefs 记已丢弃片段 |

| 权限清单 | PASS（有冗余可关注） | RECORD_AUDIO 有前台服务指示器；后台定位、PACKAGE_USAGE_STATS、UPDATE_PACKAGES_WITHOUT_USER_ACTION 属高敏感，当前各自有真实功能使用（场景/更新），建议发布前复核是否全部保留 |

## 发现并修复

**P1 MCP `record_get` 越权读**：限定项目的 MCP 客户端可按 id 直接读取其他项目的 idea/decision（`inScope` 未套用）。已在 `McpServer.callTool` 的 `record_get` 分支补 `takeIf { inScope(it.projectId) }`，越权时返回"不存在"（不泄露存在性）。其余工具路径（search/list）此前均已正确套用 inScope。

## 已知残留风险（不在本次修复）

- MCP Bearer 比较非常数时间：仅监听 localhost，timing 侧信道现实风险极低，记录不修。
- 明文备份选项：用户不设口令时导出明文 zip 到自选目录；属显式选择，建议后续在备份页加一次提醒文案（Claude 侧 UI）。
- `UPDATE_PACKAGES_WITHOUT_USER_ACTION`：静默安装能力有完整签名+sha256+身份比对兜底，但该权限本身属高危，发布门禁项。
- 崩溃日志/FailureNotes 可能含转写文本片段：存私有目录，出向仅限用户主动导出诊断，可接受。
- 无截屏/录屏防护（FLAG_SECURE）：个人自用定位，暂不启用。
