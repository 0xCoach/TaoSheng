# 093：本地转写主要识别语言

## 修改

- 在“原话与转写 → 模型和转写设置 → 本地识别”增加“主要识别语言”：自动识别、中文（普通话）、粤语、英语、日语、韩语。
- 升级默认保留自动识别；用户本次主要使用带口音普通话，安装验证后在手机上选择中文。
- 仅改变现有 SenseVoice 的语言参数，不训练、更换或重新下载模型；不影响豆包和自定义云端转写。
- 设置保存在现有 transcribe 偏好中，纳入现有备份。参数作为一次请求的快照跨进程传递，NPU 失败回退 CPU 时继续使用同一语言。
- 模型复用标识包含语言；改语言后的新请求不会复用旧语言配置。正在执行的请求按启动时的语言完成，后续请求使用新设置。
- 本地转写配置身份包含语言，设置改变后旧轮次不会继续按旧配置处理后续记录；云端身份不受此设置影响。
- 旧转写不自动重写；用户可按需手动重转。没有增加模型调用或云端 Token。

## 效果边界

- 指定中文针对自动语种误判，不承诺所有口音都准确。自动与中文在真实误识别录音上的准确率对照尚未完成。
- 英语、日语等实际外语录音应选相应语言或自动识别。语言选项能力和设备运行验证不能代替每种语言的准确率评测。
- 本次明确授权增加设置，UI 改动限于该选择器，未改任何 Contract 接口签名。
