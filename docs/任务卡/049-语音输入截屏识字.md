# 卡 049 · 语音输入：读不到界面时截屏识字（后端）

**真机结论（10-24，诊断日志）**：卡 048 的“读界面”在负责人最常用的两个场景都失败——
- **微信**：无障碍只露出 1 个节点（根节点，无子节点），输入框和聊天内容都拿不到（微信屏蔽第三方无障碍）。
- **UU 远程终端**（`com.netease.uuremote`）：32 个节点、0 个可编辑框，文字是自绘的。
- 判断“正在语音输入”是成功的（讯飞 `com.iflytek.inputmethod.miui` 录音会话每次都被察觉）。

负责人提议并确认：**截屏 + 本地识字**。**两个方案都保留**：能用无障碍读到的照旧用原文（小米备忘录 10-24 实测已成功），读不到时自动改用截屏识字。

**约定**：`VoiceInputSettings.screenOcr`（默认 true）已加，界面开关已做。其余签名不变。
**分支 / 工作树**：`codex/049-voice-ocr`，`~/Developer/resound-codex-049`。main 上已有卡 048 及调试改动（`VoiceInputService` 的 `findEditable` 兜底、`connected` 运行状态、`VoiceInputDbg` 诊断日志——只写步骤和数字，保留这种写法）。

**负责人定的简化（10-24）**：**每次语音输入只截 1 张图**；**不补记之后的回复**（对方回了，负责人肯定还会再回，下一次语音输入自然把它当上下文）。截图只在内存里识别，识完即丢。连续几段语音输入时，**上下文完全相同的内容去重**，让记录连起来是通顺的。

## 一、截屏

1. 无障碍配置加 `android:canTakeScreenshot="true"`，用 `AccessibilityService.takeScreenshot`（API 30+，手机为 Android 15）。不走 MediaProjection，不弹录屏确认。
2. **只在读界面拿不到输入框 / 文字时**才截（备忘录这类读得到的照旧走卡 048 原路，10-24 实测成功）；`screenOcr=false` 不截。
3. **时机：每个语音窗口只截 1 张**——别的应用停止录音后约 1 秒（等输入法把最终文字填进输入框）。若在这 1 秒内已离开该应用，就不截不记。
4. 截图只在内存里识别，**不落盘、不上传、不进日志**；识完立即回收位图。禁止截屏的页面（报错或全黑）跳过不记。
5. 描述文字（`voice_input_description`）补一句“读不到界面时会截屏在手机上识别文字，图片不保存”。

## 二、识字

1. 离线中文识字（建议 Google ML Kit 中文文字识别**内置模型版**，不依赖 Play 服务下载；版本与 AGP 8.11.1 / compileSdk 36 兼容，体积增加写进交付说明）。返回每块文字及位置。
2. 去掉状态栏、导航栏、输入法面板（用 `windows` 里 `TYPE_INPUT_METHOD` 窗口的位置——微信屏蔽节点但窗口列表是系统给的；拿不到就按屏幕下方约 40%）。去掉时间戳样式（`23:41`）和“发送”“按住说话”等界面文字（复用 `CHROME`）。

## 三、从这 1 张图里取

1. **我说的那句**：紧贴输入法面板上方的那一块（输入框，可能多行，按位置合并）。终端类同样取输入法面板上方最靠下的那一段（光标所在行）。取不到就不记。
2. **之前的上下文**：输入框上方的内容，最近约 20 行 / 1500 字。
3. **标题**：顶部区域的标题文字（如“文件传输助手”“老王”），拿不到为 null。
4. `after` 一律为 null；去掉卡 048 的“回复补记”在截图路径上的逻辑（读界面路径也按负责人意见**不再补记回复**：约定里 `replies` 默认已改为 false、界面开关已去掉；已存的设置文件里若为 true，读取时一律按 false 处理）。

## 四、去重（两条路径都适用）

1. **上下文去重**：同一应用 + 同一标题（标题都为 null 时按同一应用）在 **30 分钟内**的上一条语音输入记录，其上下文里已经出现过的行（规范化后完全相同），这次不再存；只存新出现的行。都重复就存 null。
2. **我自己的话不进上下文**：上下文里与我之前已记下的语音输入原话完全相同的行去掉（它们已经是单独的记录）。
3. **原话去重**：与 30 分钟内同应用的上一条语音输入原话完全相同（规范化后）就不再存（防同一句被识别两次）。与录音转写的重复检查照旧。
4. 只做“完全相同”的去重，不做意思相近的合并。

## 五、必测（6～10 个，用构造的识字结果，不用真图）

1. 取输入法上方的输入框文字为原话；多行合并；上方内容为上下文。
2. 终端：取最下方一段。
3. 每个窗口只截一次；1 秒内离开应用不截；读界面成功时不截；`screenOcr=false` 不截；截屏失败 / 黑屏跳过。
4. 状态栏、输入法区域、时间戳、界面文字被过滤。
5. 去重：连续三段语音输入，后两条只存新增的上下文行；我之前的原话不进上下文；完全相同的原话不重复存；超过 30 分钟或换了聊天不去重。
