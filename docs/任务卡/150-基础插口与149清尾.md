### 1. 基础插口（`shared/src/commonMain/kotlin/app/resound/platform/`，新文件，签名按下面写，可补 KDoc，不要擅自加方法）

```kotlin
package app.resound.platform

/** 当前时刻（毫秒）。业务规则一律从这里取时间，不直接调系统时钟 */
fun interface NowMillis { fun now(): Long }

/** 当前时区 ID（如 "Asia/Shanghai"）；规则里需要按本地日期计算时由它提供 */
fun interface ZoneProvider { fun zoneId(): String }

/** 日志：tag 用中文或包名均可；不得记录密钥、原话全文 */
interface Logger {
    fun info(tag: String, message: String)
    fun warn(tag: String, message: String, error: Throwable? = null)
}

/** 简单键值存储（安卓用 SharedPreferences，iOS 用 UserDefaults） */
interface KeyValueStore {
    fun getString(key: String): String?
    fun putString(key: String, value: String?)
    fun getLong(key: String, default: Long): Long
    fun putLong(key: String, value: Long)
    fun getBoolean(key: String, default: Boolean): Boolean
    fun putBoolean(key: String, value: Boolean)
}

/** 平台无关的文件引用：只是一个不透明的编号/路径字符串，由平台解释 */
data class FileRef(val id: String)

/** 文件读写插口 */
interface FileStore {
    suspend fun exists(ref: FileRef): Boolean
    suspend fun size(ref: FileRef): Long
    suspend fun readBytes(ref: FileRef): ByteArray
    suspend fun writeBytes(ref: FileRef, bytes: ByteArray)
    suspend fun delete(ref: FileRef): Boolean
}

/** 调度器插口：规则里需要切到后台时用它，不直接写 Dispatchers.IO */
interface AppDispatchers {
    val io: kotlinx.coroutines.CoroutineDispatcher
    val default: kotlinx.coroutines.CoroutineDispatcher
}
```

另加 `platform/SharedJson.kt`：一个配置好的 `kotlinx.serialization.json.Json` 实例（`ignoreUnknownKeys = true`、`explicitNulls = false`、`encodeDefaults = true`），供后续卡替换 org.json 时统一使用；本卡只建，不替换任何 org.json 调用。

安卓实现放 `app/src/main/java/app/resound/platform/`：`SystemNow`、`SystemZone`、`AndroidLogger`（android.util.Log）、`PrefsKeyValueStore`（构造传 SharedPreferences）、`LocalFileStore`（FileRef.id 当作绝对路径）、`AndroidDispatchers`（Dispatchers.IO / Default）。在 `AppGraph` 装配为 `AppGraph.platform`（一个小数据类收齐这 6 个，`isPlatformReady`），由 `ResoundApp` 早期创建。本卡**不要求**现有代码改用这些插口（除下面第 2 条需要的）。
