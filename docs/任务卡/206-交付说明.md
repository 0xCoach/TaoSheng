# 卡 206 交付说明

## 后台改动

前台点击安装沿用已有的备份、校验和会话提交。提交后，由当前已恢复的 Activity 直接打开 update 包里的透明中转页。广播接收器只接收系统回执。中转页在前台时接手系统给的确认 Intent，后台待确认时发送高重要性的“点这里完成安装”通知，通知也进入中转页。

确认页返回时，中转页核对当前会话和已安装版本。成功回执结束更新，取消回执恢复“可安装”。返回时仍没有确定结果、提交失败、通知被禁、确认页拉起失败，或提交后 30 秒没有回执时，开放系统安装器入口。进程重启时按已保存的会话、提交时间和完整包摘要恢复。系统安装器接手后，旧会话的取消回执不会覆盖兜底状态。

兜底动作复用 files/update 下已经合成的完整 APK，每次交出前重新核对大小、SHA-256、包名、版本和签名，再通过 FileProvider 的临时只读 URI 发出 ACTION_VIEW。校验不通过会阻止移交。有效文件在兜底期间保留，升级后沿用启动清理，用户明确跳过该版本时释放兜底文件。

## Claude 接入版本更新页

| 界面位置 | 状态或动作 |
| --- | --- |
| 原“安装”按钮 | 继续调用 `AppGraph.updater.install()`，后台负责从当前前台 Activity 打开中转页。 |
| “用系统安装器安装”按钮 | 订阅 `UpdateInstallActions.systemInstallerAvailable`（`StateFlow<UpdateInfo?>`）。有值时显示该版本的按钮，替代会触发下载的“重试”。点击后在协程调用 `UpdateInstallActions.installWithSystem(activity)`，传当前 Activity。返回 true 表示已交给系统，最终安装情况以系统回执或新版启动为准。 |
| 兜底失败、用户放弃 | 结合 `updater.state` 的 Failed.message 显示失败原因。保留“稍后”和“跳过这个版本”的区别，后者调用 `updater.skip()`。 |
| 小米提示卡 | `UpdateInstallActions.showXiaomiInstallHint` 为 true 时提示检查“后台弹出界面”和“安装未知应用”。检测澎湃和 MIUI 的版本属性，属性读取受限时使用厂商标识。该标记只识别机型环境。 |
| 权限按钮 | `openXiaomiPermissions(activity)` 进入带本应用包名的小米权限编辑页；`openUnknownApps(activity)` 进入安装未知应用设置。两者都在 `UpdateInstallActions` 下，打开失败会尝试应用详情页，均失败返回 false。回到页面时用 `updater.canInstall()` 刷新未知来源安装权限。 |

## 真机待验收

1. 负责人在小米 14 Pro 澎湃 OS 上从旧版本走一次补丁更新。问题记录搜索“涛声更新”，同一 session 应能看到 `incremental=true`、`result=submitted`、`result=pending_user_action`、`relay_opened`、`confirmation_opened`。确认页出现时，中转页和待确认回执的先后可能不同。
2. 切到后台，验证收到“点这里完成安装”，点击后出现系统确认。查 `confirmation_notification=true`。在系统确认页取消，核对 `confirmation_returned` 和 `result=cancelled`，更新页应恢复可安装。安装成功可能重启进程，查 `result=success` 或新版启动后的 `result=replacement installed=…`，核对版本号。
3. 若仍卡住，按 session 找最后一步。提交超时看 `fallback=no_progress_30s`，通知被禁看 `fallback=notification_blocked`，拉起失败看 `relay_start_failed` 或 `confirmation_launch_failed`，请求确认后一直未离开中转页看 `confirmation_not_visible_30s`，返回结果未定看 `confirmation_returned_session_exists_`。点击兜底后应有 `result=system_installer_opened`，无需再下载。
4. MIUI 14 请原反馈人按同一路径复验。权限页的实际落点、通知展示和 ROM 是否允许弹窗均待实机确认。系统安装器 ACTION_VIEW 交接后若用户在系统页放弃，保留兜底按钮供重试。

本卡完成后台与规则，按钮和提示卡待 Claude 接入。
