## 界面对接与真机待验

## 调研和功能边界

- 仅 DeepSeek 用本机已有密钥只读实测 `/models` 与余额，均 HTTP 200；未输出密钥或账户金额。OpenRouter 公开模型目录已核对。其余厂家没有带账户实测，不声称 12 家推理全部可用。
- 模板只内置 DeepSeek、Kimi 两家的同推理 Key 余额接口。需要云签名、管理密钥、控制台登录或没有可核实公开契约的均为 `null`；手填余额字段仍按人民币元解释，不支持币种换算、表达式或额外签名头。
- MiniMax 当前兼容契约未列 `response_format`，后台依赖提示词要求 JSON 和已有严格解析/重试，不承诺强制 JSON。仅思考型号使用有限输出预算，复杂任务仍可能截断或超时；建议配置后先做模型检测。
- 模型 ID、价格、账号开通条件为调研当日快照，后续变化需更新模板。零一万物不收录的理由是未核实，不能解读为已确认停服。
