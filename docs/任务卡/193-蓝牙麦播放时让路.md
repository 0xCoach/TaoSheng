# 卡 193：用蓝牙麦录音时，放视频音乐就让出（大疆 Mic 等）

基线：main（含 #47 设备播放检测，数据库 37）。执行：Codex（Astra）。工作目录 `~/Developer/TaoSheng-193`，分支 `codex/193-bt-yield`。目标版本 0.5.0。**不改数据库**，不改 `ui/`、`MainActivity.kt`（界面 Claude 做，需要的配合写进交付说明）。

## 为什么做

用户反馈：大疆 Mic 连上手机后系统把它当成蓝牙耳机；涛声用它录音时看视频没有声音。

原因（已读代码确认）：用蓝牙麦录音必须进入通话模式（`audio/ExternalAudioSource.kt` 第 78～93 行：`MODE_IN_COMMUNICATION` + `setCommunicationDevice` / `startBluetoothSco`）。通话模式下媒体声音也被导到蓝牙通话通道，手机扬声器和普通蓝牙音频都没声。

## 目标

1. **播放时让出**：用蓝牙输入（`InputKind.BluetoothCall` / `BluetoothLe`）录音期间，订阅 #47 的 `AppGraph.playback`（`PlaybackState.playing`：任何媒体在出声）。检测到开始播放：
   - 和现有“别的应用要录音就让出”（`signals.othersRecording` → `yielded`）一样整轮释放：停录、退出通话模式、清通信设备 / 停 SCO，媒体恢复正常出声；
   - 状态报告新的让麦原因（`MicYield` 里加一个，如“正在播放视频或音乐，蓝牙麦已暂时让出”），首页和通知栏能显示；
   - **播放停止后**等一小段确认真的停了（建议 3 秒，避免切歌、广告间隙来回抢），再自动接回蓝牙麦。
2. **让出期间不丢记录的选项**：让出期间改用手机麦克风继续录（外放检测照旧会把外放片段标出来），还是干脆不录，由一个设置决定（见第 3 条）。默认：**改用手机麦克风继续录**；自动切回逻辑复用现有输入切换（`InputSwitchLoop`）。若实现上切换代价太大，可退一步只做“暂停不录”，在交付说明里写清原因。
3. **开关**：新增设置“用蓝牙麦时，放视频音乐自动让出”，默认开；偏好键放已有的录音/输入设置文件里，并按卡 190 的规矩归类（守卫测试要过）。关掉就保持现状（继续占用蓝牙麦，媒体可能没声）。
4. **只影响蓝牙输入**：手机麦克风、USB、有线输入的行为完全不变。#47 的外放检测、外放跳过转写规则不变。
5. **耗电**：只在“蓝牙输入 + 正在录”时订阅播放状态；没订阅者时 `PlaybackMonitor` 不注册回调（#47 已保证）。
6. **诊断**：问题记录里能看到让出 / 接回的时刻与原因（不记应用名、标题）。

## 不要做

- 不自动断开或重连蓝牙设备本身。
