# 020 两三人身份识别推进计划

用户已允许在问问完成后推进。沿用 017 评估，当前尚未向正式 App 上线多人识别。

1. 独立验证短窗 CAM++ 特征和换人边界，先处理两人、再三人轮流讲话。复用真实日常录音，排除电视剧；对比现有整句认我方案，建立人工说话人时间标注。重叠、太短、噪声大的片段标未知，不强行命名。
2. 通过验证后增加人物与样本关联，兼容原有“我”样本及用户纠正。支持人物名、录入/补充样本、从原话指定人物、删除人物声纹。身份与临时说话人编号分开；匿名编号只在同一对话内稳定，不假定跨天是同一个人。
3. 先区分说话人再把可靠片段与人物样本匹配。相似度阈值与第一/第二候选差距共同控制命名；不确定显示待确认。避免未知人的声音被自动纳入已有身份样本。
4. 与现有批处理转写衔接，复用解码和特征缓存；换人后需重新处理转写时间对齐，不能把当前约 28 秒的整块文本直接赋给单个人。
5. 用户后续明确取消专项耗电测试；只验证功能、错认、分段对齐和稳定性。保留批处理，不增加持续实时识别，不要求拔线测电。

上线顺序：独立样本验证 → 人物库和纠正操作 → 批处理整合 → 真机功能验证。保留现有认我行为作为可回退路径，避免将实验标签写进已有记忆。
