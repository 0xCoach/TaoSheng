## 二、设备中枢（`:devices` commonMain，纯 Kotlin）

放在 `app.resound.devices.hub` 包。只依赖约定文件里的接口，全部可用假实现做单元测试。

1. **广播分发与认设备**：输入一条 `Advertisement`，对 `DriverCatalog` 里每个驱动调用 `match`（单个驱动抛异常按 `None` 处理并计一次故障）。
   - 只有一个 `Certain` → 选它；多个 `Certain` → 报“驱动冲突”（列出驱动编号，进诊断，不连接）；没有 `Certain` 但有 `Possible` → 返回候选列表让界面让用户选。
   - 用户选定或自动选定后，记住 `平台句柄 → 驱动编号`（以及连上后得到的 `DeviceId → 驱动编号`），下次直接用。持久化通过一个仓储接口（见第四节），不直接写文件。
2. **连接租约**：每台设备同一时间只有一个持有者（收音、补传、临时管理），后来者排队或拿到“忙”；持有者结束必须释放，协程取消也要释放（用 `try/finally` / `NonCancellable`）。参考 PR #30 的 `D3200Coordinator` 租约做法，但用协程 `Mutex`，不用阻塞锁。
3. **会话**：为每个连接构造 `DriverSession`：
   - `store`：按“驱动编号 + 设备身份”分命名空间的键值存储（底层走仓储接口）。
   - `schedule`：最短间隔 30 秒（短于此按 30 秒），每个连接最多 4 个定时任务，连接断开全部取消；任务抛异常记一次故障但不让会话崩溃。
   - `log`：写入环形诊断缓冲（每台设备最多 500 条），供以后导出。
4. **重连**：连接断开（`closed` 发出或底层断开）后按 3 s、6 s、12 s… 最长 60 s 退避重连；用户“忘记设备”或驱动被停用时停止。
5. **故障隔离**：驱动的任何调用（`match`、`open`、控制、文件、定时任务）抛出非 `DeviceException` 的异常，或单次调用超时（默认 15 秒，文件读取按块计时 30 秒），计为一次故障；同一驱动 10 分钟内 5 次故障 → 对这台设备自动停用该驱动，状态里带原因，需用户在界面手动重新启用。
6. **状态汇总**：给界面一个可观察的设备列表（新类型放 `hub` 包，Claude 之后据此做界面）：每台设备的显示名、驱动元信息、连接状态（连接中 / 已连接 / 正在补传 / 等待重连 / 已停用 + 原因）、`DriverConnection.status` 的最新值、最近错误码。错误只给 `ErrorCode`，不给中文句子（文字由界面翻译）。

## 三、安卓平台插口（`:app`，`app.resound.devices.android` 包）

在现有 `AndroidDeviceLink` / `AndroidDeviceRadio` 基础上改写或包装，供卡 141 接入：

1. **蓝牙中心**：全 App 唯一扫描入口，扫描结果转成 `Advertisement` 交给中枢；遵守“30 秒内最多启动 5 次扫描”（超了就合并 / 延后）；按服务编号过滤的参数可传入。
2. **`GattLink` 实现**：所有 GATT 操作一条一条排队（沿用现有 `serial` 做法）；`maxWriteLength(withResponse)` 按协商后的 MTU 计算（带回应 = MTU−3，不带回应同样 MTU−3，读不到 MTU 时按 20）；**写入超过长度抛 `DeviceException(WriteTooLong)`，不自动拆包**；同一通道多次订阅共享一个订阅。安卓上仍可请求 MTU（说明卡的 `mtu` 是请求偏好）。
3. **`CryptoPort` 实现**（JCA）：严格按约定注释里的字节编码。附测试向量：HKDF 用 RFC 5869 测试用例 1；AES-CTR 用 NIST SP 800-38A F.5.1；AES-GCM 用 NIST 公开向量一条；ECDH 与 ECDSA 用本机 Python（若有 `cryptography` 库）生成的固定向量写进测试资源，没有该库就用 JCA 自身互验并在交付说明注明。
4. **`OpusDecoder` 实现**：包装现有 `AndroidOpusDecoder`，不改其解码行为。
5. **`ClockPort`**、**`DriverStore` 底层仓储**：仓储用一个独立的 SharedPreferences 文件 `device-drivers`（键带命名空间前缀）。**确认备份会包含这个文件**（负责人要求所有配置都进备份）；若备份是白名单机制，就把它加进去并在交付说明写明。
6. **`PlatformExtras.classicSerial`**：本卡只给接口的空实现（返回 null），经典蓝牙串口留给卡 143。
