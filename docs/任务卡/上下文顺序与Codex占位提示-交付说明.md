# 上下文顺序与 Codex 占位提示修复

## 行为

- 保留原有同应用、同标题、近 30 分钟上下文去重范围，以及正文的精确/近似比较门槛；原话去重与续写规则不变。
- 上下文去重只比较此前存过的 before，不再把独立语音原话 row.text 混入已存上下文集合。因此自己的已发送消息可以第一次进入上下文，之后重复仍去掉。
- 比较上下文时区分说话人，避免“我：明天见”和“对方：明天见”互相删掉。旧的无说话人记录与带说话人的记录不互相匹配。
- OCR 和无障碍聊天节点按屏幕自上而下排序，标注我/对方或单聊联系人名。同侧不同消息不再无条件拼接；同块且紧邻的 OCR 折行仍合并。
- 模型提示说明上下文是去重后的新增消息，可能不连续；不据此猜测明确引用关系、屏幕外消息或精确发送时间。
- UU 远程/终端排除整句 Ask Codex 占位提示（含大小写、尾部省略号、光标变体），不会过滤“请解释 Ask Codex 是什么意思”这样的真实指令。终端不使用右侧聊天气泡兜底，后续占位提示不会覆盖之前识别到的真实输入。
- 未改界面、接口约定、数据库或旧记录。
