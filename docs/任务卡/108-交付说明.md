# 108：自定义异步语音服务与声纹样本管理

## 功能
- 自定义转写服务在 /models 显式声明 async_jobs、diarization、identification 能力后使用异步协议；其他服务沿用现有协议。服务地址、模型和密钥由使用者自行配置。
- 保存任务句柄与幂等键，恢复查询不重复上传；正常慢任务最多等待 90 秒，等待状态不消耗失败次数；支持取消及网络策略暂停。
- 服务地址与密钥作用域隔离人物、样本和动作；远端身份不会被本地自动认人覆盖。
- 人物页展示原话及样本，支持标注录入、样本删除与回放；旧样本无副本时从仍存在的原音频读取。
- 修复远端声纹就绪后旧本地原话无限等待整理的问题。

## 数据与接口
- Room 29→30 新增远端任务、人物、动作表及片段来源；30→31 新增样本表。迁移集中注册，保留已有数据。
- 服务端需实现 /transcription-jobs 及人物/样本管理接口，普通 OpenAI 转写接口不会自动具备这些能力。
- 包含已有 VoiceprintContract 的样本/原话查询、删除、回放接口及配套界面，需界面与接口负责人审核；本次未另行设计界面。
- 保持主分支的包名、版本号、签名、应用名称及更新通道。
