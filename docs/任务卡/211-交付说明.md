# 卡 211 交付说明：修改原话（最简版，#55）

## 方案（负责人 11-19 确认）
直接改原句、不留旧句；人工修改视同一次“只换原话”的重新转写：事件不自动变，改完提示重新整理；改错了对那段重新转写回到机器结果。语音输入的句子同样规则。

## 做了什么
- 数据库 42 → 43：`transcript_lines` 加 `textEditedAt`（人工修改时间）。`TranscribeDao.editLineText` 直接替换文字、清掉同音纠正旧句 `originalText`、记修改时间；`editedLineCount` 统计若干录音段里人工改过几句。全文索引由现有触发器自动更新。
- 仓储：`TranscriptRepository.editLine`（空文本拒绝、去首尾空白）、`editedLineCount`；`TranscriptLine` 加 `edited`、`eventId`。
- 界面：长按原话菜单“复制这段”下加“修改文字”，这一句原地变输入框（取消 / 保存，空不能存）；改过的句子末尾灰字“已修正”；保存后若该句已整理进事件，底部提示“原话已修改 · 重新整理”（6 秒），点了打开现有重新整理面板；没整理过的提示“之后整理会用新的文字”。底部提示条支持自定义按钮文字（默认仍是“撤销”）。
- 播放：正在播放时同步替换播放条字幕（`LinePlayer.replaceText`）。
- 重新转写：预估 `RedoEstimate.editedLines`，要重转时提醒“其中 N 句原话你手动改过，重新转写会换回机器识别的结果”。
- 搜索、推送、备份、问问引用按内容变化自动跟上；备份按列通用导出，旧备份缺这一列按空值恢复。
