# 卡 058 · 手动生成回顾：可靠完成，没生成要说清楚原因（后端）

App 名叫“涛声”。给用户看的文字一律写“涛声”，只说结果、不讲机制。
约定文件：`review/ReviewContract.kt`（负责人已改：`ReviewState.stage`、`ReviewState.lastErrorDate`、`hasMaterial()`、`windowText()`）。签名不要改。
界面（“按天”页和回顾设置页显示原因、进度，按钮按 `hasMaterial` 显示）由 Claude 做，**本卡不改 `ui/` 和 `MainActivity.kt`**。

## 一、问题（已查明）

用户反馈手动点“生成回顾”没生成。代码里三处会让它**悄悄失败**：
1. 回顾窗口是（上一日截止时刻，当日截止时刻]，默认昨晚 22:00 到今晚 22:00；“按天”页的按钮却按自然日有没有事件显示。窗口里没内容时 `run()` 走 `error(null); return`，**清掉错误、什么都不说**。
2. 失败原因只写 `lastError`，“按天”页不显示（界面问题，Claude 改）。
3. 手动生成用 `scope.launch` 在后台跑，先做 `beforeReview()`（补转写+整理，最长 10 分钟），**没有前台保护**，用户切走后小米很可能杀进程，静默丢失。

## 二、已定方案（负责人已确认）

**原则：每次手动生成结束，要么回顾已更新，要么 `lastError` + `lastErrorDate` 写清楚为什么没生成。不允许没结果也没原因。**

1. **手动生成改走 WorkManager 加急任务**（`setExpedited`，配额不足时退为普通任务），复用 `withReviewForeground` 的前台通知（标题“涛声正在生成回顾”）。同一天重复点只排一个（`enqueueUniqueWork` + KEEP）。`generateNow` 立即把 `generating = true`、`stage = "排队中…"`，界面马上有反馈。进程被杀后 WorkManager 会接着做。
2. **进度 `stage`**：`"正在转写和整理还没处理的录音…"` → `"正在写回顾…"` → 结束时为 null。
3. **没内容时说清楚**：`lastError = "${windowText(date)} 没有可写进回顾的事"`，`lastErrorDate = date`。**手动生成**时不能再 `error(null)` 静默返回。定时生成没内容时保持现在的行为（不推送，也不报错）。
4. **各类失败的原因**（都写 `lastErrorDate`）：
   - 没填密钥：“还没填写整理模型的密钥”（自定义服务无密钥时不算，见卡 055）。
   - 模型错误：沿用 `LlmException.type.human`；可重试的类型在文案末尾加“，稍后再试”。
   - 模型返回的内容无法解析：“模型返回的格式不对，换个模型或稍后再试”（单独 catch `ReviewPrompt.parse` 的异常，不要落到笼统的“生成失败”）。
   - 其他：“生成失败：{异常类名}”。不回显密钥、原话或服务端原文。
   - 回顾前整理超时或部分失败**不算失败**，照常用已有内容生成；但生成成功后，若整理没全部完成，`lastError` 写“已用现有内容生成；还有录音没整理完”，`lastErrorDate = date`（界面用灰色显示）。
5. **成功时**清掉 `lastError` 和 `lastErrorDate`。
6. **`hasMaterial(date)`**：与 `run()` 的判断完全一致（窗口内有事件，或有条目，或有超期未跟进的重点），返回 Flow，事件变化时自动更新。抽一个共用函数，`run()` 和 `hasMaterial()` 都调它，不要写两份规则。
7. **`windowText(date)`**：如“10月28日 22:00 – 10月29日 22:00”；截止时刻为 0:00 时写成“10月28日 0:00 – 10月29日 0:00”。

## 三、必测（适度，5～8 个）

- 窗口内没内容 + 手动：`lastError` 含窗口文字、`lastErrorDate` 正确，`generating` 回到 false。
- 窗口内没内容 + 定时：不报错。
- 模型返回乱码：文案为“模型返回的格式不对…”。
- 成功：清掉错误；整理未完成时写“已用现有内容生成…”。
- `hasMaterial` 与 `run` 判断一致：自然日内有事件但都在截止时刻之后 → false。
- `windowText` 一例。
