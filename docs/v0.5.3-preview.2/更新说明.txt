⚠️ 预览版：不改数据库，可以直接装回 0.5.2 正式版。

【鼾声中断能听、能确认】
从这版起每次鼾声中断都存一段录音（安静前 5 秒到鼾声回来后 8 秒）。在“昨晚 → 鼾声中断”里点时间，图会移过去并播放；下面可以点“是 / 不是”，点“不是”就从次数里去掉。以前记的中断没有录音。

【夜里录音保留】
确认过的录音最多留 90 天（以前一直保留），没确认的仍是 7 天。

【坚果云推送不再太频繁】
同步文件夹的摘要以前每出一张卡就推一次，现在和整理结果一起按你设的间隔合并推；没有变化时不再连坚果云，减少限流。

【备份更快】
以前每次备份要逐天检查一遍（导入旧通话录音后有几百天，很慢），现在一次列清。

【豆包可用 Agent Plan】
语音转写 → 豆包 → 接入方式，可以选“Agent Plan”，填火山方舟 Agent Plan 订阅页的专属 API Key，用套餐里的豆包语音识别。两种 Key 分开保存；Agent Plan 失败不会改走按量计费。是否扣的套餐额度请在方舟控制台查看。

【通话录音转写失败说清原因】
时间线上点“转写”失败时，不再一律写“原文件不在了”，会写具体原因（如需要重新授权、格式不支持），能重试的有“重试”按钮。

【位置调整】
“原声保留天数”和“录音包导出”挪到 设置 → 录音管理 → 录音存放。

【其他】
· 备份页写成“记录跨 N 天（最早某年某月）”。
· 删除导入的录音时，说明写清：手机里的原录音不会被删，通话录音删后回到“未转写”可以再转。
· 问题记录不再被无用记录占满；备份成功也会记下用时。
